# Native roundtrip fixture

One saved DKM project and its hashed native-source ZIP, used by the focused
native payload, gate, record and official bundle checks. These are map data;
they contain no editor source code or DLL. Keep both files together.
Run the test executables from the repository root.

Original game definitions for these tests are read from installed level1.kwd;
tests never write that installed bundle. The fixture was saved by the user.
