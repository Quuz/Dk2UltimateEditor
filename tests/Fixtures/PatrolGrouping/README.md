# Patrol tree oracle

Read-only expected source lists, never game-map repair fixtures.

- `source-groups.tsv`: `physical ID order|next IDs indexed by ID|groups`; commas
  separate IDs, semicolons separate groups. An empty third column means no paths.
  Exhaustive 1–4-identity functional graphs and all file permutations: 15,404 rows.
- `literal-cases.json`: nine hand-specified source cases, including the Level10
  branch described by the original comment.
- `level10.json`: independently parsed installed Things.kld SHA/ordered ID pairs
  and source groups. This installed version differs from the comment's links.

Generated by the separate fixed-array C-routine simulation recorded in
`artifacts/Evidence/PatrolGrouping-20261012/source-oracle.py`; product code is not
used to derive the expected groups. The fixtures are included in the unified
source project. See `docs/PATROL_SOURCE_GROUPING.md` for scope and limitations.
