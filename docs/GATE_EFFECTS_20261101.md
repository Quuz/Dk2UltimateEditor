## Разобранные особенности проверки

Первый assert после общей отмены вложенной генерации ошибочно ожидал revision0.
Фактический сохранённый baseline после подготовки площадки имел revision2;
сохранение очищает историю/dirty, но не обязано обнулять revision.
Полные буферы и история уже совпадали. Проверка исправлена на точное равенство
исходной ревизии; повторное чтение подтвердило прежнюю2. Продукт не менялся.

После скрытия/показа окна UIA пересоздала часть элементов; старый индекс имени
стал недоступен. Получен новый снимок и актуальный индекс. Главный UIA tree
местами оставался старым, поэтому новые действия выполнялись по свежим
скриншотам, а модальные поля — по их собственным свежим снимкам.

После закрытия modeless окна снимок главного окна иногда показывал Codex,
оказавшийся впереди. На нём действий не выполнялось; редактор активирован,
получен новый снимок. Наличие таких снимков не считается проверкой редактора.
Полный протокол MCP сохраняет источники сравнения.
