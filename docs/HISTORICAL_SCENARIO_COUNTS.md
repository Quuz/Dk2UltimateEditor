# Исторические сценарии: полный диапазон отрицательных ID действий

25 октября 2026. Устранён ложный отказ upgrade KTRG версии1 →3.

Исходный `Editor_ExtractTriggers` читает число действий как LONG, назначает
первому действию WORD `0xFFFF` и уменьшает ID для каждого следующего.
В знаковом пространстве действий это −1…−32768: **32768 действий**.
Условия используют положительные ID1…32767. Современный allocator новых
действий уже поддерживал все 32768 значений.

В `UpgradeNestedEvents` один helper ограничения числа записей применял предел
32767 и к условиям, и к действиям. Поэтому 32767+1 действий в двух условиях
успешно обновлялись, а те же 32768 действий в одном условии ошибочно отвергались.

Helper теперь принимает максимум, по умолчанию32767. Только число действий
в одном условии проверяется с пределом32768. Общие пределы по-прежнему
проверяются отдельно: максимум32767 условий и32768 действий во всём upgrade.
32769 действий, переполнение между условиями, невозможные счётчики и неполная
последняя запись отвергаются атомарно. Маркеры, размеры, типы и хвосты остаются
под прежними проверками; ни один ID0 не назначается действию.

Полный upgrade остаётся одной отменяемой операцией. Исходный файл не меняется.
После сохранения DKM и повторного открытия крайний ID0x8000 остаётся допустимым;
компиляция переносит все32768 действий в игровую коллекцию без столкновений ID.
Тестовое игровое имя — `DK2Preview_6a88240eaf814f78`; игра не запускалась.

В этой ветке сопоставлены четыре исходных рецепта условий и десять действий.
Изменения координат у старого ADDCREATURE (x−1/y−1), отличие CHANGESQUARE без
смещения, reusable→repeat1/255 и преобразование обратных связей не менялись.
Для пустого списка текущий upgrade сохраняет нулевую ссылку, не повторяя
исходное присвоение будущего ID несуществующей записи. Это прежняя явно
проверенная коррекция целостности, а не новое расширение этой правки.

KTRG2 →3 расширяет только записи TRIGGERLINK; оставшиеся события и весь хвост
из146×64 байтов псевдонимов копируются прежним маршрутом. KTRG3 не обновляется.
Неизвестные версии/неподтверждённые layouts не преобразуются по догадке.
Их дальнейшая editable поддержка относится к I04.

Доказательства: `artifacts/Evidence/HistoricalScenarioCounts-20261025`.
До изменения: одна неуспешная и три успешных новые группы. После изменения:
четыре успешных группы, включая настоящий Save/reopen, компиляцию32768 действий,
Undo/Redo и полный откат переполнения. Связанная прежняя группа проверяет
все4/10 рецептов, пустые scopes/списки, параметры, backlinks и повреждённые
входы. Конечные коды и хеши находятся в `*-exit.json`, `source-count-proof.json`
и `delivery.json`.

Все41 проекта собираются без ошибок и предупреждений. EN/RU не менялись
(2881 ключ). Полный корпус, GUI, WPF и Computer Use не запускались.
I03 остаётся открыт для остальных направлений переноса сценариев;
[конечный перечень](OPEN_FUNCTIONS_RU.md) сохраняет их в общей цели.
