# Подписи переключателей сценариев EN/RU

Этап ScenarioChoiceCaptions-20261017 уточняет текст существующих списков,
не меняя числовые параметры, проверки, writer, компилятор или форматы.

Вместо общих Enable/Disable у системных сообщений, настроений существ,
голосового отсчёта, порталов и режима обзора показано конкретное действие.
Порталы явно открываются/закрываются; речь таймера названа голосовым отсчётом
оставшегося времени, а сообщения — игровыми. Исходный cinematic/CinemaScope
режим назван кинематографическим обзором. Значения0/1 остались прежними.

У ACTION_RUN нулевой вариант теперь означает прекращение принудительного
бега, как исходное «Arrêter de faire courir», а не отдельную команду ходьбы.
У ACTION_ATTACK варианты соответствуют исходным radio captions «существо
атакует / не атакует». При этом исходный форматировщик описаний сам использует
«agressive/passive»: существующие описания сохранены, это отдельный слой текста.
Русское Built для дверей/ловушек уточнено до «Построенные».

Source: Source/Includes/Strings.h, Resources/Editor.rc, Triggers_Actions.c
и Texts_Triggers.c. Для этих семи действий radio200 сохраняет1, radio201 —0.
Подписи и коды проверялись раздельно; текст не использован для вывода wire values.

Снимок100 native/DKM полей выбора до и после подтверждает тот же набор полей,
кодов и их порядок. Текст изменён в18 полях, включая две built-категории
каждого формата. В словарях EN/RU изменено по шесть существующих значений;
все остальные2597 и полный набор2603 ключей сохранены. Новых ключей нет.
Остальной src/tests буквально совпадает с предыдущей поставкой.
