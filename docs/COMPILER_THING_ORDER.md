# Порядок записей в игровом Things.kld

24 октября 2026, CompilerThingOrder-20261024. Исправлен порядок категорий при
компиляции DKM в игровой комплект. Это конкретное исправление открытого I02.

Исходный `Files_Editor.c` сохраняет DKM-списки в одном порядке, а
`Compiler_GenerateThingsFile` вызывает девять writers в другом. Наш compiler
раньше обходил физические записи DKM подряд. Кроме того, он записывал
генераторы эффектов до создаваемых записей сердец. Поэтому состав данных
мог совпадать, но физический порядок `Things.kld` отличался от исходного.

Теперь экспорт соблюдает последовательность source writers:

| Этап | Физические записи |
| --- | --- |
| Objects | Обычные предметы, GAMEOBJECT |
| MagicalObjects | Магические предметы, тоже GAMEOBJECT |
| Traps | GAMETRAP |
| Doors | GAMEDOOR |
| Creatures | GAMEHERO, GAMENEUTRAL, GAMEKEEPER в общем порядке списка существ |
| Areas | GAMEAREA |
| Gates | Сначала заданные геройские ворота; затем сердца игроков3–7 по номеру |
| Effects | GAMEEFFECT |
| Heros | GAMEBAND с фиксированными вложенными слотами |

Порядок внутри каждого исходного списка сохраняется. Существа не сортируются
по владельцу; обычные и магические предметы различаются до записи, хотя у
них одинаковый native signature C2. DKM, исходные карты и history не
переставляются. Порядок меняется только в новом игровом результате.

Тела записи полей сохранены буквально. Обработка областей вынесена в
локальную функцию с прежним телом: сначала она вызывается для областей и
ворот, затем создаются сердца, затем обрабатываются эффекты. Guard неизвестного
типа региона сохранён. Даты, базовые definitions, параметры сценариев и
правила first-object/first-gate lookup не переписаны.

## Доказательства и границы

Четыре новые группы дали 4 FAIL до исправления и 4 PASS после него:

- Перемешанные предметы/магические предметы/ловушки/двери/существа, два
  противоположных порядка вставки и цели13/16/17. Проверяется сохранение
  внутреннего порядка, включая разные layouts трёх владельцев существ.
- Перемешанные области/ворота/эффекты и отряд, те же порядки и версии.
- Полный смешанный набор с сердцем: сердце между воротами и эффектами.
- Реальный DKM Save/reopen, compile и запись ровно семи игровых файлов;
  после загрузки совпадает весь `Things.kld`, его count/size и поток записей.

Оракул читает физический поток с header56, signature и размером записи,
не использует сортировку compiler или порядок `Records()`. Проверяется
неизменность input bytes, dirty/revision, истории, счётчиков и уведомлений.

Из-за изменения адресов повторены связанные retention checks: все97 полных
area/band/player records, 1800 cells/711 event payloads, изменённые поля,
Undo/resize/identity cases, перенесённые gate/gem targets и шесть групп
DESTROYGATE/deletion/reuse. Все завершились ExitCode0 на том же Core, что
поставляется в App. Несвязанные успешные группы и весь корпус не повторялись.

Все41 проекта собраны без предупреждений и ошибок. Поставка и оба архива
обновлены с проверкой каждой записи. Source/Binaries/Fixtures, установленные
карты и2873 EN/RU literals сохранены. Логи, terminal codes, source call order
и проверка буквальной сохранности тел:
`artifacts/Evidence/CompilerThingOrder-20261024/`.

GUI/WPF, игра, audio и Computer Use не запускались. Исторические1840/63
не являются полным результатом текущей DLL. I02 остаётся открытым для
полной сверки полей/validator/version routes; metadata/player/AI не объявлены
закрытыми этим изменением. Прежние8 кодовых и23 ручные группы сохраняются.
