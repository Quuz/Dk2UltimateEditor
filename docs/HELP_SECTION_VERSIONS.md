## Руководство в приложении

«Справка → Руководство пользователя» открывает текущий USER_GUIDE_RU.md либо
USER_GUIDE_EN.md в отдельном немодальном окне. Установленная программа для
Markdown не требуется, shell/browser не запускается. В полной поставке
ищется Documentation рядом с App либо внутри каталога приложения; для сборки
из исходников — docs канонического проекта с DK2MapEditor.slnx.
Отсутствующее руководство не подменяется другим языком: показывается
локализованное сообщение о восстановлении полного комплекта документации.

Отображаются заголовки, абзацы, выделение/код и локальные Markdown-ссылки;
табличные строки и блоки кода сохраняются моноширинным текстом. Это встроенное
чтение, не редактор документации. Ссылки внутри каталога Documentation могут
открывать связанные страницы; внешние и отсутствующие цели остаются подписью.
После переключения EN/RU окно возвращается к основному руководству выбранного
языка. Повторная команда активирует уже открытое окно. Закрытие MainWindow
закрывает справку и снимает language subscription.

## Версии секций

«Справка → Версии секций проекта» показывает именно девять исходных категорий:

| Секция | Подпись файла | Source current |
| --- | --- | --- |
| Статистика | KSTS | 1 |
| Клетки | KMAP | 1 |
| Объекты | KTGS | 6 |
| Сведения о карте | KINF | 7 |
| Игроки | KPLY | 3 |
| Области/проходы/эффекты | KREC | 1 |
| Отряды | KMTH | 5 |
| Сценарии | KTRG | 3 |
| Глобальные переменные | KGBL | 1 |

Имена, порядок и версии сверены с Main_Debug.c/Version.h/Files.h. Исходные
SHA256 — artifacts/Evidence/HelpSectionVersions-20261018/source-scope.json.
Колонка «Вход» сканирует только реальные section headers MainFile контейнера,
без parsing records или угадывания layouts. «Рабочая» читает текущее DWORD
version из соответствующего NativeFile. «Эталон» — исходный current constant.
У отсутствующей исходной секции может быть только сгенерированный рабочий
буфер; такой случай явно подписан, не выдаётся за прочитанную секцию файла.
Уже выполненный upgrade можно увидеть как различие входной/рабочей версий.

Статус относится к рабочей версии: текущая, старее, новее, только рабочий
буфер, отсутствует, неверный header или дубликаты. Старая/новая версия сама
по себе не означает поддержку редактирования произвольного layout. Здесь
нет upgrade, ремонта, нового writer или обещания полной расшифровки байтов.
Для KWD/KLD значения входа/рабочих проектных секций помечены «не относится
к игровым файлам»; DWORD типа/заголовка native не выдаётся за версию DKM.

Просмотр не CommitFields, не меняет bytes/counters/history/save state,
выделение или буфер. Сводка обновляется после изменения/Undo и языка;
смена/закрытие документа закрывает прежнее окно и снимает subscriptions.
При живом карандаше, чужом owner и закрытом MainWindow команда отклоняется.
GUI-переход фокуса с начатого свойства остаётся M20, не доказан чистым scanner.

## Проверка и ручные шаги

Новый linked-App CLI --help-section-versions-only проверяет путевые правила
поставки/source build и EN/RU/missing, local link boundaries, девять rows,
generated-versus-input, native N/A, old/new/zero version, дубликаты, обрезанные
входные/рабочие headers и uint-length overflow. Чтение сохраняет точные
bytes/revision/history. Новое состояние заголовков создаётся только в частной
synthetic fixture, установленные карты не переписываются.
Сборка41 проектов и publish подтверждены exit records. Core неизменна;
полный корпус и прежние зелёные проверки не повторялись. Последний полный
1822/63 остаётся историческим результатом более ранней Core DiskProgress,
а не новым full этой сборки.

Подготовлены4 WPF native/project × EN/RU cases actual commands, modeless
guide/version windows, девять read-only rows, live language, no data/history
changes, pen guard, смена owner и закрытие окна. Они только скомпилированы;
Computer Use, WPF, renderer и игра не запускались.

Ручная приёмка M20/M21/M23:

1. Без карты открыть справку, прочитать начало RU/EN, перейти по локальной
   ссылке на CURRENT_STATUS. Проверить прокрутку, код и длинные таблицы.
2. Открыть DKM, затем сводку версий:9 строк и реальные входные/рабочие числа.
   При upgrade/Undo убедиться, что строка обновляется. Сам просмотр не создаёт
   шага Undo или изменения карты.
3. Открыть KWD: явная пометка неприменимости DKM-секций. Смена карты закрывает
   старую сводку. Повторить EN/RU, Escape/Close, фокус и DPI100/125/150.
4. На копии поставки временно убрать только руководство нужного языка:
   понятное сообщение вместо пустого окна/перехода на чужой язык; вернуть файл.

Два primary menu IDs снимаются из остатка I17. Следующая ограниченная работа
в этом пункте — таблицы собственных команд manager/scenario и исходных
keyboard callers; наличие70 входов не заменяет сверку их содержимого.
