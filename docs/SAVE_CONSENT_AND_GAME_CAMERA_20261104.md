## M03: Cancel предупреждения преобразования

Опубликованная App открыта с MCP на отдельной NativeInput внутри SaveConsentLive-20261104. Копия включает семь Maps-файлов, общий GlobalVariables и отдельный sidecar имён вне Maps: всего9файлов на диске. Это не9игровых map-файлов. Первый подготовительный assert ожидал8файлов и остановился до мутации; проверка исправлена на точное копирование всех реальных файлов и ровно7в Maps.

Через живой MCP подготовлена одна несохранённая правка клетки5,5:terrain2/owner3/variant1. Получен dirty=true, ровно1Undo,0Redo, normalSavePath=null. Записаны полный editing fingerprint, document revision/dirty/path, история и хеши исходного/скопированного комплекта.

Настоящий GUI RU125%: Ctrl+Shift+S → системный SaveAs → отдельный CancelledConversion.dkm → «Сохранить» → окно «Проверка сохранения карты». В нём видны предупреждение о sourceZIP и потере opaque collection tail. Нажата именно «Отмена» этого окна, а не отмена системного выбора пути. UIA-click системной кнопки сначала отказал из-за owned-window geometry; после активации/свежего снимка координатный click выполнился. Это ошибка управления тестом, не продуктовая ошибка.

Свежий MCP после Cancel подтвердил:

Затем отменена только подготовительная клетка: исходный clean fingerprint восстановлен. Прежний CameraSearchLive/AcceptedProject снова открыт; его полный fingerprint совпал с исходным, RU, dirty=false,0Undo/0Redo, без модального окна.
