# Создание региона из общего черновика

RegionCreationDraft-20261018. Конкретный подпункт **MC01 внутри I17 закрыт по
коду**. Ручная приёмка окна остаётся в M12/M20/M23. Остальные MC02–MC06 не
объявляются исправленными; I17 целиком остаётся открытым.

## Поведение

В блоке регионов кнопка «Добавить регион» открывает независимый черновик
области, прохода или генератора эффектов. Начальная геометрия берётся из
выделения, а без выделения — точка (0, 0). Проход всегда занимает одну клетку.
«Добавить из выделения» и «Добавить на карте» также открывают этот черновик;
они больше не создают запись с настройками по умолчанию сразу после выбора.

В одном окне доступны координаты, выбор геометрии на карте, выделение,
имя, описание, два цвета и вложенные параметры области/эффекта либо генерация
для проходов. Игровые native-записи не хранят редакторские имена, описания и
цвета: эти поля, как и в прежнем окне изменения, доступны в рабочем DKM.

До Add ничего не попадает в живую карту. Каждое принятое добавление публикует
полный регион и принятые вложенные операции одной транзакцией и одним Undo.
Счётчик исходных команд включает Add и реальные команды вложенной генерации;
отдельного искусственного Modify после Add нет.

Окно остаётся открытым. Следующее добавление сохраняет геометрию, описание,
цвета, флаги и параметры эффектов. Для каждой категории берётся свободный ID
1–255. Исходные стандартные имена Z/P/E с номером обновляются по правилу
первого символа и десятичного префикса; пользовательское имя сохраняется.
Принятая генерация не повторяется автоматически следующим Add.

Закрытие/Escape отменяет только ещё не добавленный черновик. Уже добавленные
регионы остаются в карте и отменяются обычным Undo. Два выбранных цвета
запоминаются отдельно по виду региона на время работы приложения, включая
закрытие без Add; остальные начальные параметры следующего нового окна
сбрасываются, как при исходном RectEx_Select. Новые настройки JSON не добавлены.

## Исходник и реализация

- Source/Sources/Things/Things_RectEx.c:43–129 — начальный контекст и цвета;
  722–815 — CopyMemory полного MAPRECTEX, выделение ID, Add, Undo, обновление
  стандартного имени, MapChanges. Source/Includes/RectEx.h:31–49 — packed fields.
- Source/Sources/Datas/Texts_Effects.c:10–12 — исходные префиксы Z/P/E.
- Core/Editing/RegionCreationSession.cs — полный независимый клон, существующий
  RegionPropertiesSession, preflight и атомарное применение. Старые методы
  AddMapRegion и ApplyEditorRegionProperties не переписаны.
- App/Editing/RegionPropertiesWindow.cs — общий интерфейс создания/изменения;
  App/Editing/EditorWorkspace.Regions.cs и EditorWorkspace.xaml — все три входа.

Внешнее изменение карты, Undo/Redo, подмена владельца, прямое изменение private
документа или bytes, закрытие и активный карандаш лишают черновик полномочий.
Незавершённый дочерний выбор запрещает Add. Перед применением проверяются и
версия параметров, и полный отпечаток живой карты/частного документа.
Для нового native-прохода тип/ориентация выводятся из окончательно выбранной
клетки; привязки обновляются через существующий MutateNativeGate.

Ошибка выделения памяти для истории полностью откатывает запись и сохраняет
черновик для повторной попытки. Уведомление об Undo доставляет существующий
общий обработчик приложения. Ошибка наблюдателя после состоявшегося commit
не оставляет повторно применимый Add.

## Проверка и ручная приёмка

Новый CLI `--region-creation-only` проверяет native/project × три вида,
literal полные buffers, исходные defaults, переименование, повторный Add,
save/reopen, вложенную генерацию, единую историю, stale/foreign/raw/closed/
active-edit guards, observer failure и управляемый отказ памяти после записи
до публикации истории. Точные результаты сборки, полного прогона и поставки
указаны в CURRENT_STATUS и artifacts/Evidence/RegionCreationDraft-20261018.

WPF `--region-creation-only` подготовлен и только скомпилирован: EN/RU × два
формата, новые и прежние кнопки, сохранение черновика при смене языка,
повторный Add, частный map pick, Cancel, Undo и смена документа. Редактор,
renderer, Computer Use и игра агентом не запускались.

Вручную в текущей сборке:

1. Выбрать вид региона и нажать «Добавить регион». Задать геометрию и вложенные
   параметры; в DKM также имя/описание/цвета. До Add закрыть окно: карта прежняя.
2. Повторить, нажать Add дважды. Проверить сохранённые параметры, разные ID,
   стандартное и собственное имя. Закрыть окно; два Undo удаляют записи по одной.
3. Проверить выбор геометрии на карте и Escape, а для прохода — вложенную
   генерацию с общим закрытием до Add и с принятым Add. Проверить EN/RU и DPI.
4. Скомпилировать ровно семь файлов под именем DK2Preview_6a88240eaf814f78,
   открыть в официальном редакторе и запустить
   `DKII-DX.exe -q -level DK2Preview_6a88240eaf814f78`.

Действующее согласованное восстановление порядка/состояния при Undo удаления
регионов не изменено: [REGION_UNDO_POLICY](REGION_UNDO_POLICY.md).
