Raw сохранение не означает разрешения угадывать владельца/граф при
семантической операции. Явные ID-поля сохраняют собственные source sentinel
и namespace rules. Предупреждение missing/duplicate entity reference не
превращается в автоматическую перенумерацию. Для непрозрачных layouts действует
I04: bounded raw retention и named Error/Loss+source archive policies.
Физическая однозначность требуется там, где команда выбирает владельца/target.
