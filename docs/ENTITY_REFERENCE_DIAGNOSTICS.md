# Проверка ссылок на объекты

Дополнение24 октября: [I06: ссылки на определения](I06_CODE_CLOSURE.md)
реализует отдельные информационные DK2N039/040. Ниже описаны identity-связи
DK2N026–028 и исторические проверки12 октября; это разные каталоги и codes.

Реализация identity-проверок: `EntityReferenceDiagnostics.Validate`, подключённая к
`NativeMapValidator`. Работает для native KWD/KLD и поддержанных DKM-записей.
Результаты — предупреждения, не автоматическое исправление и не запрет
побайтового сохранения импортированных данных.

| Код | Что установлено |
|---|---|
| DK2N026 | Поддержанная ссылка указывает на отсутствующую зону, отряд, проход или генератор эффектов |
| DK2N027 | Поддержанная ссылка соответствует нескольким записям одной категории с одинаковым ID |
| DK2N028 | Несколько записей одной категории имеют одинаковый ID; предупреждение у каждой записи |

Интерфейс показывает общее описание EN/RU и техническую подробность с категорией,
именем поля и смещением. Одинаковые числа в разных категориях не являются
конфликтом. Например, зона 7 и генератор эффектов 7 имеют независимые ID.

## Какие ссылки проверяются

`EntityReferences` задаёт проверенные идентификаторы зон, отрядов, генераторов и
проектных проходов; successor зоны/патруля, цель героя, принадлежность native
героя отряду, активные участники отрядов, проектные привязки сценариев. Каталог
14 сценарных привязок извлекается из исходных функций сохранения параметров
`Triggers_ActionDlgParamsStore` / `Triggers_TriggerDlgParamsStore`.

Ноль пропускается только там, где исходная схема обозначает отсутствие ссылки.
Отряд 0 действителен. Значение 255 означает отсутствие отряда только у отдельного
native героя. Native DESTROYGATE хранит координаты, поэтому они не проверяются как
проектный ID прохода. Native GAMEGATE не имеет этой уникальной проектной identity.

Отряд содержит 16 мест. Проверяется непрерывная активная часть до первого
неактивного участника: native creature/behavior не равны нулю; в DKM используется
isvalid. Неиспользуемый хвост сохраняется и не создаёт ложных ссылок. При
`includeScripts=false` пропускаются события и проектные сценарные привязки, как
требует экспорт MAP без сценариев.

## Границы доказательства

Если неизвестная native запись Things или непрозрачная будущая проектная секция
может содержать неразобранную identity, отсутствие такой цели не утверждается.
Уже доказанные повторные IDs и неоднозначные ссылки остаются предупреждениями.
Это не означает полного декодирования неизвестных секций.

DK2N026–028 не проверяют игровые definition ID. Поддержанные поля теперь
охвачены отдельной [диагностикой I06](I06_CODE_CLOSURE.md); границы непрозрачных
внутренних ссылок и пользовательских игровых каталогов описаны там.

## Выполненные проверки

12 октября 2026: `--entity-diagnostics-only` завершился с exit 0. Независимые
native/project fixtures проверяют категории, нулевые/255 sentinel, отсутствующую
цель, повторные IDs, активные/неактивные места, один сценарный effect operand,
отключение сценариев, сохранение/повторное открытие и непрозрачную native запись.
Проверяется неизменность каждого байта, revision, dirty, Undo/Redo и отсутствие
уведомлений. Это не отдельная исчерпывающая проверка всех 14 сценарных типов.

Полный CLI regression текущей DLL: 1796 passes / 63 failures, terminal exit 1.
Все 63 сообщения совпадают с предыдущим отчётом в полном исходном порядке;
прежние passes сохранены. Полный corpus остаётся неуспешным.
Все 41 проекта собраны без предупреждений/ошибок. Фокусные official/record/gate/
payload проверки завершились с exit 0. Доказательства:
`artifacts/Evidence/EntityDiagnostics-20261012`.
Физическая EN/RU/game проверка последней сборки пользователем ещё не подтверждена.
