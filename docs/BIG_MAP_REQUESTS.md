# Общий вопрос о большой карте

Этап BigMapRequests-20261017. Основной проект остаётся в `src/`, решение
`DK2MapEditor.slnx`; источники Source/Binaries и установленные карты не меняются.

## Поведение редактора

«Создать» в форме новой карты доступно для допустимых параметров. Если нужен
вопрос о размере, он появляется после нажатия; прежний обязательный флажок
в форме убран. «Нет», Escape или закрытие вопроса возвращают к настройкам,
не создавая карту. При изменении размера в свойствах действует тот же вопрос.
Подтверждение обрезки содержимого остаётся отдельным и не запоминается этим
флажком.

«Да» — ответ по умолчанию. «Запомнить Да» выключает «Нет» и запоминается
только после принятия «Да», а не после установки флажка или закрытия окна.
Этот ответ общий для создания и изменения размера, переживает Undo/Redo,
смену документа и отмену родительской формы, но не новый запуск редактора.
«Вернуть вопрос о большой карте» в обеих формах сбрасывает только этот ответ.

Запрос разрешает продолжить операцию, сам он не создаёт и не изменяет карту.
Новая карта строится после проверки актуальности принятых настроек. Изменение
карты выполняется общим Apply свойств, со своей проверкой обрезки и прежним
полным Undo. Параметры, изменённые после открытия вопроса, не получают старое
разрешение. Возврат к прежним значениям после редактирования тоже не оживляет
старый вопрос. Смена документа/закрытие вызывающей формы отменяют его.

Переключение EN/RU в новой карте сохраняет прежний набор значений и переводит
открытый вопрос. В свойствах сохранён прежний контракт: изменение языка
увеличивает revision формы и требует нового Apply, вместо применения старого
подтверждения. Ни один случай не разрешает старый план автоматически.

## Что подтверждает исходник

`Map_NewReset` в `Source/Sources/Map/Map_Setup.c` и `Properties_MapReset`
в `Source/Sources/Properties/Map/Properties_Map_Global.c` используют один
REQUEST_BIGMAP =0x20 в Config.RequestsFlags. Оба проверяют строго
`Width*Height > 120*120`, выбирают default Yes, MBF_AUTOREPLY,
MB_ICONINFORMATION и MBP_FOLLOWMOUSE. «Нет» оставляет родительский диалог
открытым. В свойствах вопрос нужен только при изменении размеров; уже
большая карта с прежними размерами не задаёт его повторно.

Source UI ограничивает новую карту300 клетками по стороне. Существующее
современное расширение до1024 и дополнительный new-map вопрос при стороне
свыше300 сохранены. Это отдельное расширение; его не выдают за исходный
порог площади. На исходном диапазоне обе команды используют общий порог
14400 клеток. Площадь ровно14400 не превышает порог.

Вопрос использует оригинальный Information32.ico, а не warning/question icon.
При показе он размещается около указателя с ограничением рабочей областью
монитора; без доступного native handle остаётся CenterOwner. Реальные
keyboard/mouse/audio/multimonitor/DPI свойства этого поведения требуют
ручной приёмки.

## Реализация

EditorLargeMapPolicy хранит только общий session bit0x20 через
EditorRequestPreferences и использует его single-active lease с запросами
объектов/регионов/сценариев. BeginNew фиксирует immutable NewMapOptions и
проверку revision/контекста формы. BeginResize связан с существующим
MapPropertiesPlan, live/working fingerprints, revision и закрытием session;
активная транзакция или pen stroke исходного/рабочего документа не допускаются.

EditorLargeMapRequest не требует фиктивного документа для New Map и не
реализует контракт документного удаления. Accept меняет только preference
и состояние запроса. No/Dispose не запоминают ответ. Callback, сбросивший
или подменивший свой запрос во время проверки, не получает approval и не
крадёт чужой lease. Сброс0x20 не меняет остальные request bits.

MainWindow передаёт существующий EditorWorkspace.RequestPreferences новой
карте; тот же объект получает MapPropertiesWindow. Child working workspace
не подменяет этот store. LargeMapWarningWindow показывает original info icon,
переводы, размер, Yes/No и remember. Старый LargeMapPrompt delegate в свойствах
сохранён для существующих подготовленных проверок и проходит тот же guarded
request; штатный путь использует новое окно. CropPrompt остаётся прежним.

Поля карты, DKM/native metadata, компилятор, семифайловый формат и game-level
launcher не менялись. Preferences не пишутся в карту или AppSettings.
