# Оригинальные изображения в глобальных определениях

13 октября 2026. Код находится в едином `src/`; ресурсы берутся из сохранённого
`Source/`, дополнительные копии исходных BMP не создаются.

## Поведение редактора

В общем каталоге определений, пятистраничном окне элементов и девятистраничном
окне существ строки теперь содержат оригинальные изображения размером 32×32.
Охват: 38 типов территории, 24 комнаты, 8 дверей, 15 ловушек, 13 заклинаний
Хранителя, 45 существ и 41 заклинание существ — всего 184 строки. Восемь страниц
свойств существ используют один каталог; страница заклинаний существ — свой.

В параметрах выстрелов ловушек, заклинаний Хранителя (оба слота) и заклинаний
существ также восстановлены изображения. Формы 2/3 показывают 45 существ,
форма 4 — 116 объектов. Уровни 1–10 остаются числовым списком. Неизвестное
импортированное значение сохраняет текстовую строку без придуманной иконки.

Выбор строки, поиск, подписи EN/RU, приватные значения, Cancel, общий Apply,
Undo и экспорт карты работают через прежние команды. Изображения не добавляют
данных в KWD/KLD/DKM. Игровой экспорт по-прежнему содержит семь файлов.

## Связь с исходником

`Datas_GlobalVariables.c` содержит отдельные GTerrains/GRooms/GDoors/GTraps/
GSpells/GCreatures/GCrSpellsLst. Третье поле ELEMENT — номер графического
ресурса, отдельный от ID игры и порядкового номера строки. Ранее текущий парсер
сохранял для него ноль; теперь сохраняет исходное значение.

`Editor.rc` связывает номера с BMP, а `Misc_CreateImageList` загружает их с
заданными 32×32. Исходные файлы бывают 32×32, 48×48 и 64×64. App загружает
сохранённый BMP, масштабирует до 32×32, замораживает BitmapSource и кеширует.
Побайтовая идентичность BMP не доказывает совпадение алгоритмов масштабирования
WPF/Win32, выделения строки или отображения при другом DPI.

`Properties_Global_Functions.c` явно создаёт OptionsImages из GCreatures для
форм 2/3 и из Objects для формы 4. Текущие списки следуют этим каталогам,
а не сокращённому списку размещаемых существ или случайному соответствию ID.

`DefinitionImages.props` добавляет 43 ранее не встроенных ресурса: 482, 504,
2301–2341. Остальные берутся из уже встроенных ресурсов App. Исходные номера
1214/1215 ссылаются на тот же Prince.BMP, что 1213; 1306/1300 и 1412/1400
также являются ссылками на одинаковые физические файлы. Эти связи проверены
по RC. Общий BMP встраивается один раз, исходные номера в Core сохраняются.
Первоначальная попытка встроить все номера отдельно дала NETSDK1022; исправлено
переиспользованием файлов, исходный журнал ошибки сохранён.

## Доказательства и ограничения

Независимый снимок `GlobalDefinitionImagesSource.json` содержит ID, порядок,
символ, номер ресурса, путь исходного BMP, размеры и SHA256 для 184 строк и
116 объектов. Validation сравнивает его с текущими каталогами Core и читает
байты EmbeddedResource непосредственно из собранного managed PE App.
App, WPF, декодирование изображения, окна и рендер при этом не исполняются.

`--definition-images-only` выполняет эту проверку вместе с существующими
проверками глобальных значений, сбросов и Undo. Журналы сборки, проверки,
семифайлового экспорта, полного корпуса и поставки находятся в
`artifacts/Evidence/GlobalDefinitionImages-20261013`. Актуальные результаты
приведены в [CURRENT_STATUS](CURRENT_STATUS.md).

## Ручная проверка

1. Откройте текущую сборку и рабочую копию тестовой карты. На вкладке глобальных
   определений раскройте списки семи семейств: рядом с названиями должны быть
   изображения. Проверьте первую и последнюю строку каждого списка.
2. Откройте общие свойства элементов и существ. Проверьте изображения при смене
   страниц; у заклинаний существ картинки должны отличаться от списка существ.
3. В параметрах выстрелов проверьте форму выбора существа с количеством, форму
   существа с уровнем и форму объекта. Изображения нужны у существ/объектов;
   уровни остаются числами. Повторите для ловушки, обоих слотов заклинания
   Хранителя и заклинания существа.
4. Переключите EN/RU. Проверьте раскрытый список, выбранную строку, читаемость
   названий и отсутствие обрезания изображения при своём DPI. Закройте окна
   через Cancel: простая навигация не должна менять карту или создавать Undo.

Сравнение изображений и выделения с исходным GUI остаётся ручным. Это исправление
не закрывает остальные требования [FEATURE_PARITY](FEATURE_PARITY.md).
