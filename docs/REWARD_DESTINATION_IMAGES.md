# Награды и значки целей сценария / Reward and destination images

RewardDestinationImages-20261021, 21 октября 2026.

В шести списках наград уровня устранён фиксированный размер32×32. Исходный
`Properties_Map_Options.c` задаёт квадрат `Font.FontHeight+2`, причём FontHeight
в `Misc_Font.c` равен tmHeight+tmExternalLeading. Наш WPF-контрол берёт высоту
строки текущего FontFamily/FontSize, округляет её вверх до физического пикселя
и добавляет два физических пикселя. Результат переводится в DIP текущего
монитора; при смене DPI повторяется измерение. Это перенос правила размера
на текущий шрифт WPF, а не доказательство идентичности метрик GDI/WPF.

BMP читается из исходного embedded resource без промежуточного32×32 и
масштабируется при показе. Неизменяемые оригиналы кэшируются. Пункт0 «Нет»
оставляет пустой квадрат и отступ, как исходное owner-draw окно. Прежние48
наград, их IDs, порядок, EN/RU подписи, неизвестные значения, независимый
черновик и Apply/Cancel не изменены.

Списки владельцев, мест переноса и целей сценария получили TrImages16×16:
игрок202, существо/участник отряда203, область204, отряд205, дверь206,
предмет207, магический предмет208, уровень209, условие200, действие201.
Это значки категорий исходного `Triggers_Select`, отдельные от32×32 картинок
в мастере создания точки. Для пустой цели0 значок отсутствует. Перенос строк
и tooltip сохранены; текст переносится в пределах300 DIP плюс20 DIP для
значка. Состав списков, выбранные IDs, сортировка и команды прежние.

Независимый source capture содержит48 пар rewardID/BMP,9 scope-пар и54
идентичности BMP вместе с исходными200/201. Проверка без WPF сверяет порядок,
границы размера при100/125/150/200%, ошибочные аргументы, native/DKM назначения
и полные bytes/history до/после чтения метаданных. Embedded BMP проверяются
через PEReader; сборка приложения при этом не загружается и не запускается.
Подготовлены четыре WPF-suite EN/RU×native/DKM; они только компилируются.

Ручная проверка: откройте свойства уровня, посмотрите шесть наград при своём
масштабе Windows. «Нет» должен иметь пустой отступ той же ширины, значки —
соразмерны строке текста. Откройте сценарий: у владельцев, мест переноса и
целей должны быть маленькие значки категорий, длинный текст должен
переноситься. Переключите EN/RU и проверьте сохранение выбранных значений.
Для этого осмотра сохранять или менять карту не требуется.

GUI, popup, клавиатура, физический DPI и сравнение с оригинальным окном
остаются ручной приёмкой. Этот этап не закрывает весь I13: ещё предстоит
сверка Hero-band selector/preview, imported elite presentation и оставшихся
object/custom/dynamic captions. Общий остаток14 кодовых пунктов и23 ручные
группы сохраняется. Исторический полный corpus1840/63 не повторялся.
