## Когда завершаем эту приёмку

У всех23 групп должен быть фактический итог с датой, выполненными подпунктами
и непройденными случаями. Найденные ошибки исправляются с ручным повтором
затронутого маршрута. Отсутствие условий не превращается в автоматический PASS.
Перед завершением отдельно перечисляем оставшиеся непроверенные условия,
чтобы они не исчезли из учёта.
