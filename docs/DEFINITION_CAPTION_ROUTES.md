# Контекстные подписи определений / Definition caption routes

DefinitionCaptionRoutes-20261021, 21 октября 2026.

Исправлена потеря контекста между специальным окном определения, общей
таблицей и сырыми свойствами записи. Ранее уточнённые подписи существовали
в специальных окнах, но часть остальных маршрутов продолжала использовать
общий `Field.*`: изменение здоровья местности называлось Damage, стоимость
тайла — Cost, эффект разрушения двери/ловушки — Death Effect. Контекстные
38 атрибутов существа и название creature spell также терялись при открытии
сырых свойств. Теперь эти44 установленных значения используют общие правила.

Дополнительно общая таблица и сырые свойства существа получают13 существующих
подписей из окна параметров: тип/процент четырёх сопротивлений, два melee swipe,
два special swipe и spell swipe. Поле `Creatures.Spell` означает отображение
удара заклинанием из GCrSwipes, поэтому общее «Spell ID» здесь не применяется.
Названия в других семействах сохраняют свой контекст. Новых переводов или
догадок о неизвестных полях не добавлено; все2846 EN/RU ресурса прежние.

Для параметров выстрела учитываются исходные66 GShots rows и форма дочернего
окна: сила/изменение/увеличение/длительность/уменьшение/радиус, существо и
количество/уровень, предмет и золото. Основной и улучшенный выстрел различаются
в подписи. Источник типа — ShotType у ловушки/заклинания, Shot у creature spell,
UpgShotType у улучшенного выстрела. Неактивный второй параметр формы1 и форма255
не получают выдуманной активной семантики. Неизвестный тип сохраняет общий
FieldLabel. TriggerData типов1/2 получает область воздействия/необходимое
давление; остальные значения сохраняют общую подпись.

Таблица определения использует сохранённые значения; при их отсутствии —
значения исходного default catalogue. Сырые свойства определяют семейство
только по подтверждённым категории, сигнатуре, версии и размеру записи.
Неподходящие/повреждённые записи, неизвестные поля и индексированные opaque
данные остаются на прежнем маршруте FieldLabel с сохранением аннотаций.
Раздел эффектов двери/ловушки теперь тоже показывает «эффект разрушения».

Изменены только правила подписи и их вызовы. Значения ячеек, default/raw
колонки, выбранные записи, черновики, Apply/Cancel, обработчики изменений,
счётчики, Undo и Core прежние. Это не изменение схемы или семифайлового экспорта.

Фокусная проверка без WPF сверяет44 статических контекста,13 slot labels,
66 исходных форм и396 активных parameter routes.114 настоящих полей native/DKM
и1056 связей типа/слота проверяются на изолированных буферах14 раскладок.
Проверены наличие EN/RU ключей, форматирование, default-value route и
неизменность полных bytes/history при просмотре новой native/DKM карты.
Таблицы ожидаемых значений сняты из исходников; они включены в Source ZIP,
генератор evidence для сборки проекта не нужен.

Ручной осмотр: в разделе определений откройте местность и посмотрите Damage
и MaxManaGain, затем стоимость комнаты и эффект двери/ловушки. Откройте
«Свойства» существующего сохранённого определения: подписи должны совпадать
по смыслу со специальным окном. У существа посмотрите сопротивления и Spell;
у определения с ненулевым типом выстрела — его параметры, включая улучшенный
вариант. Переключите EN/RU. Для осмотра изменять или сохранять карту не требуется.
Физические окна/DPI/клавиатура в этом этапе не запускались и не приняты.
