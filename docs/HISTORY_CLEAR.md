# Очистка истории с сохранением Undo

HistoryClear-20261018, конкретная команда IDM_UNDOFREE внутри I17.
Исходный Window_Command вызывает Undo_DestroyAllEntries; Map_Undo.c:942
освобождает записи и обновляет меню. Config.UndoLevels, MapChanges и карта
этим вызовом не обнуляются. Прежний обход через глубину0 отключал последующее
накопление Undo, поэтому не заменял эту команду.

В «Правка» добавлена EN/RU команда «Очистить историю» / Clear history.
Она доступна, когда у текущего документа есть Undo или Redo. Новый
NativeMapDocument.ClearHistory очищает оба современных стека и стоимость
снимков. Сохраняются bytes карты, ChangeCount, EditorChangeCount, EditRevision,
HasChanges/save baseline и HistoryDepth. Следующее редактирование создаёт
обычный Undo при прежней ненулевой глубине; уже отброшенные шаги недоступны.
При глубине0 команда не включает tracking. Пустая история — no-op.

Очистка не является undoable редактированием: нет нового шага, изменения
настроек JSON или накопительной статистики карты. При изменении истории
выдаётся один HistoryChanged, без Changed. Ошибка внешнего наблюдателя
после этого уведомления не отменяет уже выполненную очистку.

Core запрещает очистку внутри транзакции и незавершённого карандаша.
CanClearHistory учитывает оба запрета. MainWindow проверяет актуального
владельца workspace и lifetime; закрытое окно или подменённый документ не
могут очистить историю другого документа. Меню обновляется через существующий
HistoryChanged, включая начало и завершение штриха. Handler не вызывает
CommitFields и сам не принимает незавершённые значения PropertyGrid;
фактическое поведение перехода фокуса остаётся ручной приёмкой.

## Проверка

Новый CLI focus --history-clear-only проверяет native и DKM: чистое состояние,
mixed Undo/Redo, exact live bytes/counters/dirty/revision/depth, отказ внутри
транзакции с полным откатом, отсутствие лишних уведомлений, прежний immutable
metadata snapshot, будущий Undo до границы очистки, redo-only, активный штрих,
глубину0 и исключение внешнего наблюдателя после выполненной очистки.
Также проверена локальная принадлежность Undo менеджеру: старые шаги после
очистки недоступны, новый шаг отменяется до новой границы.
Успешный результат — в artifacts/Evidence/HistoryClear-20261018/focus-02.log
и exit record. Первый focus ошибочно считал CreateNewMap чистой картой;
проверка исправлена на save/reload во временной директории. Исходный failure
сохранён; код ClearHistory из-за него не менялся.

Подготовлены четыре WPF cases EN/RU × native/project: реальный MenuItem,
доступность, настройки depth, выделение/буфер, будущий Undo, active pen,
live language и чужой/закрытый owner. Они только скомпилированы. GUI, игра,
Computer Use и renderer не запускались.

В Core добавлены только отдельный метод и CanClearHistory; существующие
SetHistoryDepth/Undo/Redo/Edit/reader/writer не переписаны. Полный корпус
не повторялся для additive API: новый focus непосредственно проверяет
затронутые границы. Последний фактический full1822/63 — DiskProgress на
Core73ecea159e7d4a6d298307ad44d9c20a873f4650335e5d196db6542665b5f38b;
это исторический результат, не новый full на изменённой Core.
Следующая обоснованная общая интеграция должна учитывать этот новый check
и отдельно добавленный ранее manager-list check; счётчик full не увеличивается
по одному лишь добавлению проверки.

## Ручная приёмка M10/M20/M23

1. Сделать два изменения, отменить одно. Выбрать «Правка → Очистить историю»:
   вид карты прежний, Undo/Redo недоступны, счётчик изменений сохранён.
2. Сделать новое изменение и Ctrl+Z: отменяется только оно. Настроенная глубина
   истории остаётся прежней; команда очистки её не меняет.
3. Проверить EN/RU, недоступность при пустой истории и во время drag-штриха.
   На начатом поле PropertyGrid проверить переход к меню без скрытого принятия
   неверного значения и сохранение выбранного поля/выделения/буфера.

IDM_UNDOFREE снимается из остатка главных команд I17. Остальные семь IDs,
внутренние callbacks менеджеров и shortcut completeness остаются открыты;
вся цель этим шагом не завершена.
