# Просмотр отрядов / Hero-band display

HeroBandDisplay-20261021, 21 октября 2026.

В категории менеджера отрядов каждая запись теперь показывает свой состав:
заголовок с исходным CrIcons[2]1212 и вложенные информационные строки32×32.
Это соответствует назначению `Heros_SelectBuildList`: физический порядок
отрядов и участников, отдельные записи даже при одинаковых IDs, остановка
на первом неактивном слоте. Вложенные строки не получают фокус и не принимают
мышь; выбор, изменение и удаление относятся к родительскому отряду. Фильтр
по имени и текущие команды не изменены. Остальные категории записей сохраняют
текстовое представление без добавленных значков.

Состав менеджера и отдельного окна использует все45 имён:16 обычных существ,
13 элитных и16 героев. Список создания по-прежнему содержит32 обычных/геройских
варианта. Импортированное элитное существо в окне участника получает одну
дополнительную выбранную строку с настоящим EN/RU именем и изображением.
Его ID не заменяется. Неизвестный ID остаётся числом и явно обозначенным
импортированным значением; используется прежний безопасный запасной значок.

В старом `Heros_ModifySetDispInfo` цикл элитных существ пропущен: имя/значок
импортированной элиты там не определены. Этот дефект не переносится. Сам
исходный selector обрабатывает элиту, поэтому для просмотра выбран полный
известный каталог; возможность создать элиту таким изменением не добавлена.

Строки показывают уровень, противника, цель с номером области для23 и полный
исходный индикатор `-----/----`: роль* или+, T/A/H/L и S/J/M/C. При одновременно
заданных битах2/4 знак+ имеет приоритет внутри индикатора, как в исходнике;
бит2 по-прежнему отдельно обозначает лидера. Неизвестные биты сохраняются
в данных и не получают выдуманных значений. Неизвестная цель показывается
с числовым кодом, а не техническим ключом локализации.

`ReadHeroBandDisplay` возвращает неизменяемый снимок полей без edit session,
назначения сценарных IDs, Undo или изменения карты. Для DKM1–4 существующий
source reader конвертирует только временный буфер секции; берётся физический
порядковый номер записи, а не ID. Для DKM5 и native читаются текущие поля.
Просмотр останавливается на первом пустом месте, не пытаясь исправлять хвост.
Неподтверждённая/повреждённая раскладка не получает выдуманного состава;
существующие поля/диагностика и явная команда изменения остаются доступны.

При конечной сверке соседних изображений подтверждён отдельный дефект:
`Things_ManagerGetImage` возвращает0 из общего списка для неизвестного ID.
Поэтому неизвестные дверь/ловушка получают1301, предмет/особый предмет1508,
существо1115. Раньше менеджер переиспользовал запасные значки окон выбора
и показывал неизвестную ловушку как1409, предмет как2007. Исправлен только
`ObjectManagerWindow.ManagerRow.Icon`; общий chooser helper прежний.

Проверка без интерфейса:45 известных имён/изображений в EN/RU, неизменные32
варианта создания,1024 сочетания исходных флагов плюс неизвестные биты,
native/DKM полные поля и остановка на пустом слоте, snapshot independence,
пять DKM-версий с повторными IDs и исходными defaults,34 BMP identity в PE
(32 отрядов и два запасных значка менеджера),
209 manager catalogue routes и пять запасных значков в двух версиях игры.
Полные bytes, счётчики и история до/после чтения сравниваются. Подготовлены
четыре WPF-suite, но разрешён только их compile: приложение не запускалось.

Ручная проверка: в свойствах выберите категорию «Отряды» и посмотрите состав
под заголовками. Нажатие на информационную строку должно выбирать родительский
отряд. Откройте изменение: имя элитного участника должно содержать «элита» /
«Elite», остальные поля и флаги должны быть видны. Переключите EN/RU, проверьте
сохранение выбранного участника и отображение длинных строк при своём DPI.
Закройте окна через Cancel; для осмотра сохранять карту не требуется.

Этот этап закрывает перечисленные подключения изображений отрядов и
конкретные запасные значки менеджера.81-call matrix остаётся картой маршрутов,
а не81 выполненной визуальной проверкой. Физические GUI/DPI/game-проверки
и остальные object/custom/dynamic captions I13 остаются открытыми. Общий
остаток14 кодовых пунктов и23 ручные группы не переименовывается в процент.
