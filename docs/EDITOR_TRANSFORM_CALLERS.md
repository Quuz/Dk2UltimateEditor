# Поворот и отражение выделения

25 октября: [I09 закрыт по коду](I09_CODE_CLOSURE.md). Terrain variant переносится буквально; отдельный gate-region anchor неподвижен. При DKM compile ориентация следует текущим south/east neighbours; native direct bytes и source-retention имеют отдельную явную политику. Физическая приёмка остаётся в [списке](OPEN_FUNCTIONS_RU.md).
14 октября 2026. Команды рабочего окна вызывают `TransformEditorSelection`.
В исходном редакторе принятый поворот или отражение создаёт один шаг Undo
и увеличивает счётчик изменений на 1 + K, где K — число перемещаемых объектов.
Если объектов нет, увеличение равно 1, даже если видимый результат остаётся
прежним. Текущий редактор повторяет это поведение. Базовый метод
`TransformSelection` сохраняет прежнюю обработку равного результата.

## Правила исходного редактора

В Source/Sources/Map/Map_Select.c функции Select_Rotate и Select_Symmetry
создают запись истории до обработки клеток и выполняют MapChanges++ один раз.
Каждая команда вызывает Things_RemoveAtMapPosEx для пяти списков объектов.
Этот обработчик увеличивает MapChanges за каждый объект перед его повторным
размещением. Повторное размещение не добавляет увеличения. Объекты у защищённого
края тоже учитываются: проверка защиты клеток выполняется позже. Статистика
рисования не меняется. Предыдущая сверка учитывала только верхнюю функцию
и ошибочно утверждала, что объекты не добавляют увеличений; это исправлено
в TransformRemoval-20261014.
Поворот требует квадрат, включая 1×1. Отражение требует не менее двух клеток
по изменяемой оси. Исходный параметр Vertical=true изменяет X, false — Y.

В таблице N — сторона квадрата в клетках, K — число перемещаемых объектов.

| Команда | Преобразование локальной точки | Счётчик / шаг Undo |
| --- | --- | --- |
| По часовой стрелке | (N−1−y, x) | 1 + K / 1 |
| Против часовой стрелки | (y, N−1−x) | 1 + K / 1 |
| Отразить по X | (W−1−x, y) | 1 + K / 1 |
| Отразить по Y | (x, H−1−y) | 1 + K / 1 |
| Отказ по размеру | Данные не записываются | 0 / 0 |

## Текущая реализация

TransformEditorSelection выполняет прежний алгоритм внутри EditEditorDrawing
и сообщает об одной принятой операции плюс K удалений из исходного обработчика.
Сохраняются ограничения размеров,
защита клеток, физические объекты, их идентификаторы и связи со сценариями,
различие локальных и внешних координат. Undo возвращает данные и счётчик.

Рабочее окно проверяет выделение и размер перед применением. Команда создания
повёрнутой копии меняет буфер копирования, не карту. Обычные преобразования
и Undo сохраняют внешний буфер. Защита краевых клеток не запрещает перемещение
объектов через край. Отряды и глобальные области не становятся размещёнными
объектами. Подробная геометрия: [SELECTION_TRANSFORMS](SELECTION_TRANSFORMS.md).

## Проверки и их границы

Снимок двух исходных функций и вызываемого обработчика удаления связан
с хешами Map_Select.c и Things_Functions.c. Модели проверяют
32 сочетания: native/project × четыре преобразования × равный/неравный результат
× край/внутренняя часть карты. Проверяются перестановки клеток и координат,
защита, идентификаторы объектов и событий, один шаг Undo/Redo, счётчик 1 + N,
уведомления и неизменная статистика рисования. Отдельно проверены отказы
по размеру, границам и вложенной операции, квадрат 1×1, переполнение счётчика,
нулевая глубина истории и полные снимки данных до/после операции.

Проверки входят в существующую группу выделения Validation. Дополненные
проверки четырёх команд рабочего окна с объектами у защищённого края,
сохранения буфера, отказов и сообщений
EN/RU скомпилированы. WPF, редактор и игра не запускались. Результаты сборки
и полного корпуса: [CURRENT_STATUS](CURRENT_STATUS.md). Доказательства:
artifacts/Evidence/TransformRemoval-20261014. Дополнительно проходят 80 сочетаний
с 0/1/3/5/13 объектами, пятью исходными семействами и тремя native видами существ.
Объект вне выделения и область внутри выделения не учитываются и не перемещаются.

## Ручные шаги

1. Выделите квадрат 2×2 одинаковых клеток без объектов. Выполните оба поворота
   и оба отражения, отменяя каждую команду. Даже при одинаковом виде должен
   появляться один шаг Undo; отмена должна возвращать счётчик.
2. Повторите на неодинаковом квадрате с существом и связанным сценарием.
   Проверьте направление, положение существа и связь со сценарием, включая край.
   С одним существом счётчик увеличивается на 2; с N объектами — на 1 + N.
   Количество шагов Undo остаётся равным 1.
3. Попробуйте повернуть прямоугольник и отразить выделение шириной/высотой 1
   по соответствующей оси. Должно появиться пояснение без записи в историю.
   Проверьте сообщение на русском и английском.
4. Проверьте сохранение ранее скопированного буфера. Отдельная команда
   повёрнутой копии должна менять буфер, оставляя карту прежней.

Для игры используется только DK2Preview_6a88240eaf814f78 из семи файлов:
`DKII-DX.exe -q -level DK2Preview_6a88240eaf814f78`.
Остальные требования истории, обработчиков, исторических форматов и ручной
проверки интерфейса/игры остаются в [FEATURE_PARITY](FEATURE_PARITY.md).
