# Global definition editing and source resets

The tenth workspace tab provides seven families and all 184 named source definitions: 38 terrains, 24 rooms, 8 doors, 15 traps, 13 keeper spells, 45 creatures and 41 creature spells. Names, field labels, search, notices and commands are English/Russian. Creature-spell names are curated translations of `Texts_Things.c`, not extracted game-language strings. The one-use Horny spell is a distinct definition, not the repeatable spell.

The selected field defaults to source display units: 42 verified fractional fields use integer / 4096, 13 signed creature attributes show negative WORD values correctly, and four resistance rates are ordinary integer percentages. A separate raw-value column and explicit raw-input mode retain exact stored integers. Verified BOOL fields also have No/Yes choices. A separate [projectile editor](GLOBAL_PROJECTILES.md) covers all 66 source types/five forms for traps and primary/upgraded keeper/creature spells. The [creature-job editor](CREATURE_JOBS.md) covers all 22 named jobs/four groups, signed tuples, add/update/multiremoval and source warning overrides with atomic apply. The [creature-attack editor](CREATURE_ATTACKS.md) covers all 23 attack fields, three spell slots plus melee, named contextual choices, level/damage controls, exact fractional units and all-slot atomic input/application. Remaining enums and level modifiers remain a parity requirement; unknown compound units are not guessed. See [numeric semantics and tests](GLOBAL_DEFINITION_NUMBERS.md).

Current and original reference values are separate columns. A fresh project without a KGBL override uses the original editor defaults; its first actual change creates only the required family array. An unchanged edit/reset does not create sections, history or change notifications. Missing or unverified native definitions show `—` as current values, not invented defaults, and editing/reset is disabled. Reference defaults are from the preserved original editor and do not assert effective values in other game installations.

The [effects/room-object/armour panel](GLOBAL_DEFINITION_DECORATIONS.md) implements 24 further fields, 371 bilingual effect descriptions, all per-room slot masks and source material/object choices. Its four focused WPF cases pass; exhaustive core/full-suite verification is tracked separately. Selected-record memory is per family, and expanded panels scroll without displacing the definition table in small windows.

- `Properties/GlobalVariables/Properties_Global_Functions.c`, `Properties_GlobalReset`: all 262 semantic assignments, exact reads/signedness/masks and fourteen reset sections. Compiler offsets, sizes and masks are independently cross-checked against these assignments at initialization.
- `Properties_Global_Elements.c` and `Properties_Global_Creatures.c`: buttons 998/999 reset the selected definition or all definitions of the current group. For creatures, attributes, parameters, flags, attacks, resistances, possession, jobs and lighting have independent reset boundaries.
- `Properties_Global_Default.c`, `Datas_GlobalDefault.c` and the seven preserved `Binaries/Globals/Default*.dkg` files: source record ordering, original binary values and ignored native entries.
- `Datas_GlobalVariables.c`: the seven definition lists and logical IDs. IDs, project array indices and native record indices are different; they are explicitly mapped rather than assumed equal. Room catalogue parsing retains rows whose final source column is a flags expression.
- `Includes/GlobalVariables.h` and `Files/Files_Editor.c`: KGBL v1 uses family arrays, and the whole creature array is serialized with `MGRF_CREATURES = 0xFF00`, even if only one creature subgroup changed. There are 46 serialized creature slots but only 45 named source species; the unused final project slot is retained, not reset.

The original `Editor_GetVariables` reads the creature family but does not advance/read the following creature-spell array, although its writer serializes that array. The modern reader retains and edits creature-spell data instead of reproducing this loss. Historical GUI acceptance of that specific family therefore needs care; successful modern save/reopen alone does not prove that the original GUI will retain it.

## Mutation guarantees

Selected reset touches only fields in the chosen source group. All-definition reset covers the full source family, independently of the name filter, but still only that group. Both require explicit confirmation. A selection/filter/group/draft/document change invalidates confirmation; a pending generic property commit cannot reuse old reset authority.

Explicit reset also reloads the current group's unapplied dialog inputs, even when the stored values already equal the original defaults and the reset correctly produces no document notification or undo entry. A regression test reproduced stale generic and compound inputs in that no-op case before the fix. All fourteen groups now exercise both selected/all reset through actual EN/RU native/project controls; projectile, job, attack, resistance/possession and named-rule tests additionally verify their specialized drafts are discarded. Drafts in other creature groups remain independent.

Batch edits are fully preflighted, then executed as one undo transaction. Native writes retain other bits sharing a flag byte, unknown record data and ignored native entries. Project family expansion copies existing arrays exactly, including padding and the unused creature slot. Default-backed array creation and removal by undo operate on a preinitialized optional section, keeping the transaction's file roster stable; unchanged optional sections are omitted from serialization.

Changed shared native definitions export as map-scoped files in a new game-root copy, using the existing descriptor rewrite. Installed files and original source/default binaries are not rewritten. Project export, compilation and native export leave their input buffers unchanged.

Unknown KGBL flags/versions are opaque and read-only, with compilation refused. The native 5537-byte creature variant remains read-only until independently verified; known families in the same bundle remain editable. Native catalogue mapping requires one complete contiguous declared family array: separately declared arrays are not combined just because their total record count happens to match. Unknown layouts are not silently reinterpreted.

Selection, group, field and unchanged-value drafts survive language refresh. Stored-property navigation selects the exact physical record. Closing/replacing the document clears drafts, confirmations and stale records. Map selection and copy buffers are independent of this workflow.
