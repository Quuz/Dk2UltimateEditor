# Окно задачи Test / Compile / Run

Этап CompilerTaskWindow-20261017. Сверены `Windows_Compiler.c`,
`Compiler_Compile.c` и уничтожение окна из `Windows_MainWindowProc.c`.
Это часть I17; полнота compiler/version message generators остаётся I02.

## Что делает редактор

Команды «Проверить», «Компилировать» и «Запустить игру», включая Ctrl+Shift+E,
показывают отдельное окно задачи. Оно содержит журнал фаз, полный список
диагностик с severity/координатами, подробности выбранной строки и итоговые
счётчики ошибок, предупреждений и информационных сообщений. Строки не
обрезаются и не объединяются по одинаковому коду. Выбор строки после
завершения переводит вид карты к её области, сохраняя выделение; закрытие
окна восстанавливает прежнюю подсветку, если документ ещё тот же.

Проверка, формирование native records, проверка результата и запись выполняются
последовательно через Task.Run. Индикатор показывает работу текущей фазы;
проценты и время до завершения не выдумываются. Детальные исходные сообщения
по отдельным типам records ещё входят в I02, это окно не доказывает их полноту.
EN/RU обновляет заголовок, журнал, строки, счётчики и кнопку без потери выбора.

В фоне используется независимый CreateCompilationSnapshot — тот же полный
in-memory clone, который применён для свойств карты: bytes, исходные пути,
section topology, native aliases/target/resize/gate/area/owner working metadata,
retained variables и immutable native-source payload. Нет повторного открытия
с диска, общей Undo-истории или event subscriptions. Фоновая задача не получает
живой документ для чтения. Копия не переносит live save/activity session.

Выбор папок/основы остаётся до начала задачи. Pending property fields принимаются
на UI-потоке; предложение удаления неиспользуемых сценариев и само согласованное
удаление также остаются на UI-потоке. Keep/Remove/Cancel не заменены фильтром
компилятора. Существующие проверки context/revision/plan и согласие по warnings
сохраняются перед публикацией. Во время задачи существующие открытые окна
редактора отключены; autosave учитывает active task. Новые окна согласия доступны.
После успеха/отказа прежние enabled states восстанавливаются. Тестовые синхронные
Request APIs исполняют ту же последовательность inline без открытия task window.

Во время работы кнопка и закрытие task window заблокированы — в исходнике
действующая кнопка также отключена. Частичная запись не выдаётся за отмену.
После Test/Compile/ошибки кнопка закрывает окно. После успешной подготовки Run
кнопка запускает DKII-DX.exe с отдельными аргументами `-q`, `-level`, LevelName;
процесс не стартует автоматически по завершении фоновой записи. После запуска
или ошибки кнопка становится Close. Изменение карты делает отложенный запуск
недействительным. Созданный комплект при неудаче запуска остаётся указанным в
LastGamePreview; созданный экспорт — в LastCompiledPath.

Одна новая задача заменяет старое окно результата. CompilerWindowX/Y/Width/Height
сохраняются между задачами текущего MainWindow после закрытия обычного окна.
Закрытие максимизированного/свёрнутого окна не переписывает сохранённую геометрию.
Первый размер800×600; положение — CenterScreen, как source Window_Center с
NULL parent (desktop). Восстановление ограничено рабочей
областью ближайшего монитора, с сохранением минимального размера controls.
Нет новых полей карты, Undo или JSON. Реальные DPI/мониторы остаются ручной приёмкой.

## Проверка и ограничения

CLI CompilationSnapshotChecks проверяет независимость native/project bytes,
истории, aliases/target/missing references и счётчиков; работу worker при изменении
живой карты; отказ во время edit/pen. Пользовательский NativeRoundtrip DKM с
native-source archive, его копия и копия native результата дают одинаковые
семь файлов. Все выходы создаются в private temp; установленные карты и fixtures
не записываются. Это проверка данных, она не запускает WPF или игру.

WindowsSmoke дополнен actual task controls:25 строк, навигация, EN/RU selection,
запрет действия во время работы, устаревший Run, один запуск и ошибка launcher.
Прежние UI cases Test/Compile/Run адаптированы к async completion и отдельной
кнопке Run. Эти проверки только компилируются. Их исполнение не заявлено.

## Ручная приёмка M03/M10/M14/M18/M20/M21/M23

1. Проверить карту без неиспользуемых сценариев, затем с ними: Keep, Remove,
   Cancel. Сверить сообщения, итог и один полный Undo для Remove.
2. Запустить Compile для DKM: отмена выбора папок не начинает задачу; ошибки
   оставляют полный результат без экспорта; warnings требуют прежнего согласия.
   Успешный экспорт содержит ровно7 файлов и открывается в официальном редакторе.
3. Во время работы проверить отклик самого окна, блокировку редактирования,
   недоступность X/кнопки до окончания, восстановление окон после отказа/успеха.
4. В результате выбрать диагностическую строку с координатами. Проверить
   перемещение вида, подсветку и её восстановление при закрытии, EN/RU selection.
5. Для Run убедиться, что после подготовки игра сама не запускается. Изменение
   карты делает Run недействительным. На неизменной карте кнопка запускает один
   процесс; ошибка запуска оставляет путь подготовленного комплекта и Close.
6. Передвинуть/изменить размер окна, закрыть и создать следующую задачу; повторить
   с maximized/minimized, DPI100/125/150, отрицательными координатами монитора и
   отключением второго монитора. Запоминание геометрии между запусками приложения
   не обещается.

Для ручного игрового теста использовать имя `DK2Preview_6a88240eaf814f78` и
`DKII-DX.exe -q -level DK2Preview_6a88240eaf814f78`. Уже существующий preview
редактор не перезаписывает молча; общий installed/shared контент сохраняется.
