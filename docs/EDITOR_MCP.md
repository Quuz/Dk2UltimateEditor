# Локальный MCP редактора

Текущий проход: [native-настройки игрока](NATIVE_PLAYER_SETTINGS_20261104.md) и [происхождение определений](DEFINITION_SOURCES_20261104.md). M15-02 принят; физическая клавиатура камеры остаётся открытой. Если CU показывает только owner, не считать передачу клавиш в дочерний диалог успешной без видимого результата.

Добавлен 1 ноября 2026. MCP позволяет помощнику вызывать команды открытого
редактора через локальный канал. Работает с тем же документом и историей,
которые видны в окне. Обычный запуск редактора не включает мост.

## Запуск

1. Сохрани изменения и закрой прежнее окно редактора.
2. Запусти двойным щелчком `artifacts/PreFinal/Start-Editor-MCP.cmd`.
3. Внизу окна должна появиться надпись «MCP включён». Открой нужную карту,
   закрой диалоги свойств/предупреждений и оставь главное окно открытым.
4. После регистрации сервера Codex должен загрузить его инструменты.
   Если в текущем чате их ещё нет, перезапусти Codex, сохранив этот чат.
   Первая команда — `dk2_editor_status`; она должна вернуть путь именно
   открытой карты. До такого ответа связь с настоящим окном не подтверждена.

Команда запуска вручную из PowerShell:

```powershell
New-Item -ItemType Directory -Force 'D:\Games\DK2\DK2-Map-Editor\artifacts\McpWorkspace' | Out-Null
& 'D:\Games\DK2\DK2-Map-Editor\artifacts\PreFinal\App\UltimateEditor.exe' '--mcp-pipe=dk2-editor' '--mcp-root=D:\Games\DK2\DK2-Map-Editor\artifacts\McpWorkspace'
```

Параметры пишутся через `=`. Для другого окна выбери другое имя pipe и отдельную
запись MCP. Два окна с одним именем не обслуживают общий канал.

## Подключение Codex

Сервер запускается отдельно от GUI, через stdio:

```powershell
codex mcp add dk2-editor -- 'D:\Games\DK2\DK2-Map-Editor\artifacts\PreFinal\Mcp\DK2MapEditor.Mcp.exe' '--pipe=dk2-editor'
codex mcp get dk2-editor --json
```

В текущей установке сервер уже зарегистрирован под именем dk2-editor,
таймаут установлен в 150 секунд. Команда выше нужна при переносе поставки.

Для тяжёлых компиляций рекомендуемый `tool_timeout_sec = 150` в секции
`[mcp_servers.dk2-editor]` файла конфигурации Codex. Не меняй существующие
параметры других серверов. Серверу не нужны API key, сеть, OAuth или HTTP-порт.
Настройка stdio описана в [официальной документации Codex](https://learn.chatgpt.com/docs/extend/mcp?surface=cli).

Если GUI закрыт, сервер по-прежнему отвечает на initialize и tools/list,
а команды редактора возвращают `editor_unavailable`. Сам сервер GUI не запускает.

## Библиотека камеры

Открой прямую библиотеку кнопкой «Выбрать маршрут камеры…» выбранного действия31.
`dk2_editor_status` показывает ui.cameraLibrary: query, choices(id/label),
selectedPathID, ceilingMode, canApply, локализованные title/description/mode/status.
Инструмент не открывает окна и пока не работает с дочерней библиотекой мастера.

`dk2_camera_library` требует свежий expectedStateToken для каждой команды:
Inspect без других аргументов; Search с query до256символов; Select с pathID
из текущих choices; Apply или Cancel без дополнительных аргументов. Поиск050
находит видимую строку050. Поиск и выбор не меняют карту; Apply вызывает ту же
команду, что кнопка окна, и может вернуть applied=false с inline status.
После успешного Apply окно закрыто, поля читаются заново через records.
При Cancel карта остаётся прежней. Неизвестный исходный ID сохраняется до выбора.

Открытие/поиск/выбор/перевод меняют token; stale_state требует нового чтения.
Другие команды карты остаются editor_busy. Другой диалог, отсутствующая или
закрытая библиотека дают camera_library_unavailable. Нельзя через эту команду
применить невидимый выбор или управлять произвольным окном.

[Результаты/ограничения/обновление клиента](CAMERA_SEARCH_LIVE_20261103.md).
При обновлении занятыхDLL служебный stdio-процесс может быть перезапущен; старому
подключению Codex потребуется переподключение для обновления tools/list. Новый
локальный stdio-клиент уже работает со всеми25командами; копии кода для этого не нужны.

## Состояние и согласия

Fingerprint читает текущие буферы документа, а не файлы с диска. files/orderedSha256
относятся к загруженным файлам; documentSha256 дополнительно включает служебные
буферы и идентичности путей. Clipboard, история, настройки и runtime-статистика
не входят в hash. Сравнивай его в одном документе/контексте путей: Save As или
другая исходная папка могут изменить hash без изменения игровых значений.
Содержимое буферов не выдаётся. Инструмент проверен на metadata-only edit,
который не меняет Files, и на точном Undo.

Все координаты нулевые. Стандартная палитра: terrain 1..41, owner 1..7,
variant 1 или 2; мировые клетки нормализуются штатными правилами редактора.
Кисть принимает одну клетку, для протяжённого жеста есть Line и остальные формы.

Ответ содержит `ok`, `result`, `state`. Ошибка дополнительно содержит
`code`, `message`, иногда `details`, и передаётся как MCP `isError=true`.
Нормальная MCP-ошибка аргументов использует JSON-RPC -32602.

Мутации требуют точного `expectedStateToken` последнего результата.
Токен учитывает экземпляр редактора, конкретный документ, EditRevision,
контекст окна, выделение, буфер копирования, инструмент и кисть. После ручной правки, Undo/Redo, открытия или
применения команды получи новый токен. Handles записей перечитывай после
изменения документа. При `stale_state` нельзя слепо повторять старую правку.

Selection Set требует допустимый прямоугольник. Paste использует верхний левый
угол явного текущего выделения. Непустой буфер нельзя заменить без
replaceBuffer=true: по умолчанию возвращается needsBufferReplacement без правки.
Неквадратный поворот на карте штатно отказывает с подсказкой CopyRotated.

object_paint сначала возвращает preview. Для записи нужны apply=true и, при
предупреждениях, allowWarnings=true. Замена записи со сценарием отказывает
с script_review. Creature level соответствует исходному DataAll; остальные
семейства level не принимают. Координаты и ID проверяются до размещения.

Открытый диалог, активный штрих, файловая операция или компиляция блокируют
команды: `editor_busy`. Status остаётся доступен. Незавершённое поле PropertyGrid
сначала коммитится штатным способом; если это изменило документ, запрос
отклоняется как устаревший. Исправь/отмени невалидное поле в интерфейсе.

Save требует `acceptLosses=true` только при потерях и `allowWarnings=true`
для отчёта совместимости. Без флагов возвращается предварительный отчёт,
решение остаётся за вызывающим. Блокирующие ошибки не обходятся.
Существующий файл/компаньон требует `overwrite=true`; нормальный Save остаётся
транзакционным. `discardChanges=true` отдельно разрешает замену грязной карты.
Компиляция всегда выбирает Keep для неиспользуемых событий.

Черновик properties имеет отдельный `planToken`. Prepare не меняет живую карту;
повторный Prepare заменяет старый черновик. Apply проверяет состояние владельца
и неизменность плана, применяет именно ApplyEditorMapProperties. Cancel не
откатывает посторонние ручные изменения. После выхода редактора черновик исчезает.

## Файлы и транспорт

Выходы разрешены только внутри явного `--mcp-root`. Относительные пути,
выход через `..`, соседний каталог с похожим префиксом, symlink/junction
в существующей цепочке пути отклоняются. Это защита от случайной записи,
не граница против злоумышленника с правами того же пользователя и гонок ФС.
Входные карты и KWD-основа читаются по явным абсолютным путям.

Доступ к pipe — только текущему пользователю Windows. Встроенного сетевого
сервера, запуска оболочки, установки уровня в игру и автоматического старта
игры нет. Имена pipe состоят из ASCII букв/цифр, дефиса и подчёркивания.
Соединение ожидается до 3 секунд, команда — до 120 секунд; отмена не может
откатить уже опубликованную операцию. При обрыве/таймауте результат может быть
неизвестен: сначала прочитай состояние, проверь выходы, затем решай о повторе.
Автоматических повторов отправленных команд нет.

MCP реализован как ограниченный stdio-сервер протокола 2025-11-25:
initialize/initialized, ping, tools/list, tools/call. Старые совместимые версии
2024-11-05, 2025-03-26, 2025-06-18 согласуются при initialize. Новый
server/discover получает -32601 для штатного fallback клиента.
Resources/prompts и потоковый прогресс не объявляются. JSON-RPC — UTF-8,
одна JSON-строка на сообщение, только протокол в stdout, ошибки в stderr.
Запрос ограничен 1 MiB символов, ответ pipe — 8 MiB; отчёты диагностики
ограничены 1000 строками. Документ может содержать больше данных; это не повод
удалять оставшиеся записи.

## Дочерние окна при Computer Use — наблюдение4ноября

Некоторые ShowInTaskbar=false формы отсутствуют в sky.list_windows(), но присутствуют
в windows соответствующего приложения из sky.list_apps(). Выбирать нужно именно
этот возвращённый Window, затем получать его свежий state и выполнять один input
с обновлением. UIA-индексы из composite-снимка disabled owner не подходят дочернему
окну. Отдельный снимок child также не обрезается границами owner. Этот приём не
меняет MCP и не означает, что все клавиатурные проверки автоматически пройдены.
