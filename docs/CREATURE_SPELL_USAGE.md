# Какие существа используют заклинание

CreatureSpellUsage-20261019, исправление конкретного пропуска I13.
Страница заклинания существа теперь показывает список «Существа с этим
заклинанием» с исходными изображениями32×32 и именами EN/RU. Он доступен
в отдельном CreatureSpellWindow и в общем CreatureGlobalsWindow.

Источник: Editor.rc, dialog6868, заголовок122/listbox123;
Properties_GlobalGetParamsCr, page8, выбирает все строки GCreatures, у которых
Shot1ID либо Shot2ID либо Shot3ID равен ID выбранной строки GCrSpellsLst.
Сравнивается ID заклинания, а не его индекс или projectile Shot.
Properties_GlobalCrSpellsProc рисует list123 через GCreatures и CreaturesImages.
Это просмотр пользователей заклинания, а не поле выбора цели.

ReadCreatureSpellUsage повторяет OR по трём слотам, сохраняет порядок45 исходных
видов и включает существо один раз. Native читает проверенные поля записи,
DKM без override — прежние source defaults. Непроверенные layouts не получают
придуманных значений: показаны только проверенные строки с предупреждением
о возможной неполноте. Пустой полный список обозначается отдельным текстом.

Окно хранит снимок состава списка. Смена языка переводит имена из этого снимка
и сохраняет выбранную строку, не читая изменившийся документ ради перевода.
Новый переход на страницу получает свежий список из частного контекста:
изменённые атаки в общем окне видны до общего Apply. Выбор строки списка
не меняет параметры, историю, ревизию или игровые файлы. Cancel сохраняет карту.

Изображения используют уже встроенные GCreatures/Editor.rc ресурсы через
OriginalDefinitionImages. Новых BMP и дубликатов ресурсов нет; неизвестное
импортированное значение не получает случайную картинку. Три новые строки
EN/RU: UsedBy, NoUsers, UsageIncomplete. Все прежние2781 literal values сохранены.
Полный словарь теперь2784 ключа в каждом языке.

## Проверка

DKM по независимым native offsets0xDDA/0xDF2/0xE0A, порядок/ID, отсутствие
дубликата при трёх одинаковых слотах, пустой список, private/Cancel и снимок
состава после изменения владельца. Чтение не меняет полные байты/ревизию/Undo.
Missing layouts дают неполный пустой результат, без default users.

## Ручные шаги

1. В Creatures→CrSpells выберите заклинание: внизу должны быть имена и картинки
   использующих его существ. Один вид не должен повторяться при нескольких слотах.
2. Переключите EN/RU: состав и выбранная строка сохраняются. Проверьте нижний
   край формы, прокрутку длинного списка и свой DPI.
3. В общем окне измените один из трёх слотов атаки существа и вернитесь к
   заклинанию: список должен отражать частный черновик. Общий Cancel не меняет карту.
4. На карте без проверенных definitions ожидается предупреждение о неполном
   списке, а не вымышленные пользователи.
