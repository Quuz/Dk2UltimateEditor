# Подписи настроек, запросов и отчётов

ServiceCaptionAudit-20261023, 23 октября2026, часть I13.

Сверена группа настроек и служебных окон. Использованы исходные Config.h,
Requests.h, callbacks Misc_Requests/Compiler_Report/Map_Undo и уже законченная
кодовая сверка I17. Повторно подтверждены неизменность заголовка CONFIG с42
полями,18 объявленных request bits,17 активных source requests и отсутствие
активного REQUEST_AREASIZE. Снимок23 текущих service UI файлов содержит111
буквальных/выбранных EN/RU caption keys. Наличие ключа само по себе не
принимается за проверку поведения: авторизация, default buttons, stale guards,
scope памяти и согласованные отличия опираются на отдельные документы I17.

Подписи глубины Undo и автосохранения отражают существующие параметры:
0–65535 шагов, source default200,0 отключает Undo/Redo; интервал автосохранения
в минутах, default5,0 отключает его. Системные диалоги и параметры без активной
исходной команды не превращены в новый settings UI. Нехватка памяти Undo
остаётся понятным информационным сообщением с полным откатом по явному решению
пользователя. Варианты частичного изменения/продолжения без Undo не возвращены.

Уточнены четыре EN/RU caption: ScenarioDelete.Remember, LargeMap.Remember,
ThingRequest.Remember, RegionRemoval.Remember. Теперь явно сказано, что «Да»
запоминается до завершения сеанса редактора. Преференции этих requests живут
в EditorRequestPreferences и не сериализуются AppSettings. Флажок относится
к своему типу запроса и не даёт общего разрешения на остальные операции.
Отдельная настройка ConfirmCopyBufferReplacement действительно сохраняется
в JSON; её подпись и прежняя согласованная политика не изменены.

Краткие сообщения всех61 буквальных DK2 diagnostic code в текущих Core/App
имеют EN/RU ресурсы. Это конечная лексическая выборка, не утверждение о всех
возможных dynamic codes или параметризованных сообщениях. Сырые технические
подробности остаются отдельно от переведённого summary, с исходными кодом/
путём/значениями. Их полнота и семантика проверок относятся к I09; сообщения
компилятора и точное соответствие source conversion policies — к I02.
Подписи заголовков/уровней/продолжения и read-only versions report сверены
в пределах текущих service controls; запись карт/фильтрация не менялась.

Найден и исправлен отдельный пропуск изображений отчёта. Compiler_Report.c
создаёт свой ImageList напрямую, загружая87 Warning16.ico,88 Error16.ico,
89 Information16.ico. Это не один из81 Misc_CreateImageList calls. В текущем
отчёте рядом с текстовым уровнем теперь показан соответствующий исходный
16×16 значок, без добавления новой колонки. ICO встроены как точные исходные
байты, выбирается16px frame, immutable bitmap кэшируется. Три существующие
колонки, их порядок/ширина, строки, детали, выбор, navigation, Cancel/Continue
и обработчики языка прежние.

Значок следует уже классифицированному DiagnosticSeverity. Этот этап не
меняет Error/Warning/Information и не понижает ошибку ради совпадения картинки.
В source editor-compatibility output существует особый случай показа «!»
как warning; граница сохранена в report-icons.json. Политика диагностики и
фильтрации остаётся существующей, а её соответствие не выводится из значка.
Неизвестный enum не получает выдуманную картинку.

Из2850 ключей каждого языка уточнены только четыре, остальные2846 literals
сохранены. Core, настройки, request policies, diagnostic classifiers и
formats не менялись. Новая фокусная проверка без WPF сверяет mapping3 видов,
наличие16px frames и точные embedded ICO через PEReader. Уже успешные checks
авторизации/памяти requests не повторялись. WPF только собран; реальный отчёт,
клавиатура, DPI, игра, аудио и Computer Use не запускались.

Для ручного осмотра откройте отчёт с доступными сообщениями: значок должен
соответствовать текстовому уровню, строки и детали должны оставаться читаемыми.
Переключите EN/RU, проверьте сохранение выбора. В указанных четырёх запросах
флажок должен явно говорить о текущем сеансе; для осмотра его устанавливать
и подтверждать удаление не требуется. Длинные переводы/DPI остаются ручной
приёмкой, не объявлены проверенными по успешной сборке.
