# Групповые модификаторы существ

[Настоящий native RU125% проход2ноября](MAP_RULES_LIVE_20261102.md): среднее без нулей, групповой ввод,13элитных исключений, общая отмена/применение/UndoRedo/export/reopen. Прочий остаток открыт.

15 октября 2026. В общем окне свойств карты появилась кнопка
«Модификаторы существ…» / «Creature modifiers…». Она открывает дочерний
частный контекст с выбором видов и четырьмя полями исходных модификаторов.
Обычная таблица правил сохраняется как дополнительный маршрут.

## Исходное поведение

Properties_MapCreaturesInit копирует CreaturesParams в отдельный рабочий массив.
Properties_MapCreaturesChanged обрабатывает выбранные виды и показывает четыре
независимых средних. Каждое среднее учитывает только ненулевые значения своего
параметра: нули не входят в знаменатель. Деление целочисленное. Элитные строки
с исходными индексами 17–29 исключаются из вычисления и записи.

Properties_MapCreaturesSetParam записывает изменённый параметр всем выбранным
неэлитным видам. Другие параметры и невыбранные виды сохраняются. Смена выбора
перечитывает все четыре средних, не записывая эти средние обратно в данные.
DoNotUpdate предотвращает запись при программном заполнении полей.

| Действие | Частные данные | Карта |
| --- | --- | --- |
| Выбрать виды | Меняется выбор, показываются средние | Без записи |
| Ввести параметр | Меняется этот параметр выбранных неэлитных видов | Без записи |
| Отменить дочернее окно | Черновик отбрасывается | Без записи |
| Подтвердить дочернее окно | Значения переносятся в черновик общих свойств | Без записи в живую карту |
| Отменить общие свойства | Весь родительский черновик отбрасывается | Без записи |
| Применить общие свойства | Все принятые дочерние изменения объединяются | Один исходный счётчик и один общий Undo при неизменном размере |

Исходный IDOK копирует рабочий массив обратно в контекст родителя; IDCANCEL
этого не делает. Ни дочерний callback выбора, ни setter, ни OK не увеличивают
MapChanges и не создают Undo живой карты. Принятие общих свойств имеет своё
правило счётчика, включая дополнительные действия при изменении размеров.

## Текущий код

MapCreatureModifiersSession хранит независимые значения и выбор всех исходных
видов. MapRules обеспечивает соответствие IDs, четырёх параметров и физического
хранения в native/project. Элитные и отсутствующие в неподтверждённом layout
поля не становятся редактируемыми. Непоказанные и неизвестные данные карты
не переписываются. Нулевое значение снимает переопределение.

Суммы повторяют исходный signed LONG с 32-битным переполнением и выводом
результата как unsigned. Обычный ввод ограничивается 0–65535; поля имеют исходный
лимит пяти символов. Проверены десятичный префикс, пустой ввод, отрицательные
значения, верхняя граница и переполнение DWORD. Средние заполняются с подавлением
обратных callbacks; переключение языка сохраняет текущий выбор и ввод.

MapCreatureModifiersWindow использует многострочный выбор Ctrl/Shift и четыре
отдельных поля с кнопками −/+. При вводе меняется частный массив и показанные
строки, а список выбора сохраняется. Дочернее подтверждение применяет изменения
к WorkingDocument общего MapPropertiesSession. Общий Cancel сохраняет живую карту;
общий Apply использует прежний атомарный маршрут ApplyEditorMapProperties.

Родитель проверяет неподтверждённый дочерний ввод и не применяет его молча.
Подтверждения размера/обрезки связаны также с экземпляром дочернего окна и его
InputRevision. Закрытие/Reset родителя закрывает ребёнка. Изменение живой карты,
частного документа, сырого payload или Undo инвалидирует прежний контекст;
чужое, закрытое и вложенное применение отклоняется.

Ввод во время родительского подтверждения размеров тоже увеличивает ревизию.
Если в этот момент контекст не позволяет принять параметр, текст помечается
как неподтверждённый; прежнее согласие не используется, а дочерний OK не
применяет прежние значения молча. Нужно заново ввести значение или выбрать
виды для повторного чтения средних. Этот сценарий добавлен в compiled-only
WPF checks; он не требует повторного запуска неизменённого Core.

## Доказательства и ограничения

Снимок четырёх исходных функций связан с SHA Properties_Map_Creatures.c.
Модели native/project сверяют все строки каталога и 13 элитных видов,
32 независимых сочетания выбора с буквальной матрицей четырёх параметров,
запись выбранного параметра, отсутствие изменений при просмотре/отмене,
частное дочернее и общее применение, один общий счётчик/Undo, полные bytes
Undo/Redo, статистику, закрытые/чужие/устаревшие/вложенные контексты.
Прежние проверки общих свойств, девяти привязок и изменённых размеров сохранены.

Проверки WPF используют реальную кнопку общего окна и реальный класс ребёнка:
средние, четыре поля, EN/RU, дочерний и общий Cancel, pending/stale guards,
общее Apply и Undo. Они подготовлены и скомпилированы; окна, renderer,
официальный редактор и игра не запускались. Полный итог:
[CURRENT_STATUS](CURRENT_STATUS.md). Доказательства:
artifacts/Evidence/CreatureModifiers-20261015.

## Ручная проверка

1. Откройте общие свойства карты и «Модификаторы существ…». Выберите два вида
   с различными значениями: каждое из четырёх полей должно показывать среднее
   только по ненулевым значениям выбранных видов.
2. Добавьте элитный вид к выбору: средние не должны учитывать его. Выберите
   только элитные виды — изменение параметров должно быть недоступно.
3. Измените один параметр, смените выбор и вернитесь. Другие параметры и
   невыбранные виды должны сохраниться. Переключите EN/RU: выбор и ввод сохраняются.
4. Отмените дочернее окно. Повторите ввод и подтвердите ребёнка, затем отмените
   общие свойства — живая карта должна сохраниться в обоих случаях.
5. Подтвердите ребёнка и общие свойства без изменения размера. Должен появиться
   один общий Undo; отмена возвращает все параметры и счётчик. Пока ребёнок
   содержит неподтверждённые изменения, родитель должен просить их завершить.
