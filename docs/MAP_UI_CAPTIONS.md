игроков вне ранее законченных AI/rule audits. Source snapshot содержит

Исправлены две подписи EN/RU для восьми пар TextIntroCreatureID0–7 /
TextIntroTextID0–7. Исходная группа DIALOG_MAPTXTOVERRIDE явно означает
«тексты замены при появлении существ». Прежнее «Вступление / Introduction»
не отличало эти поля от вступления уровня. Теперь подписи называют замену
при появлении существа, номер пары и creature/text ID. Это не speech bank
и не before-level mentor speech; источник не утверждает, что это только
первое появление, поэтому такое уточнение не добавлено.

43 семантических поля получили единый маршрут подписи в typed speech/text
окне и общих raw properties. Для основных параметров и опций используются
существующие MapProperties/LevelOptions keys, для речи — SpeechText keys.
Пары имеют видимые номера1–8 при хранении0–7. Raw Options/Options2 остаются
целыми битовыми байтами, не называются по смыслу одного флажка. Неизвестные
поля сохраняют старый FieldLabel с индексами и дополнительными аннотациями.

Контекст определяется по подтверждённой сигнатуре, категории, версии,
размеру и реальному полю раскладки. DKM1–7 показывают только сохранённые
поля; отсутствие Version в1–5 не превращается в поле padding. В native
GAMEINFO target game version отсутствует: выбор версии остаётся рабочим
состоянием редактора. File format version не подменяется на13/16/17.
Подписи обновляют отображение; данные, fallback старых форматов, чтение,
запись, независимые черновики и команды не меняются.
