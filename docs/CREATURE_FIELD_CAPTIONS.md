# Подписи атрибутов, флагов и заклинаний существ

21 октября 2026. Этап CreatureFieldCaptions-20261021, часть I13.

Конечный перечень девяти исходных страниц содержит 167 хранимых полей:
Attributes38, Parameters13, Flags14, Attacks23, Resistances8, Possession14,
Jobs36, Light10, CrSpells11. Он получен из исходных reset assignments,
сопоставленных текущим Core с native offsets. Все поля, исходные страницы
6860–6868, resource captions и места использования сохранены в
`artifacts/Evidence/CreatureFieldCaptions-20261021/fields-before.json`
и `fields-after.json`.

Для всех 38 атрибутов построено точное соответствие с `GAttribs` в
`Source/Sources/Datas/Datas_GlobalVariables.c`: имя поля, native offset,
признаки fixed/signed и символ французской надписи. Надписи взяты из
`Source/Sources/Datas/Texts_GlobalVariables.c`. Имена C-полей сами по себе
не использовались как доказательство значения.

Остальные атрибуты получили понятные полные названия по той же таблице, включая
условия роста гнева и здоровье от одной курицы. Единицы указаны только там,
где они есть в исходной надписи. Нового пересчёта значений нет: прежние
`GlobalDefinitionNumbers` и input callbacks сохранены побайтно.

`CreatureDefinitionFieldLabels` выбирает `CreatureAttributes.*` только для
семейства Creatures и точного набора 38 полей Attributes. Окно атрибутов и
общая таблица определений используют один маршрут. Общие `Field.Height`,
`Field.Health`, `Field.Fear`, `Field.Speed`, `Field.HungerRate` и прочие старые
ключи не меняются для других контекстов. Подписи массивов и аннотации остаются
на прежнем обработчике.

По остальным исходным страницам уточнены 13 существующих ключей на язык:

- `DoNotTrain` в общей таблице — «Не тренируется при бездействии»; положительный
  checkbox окна Flags — «Тренируется при бездействии». Инверсия исходного
  хранения сохранена; это не общий запрет обучать существо.
- `NoEnemies` — «Не ссорится с вражескими существами», а не отсутствие врагов.
- `FreeFriends` — освобождение союзников при побеге; `RevealTraps` — раскрытие
  ближайших ловушек; `RandomInvader` — использование в случайных отрядах героев.
- `HealthEffect` — эффект при восстановлении здоровья; `EntranceEffect` — при
  входе через портал; `LairObject` — предмет-кровать.
- `GammaEffect` — визуальный фильтр; `CameraRolls` — наклон камеры при повороте
  существа; `LightPlayer` — цвет света как у игрока.
- `CastCreatures` явно ограничивает применение заклинания существами-целями:
  «Применять только к существам».

Для флага `CrSpells.Creature` добавлено отдельное контекстное название
«Заклинание существа» / «Creature spell». Оно отличается от ограничения целей
`CastCreatures` и не меняет общий ключ `Field.Creature`.

Итого добавлены 39 ключей на язык: 38 атрибутов и один флаг заклинания.
Уточнены 13 прежних ключей; остальные 2794 прежних строки сохранены. В каждом
