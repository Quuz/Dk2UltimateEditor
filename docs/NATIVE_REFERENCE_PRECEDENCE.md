# Разрешение компонентов переименованной KWD

Исправление основного проекта, 12 октября 2026.

KWD содержит явные ссылки на компоненты карты. Имя дескриптора может отличаться
от имён этих файлов: например, `XXLevel10.kwd` ссылается на `Level10Map.kld`,
`Level10Players.kld`, `Level10Triggers.kld` и остальные компоненты `Level10`.

Ранее общий resolver добавлял существующие соседние `XXLevel10*.kld` даже после
успешного разрешения явных ссылок того же типа. В документ попадали два набора
объектов, игроков и сценариев. Повторяющиеся номера событий в таком объединении
могли быть ошибкой загрузчика, а не исходного набора сценариев.

Теперь для каждого типа компонента найденная явная ссылка имеет приоритет над
файлом, подобранным по имени дескриптора. Резервный поиск по имени остаётся, если
явная ссылка отсутствует или не разрешается. Метки отсутствующих ссылок сохраняются.
Общий `GlobalVariables.kwd` не заменяет собственный `Variables.kld` карты.
Несколько явных ссылок не удаляются и не объединяются по предположению.

Изменение находится в `NativeDescriptorReferences.cs`; общий resolver используется
и загрузчиком редактируемого документа, и инспектором. Пути и байты установленной
карты не изменяются. Экспорт по-прежнему использует официальный комплект из семи
файлов.

## Проверки

`NativeReferenceChecks.CheckRenamedDescriptor` сначала воспроизвёл старую ошибку
с кодом завершения 1. После исправления группа прошла с кодом 0. Проверяются все
пять типов компонентов, точные байты явных файлов, отказ от добавления соседних
копий и игнорирование повреждённых резервных файлов при найденной явной ссылке.
Отдельно проверяются отсутствующая явная ссылка с пригодным резервным файлом,
общие и собственные переменные, экспорт/повторное открытие и неизменность входов.
Существующая группа инспектора также прошла с кодом 0, включая CP1252, ограничения
путей и таблиц, повторные физические ссылки и поиск компонентов.

Доказательства и полный необрезанный regression:
`artifacts/Evidence/ReferenceResolution-20261012`.
Сравнение должно учитывать весь прежний упорядоченный список 94 отказов;
исчезновение отказа принимается только вместе с успешной соответствующей проверкой.
GUI и фактическая игра этим CLI-прогоном не подтверждаются.

Полный прогон завершён с exit 1:1795 passes/63 failures вместо1767/94.
31 отказ исправлен, прежние1767 passes не потеряны. У одного оставшегося отказа
XXLevel14 изменилась диагностика: явно указанный Level14Triggers не содержит
событие52, на которое ссылается KWD; соседний XXLevel14Triggers содержит его,
но не является указанным компонентом. Файлы и ссылка не переписывались.
Остальные62 сообщения совпадают с baseline; порядок оставшихся отказавших
проверок тот же.63 оставшихся отказа остаются видны в сыром отчёте.
