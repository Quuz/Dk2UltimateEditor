# Сохранённое раскрытие дерева сценария

ScenarioExpansion-20261018. MC04 входит в I17; ручная приёмка дерева остаётся
в M18/M20/M23. Этот документ описывает исходный флаг условия, а не игровую
логику, repeat, operands или раскрытие вспомогательных строк владельцев.

## Формат и поведение

Source/Includes/Triggers.h:134–151 определяет TRIGGER: NODE занимает12 байт,
previd —2, expanded —2 байта со смещения14, параметры начинаются со16.
TRIGGER имеет56 байт. Source/Sources/Triggers/Triggers_Select.c:156–158
записывает short0/1 в TVN_ITEMEXPANDED, без MapChanges/Undo_CreateEntry;
при построении дерева строки549–550 читают любое ненулевое значение как true.
KTRG версий2/3 содержит эти records; старые неизвестные layouts не получают
права редактирования по предположению.

Дерево читает сохранённое значение при создании модели и связывает IsExpanded
контейнера с моделью в обе стороны. Пользовательское раскрытие/сворачивание
сохраняет ровно short0/1. Чтение импортированного ненулевого short не меняет
его bytes. Смена языка/вкладки и обновление дерева не сбрасывают флаг и не
раскрывают свёрнутые ветки ради прежнего скрытого выбора. Явное выделение
нового события после команды по-прежнему может показать его путь.

Раскрытие не создаёт отдельный Undo, ChangeCount/EditorChangeCount/ревизию,
Changed/HistoryChanged или запись активности. Существующий полный Undo
восстанавливает bytes DKM, включая флаг, если они входили в его снимок.
Само раскрытие не считается семантической несохранённой правкой карты.
Обычный source Save с нулевым счётчиком не активируется; явное Save As и
следующее сохранение реальной правки включают актуальный флаг в DKM.

В 24-байтовой игровой записи нет expanded. Для native-документа это
презентационное состояние в памяти по ID условия, не полномочие менять связи
или переименовывать владельца. Клоны получают независимую копию. При native→DKM
конверсии true записывается в подтверждённый short14 до канонизации IDs,
поэтому переименование ID сохраняет флаг. Игровые байты, operands и
семифайловый экспорт из-за раскрытия не меняются. Повторное открытие KWD
начинается с исходного native defaultfalse; для сохранения редакторского
состояния используется рабочий DKM. Новый companion/игровой файл не добавлен.

Планы сохранения учитывают native-презентацию в SaveWorkingFingerprint:
раскрытие после preflight делает план DKM устаревшим. Этот флаг не изменяет
семантическую ревизию или snapshot авторизацию сценарной правки native.
DKM меняет реальный short и потому участвует в прежнем полном byte fingerprint.
Чужие/устаревшие WPF модели, закрытый документ, active pen/transaction,
не-условия, zero/duplicate IDs и неподтверждённые layouts не записываются.

## Проверка

Новый CLI `--scenario-expansion-only`: native/DKM, default/равный вызов,
точный двухбайтовый delta, отсутствие команд/history/events/activity,
независимые клоны, stale Save/Conversion plans, DKM и native→DKM save/reopen,
непрозрачный nonzero short, malformed/zero/action/active-edit отказы.
На пользовательской тестовой DKM сравнивается весь игровой экспорт до/после
переключения всех флагов: всегда7 файлов, все bytes должны совпасть.
Установленные карты и fixtures не записываются.

WPF `--scenario-expansion-only`: EN/RU × native/DKM, фактические generated
TreeViewItem и двухстороннее связывание, вложенность, collapse/refresh/
translation/tab, старая модель и закрытие владельца. Эти случаи только
скомпилированы, не запущены агентом. Фактические результаты команд и поставка
указаны в CURRENT_STATUS и artifacts/Evidence/ScenarioExpansion-20261018.

## Ручная приёмка

1. Открыть DKM со вложенными условиями, раскрыть одно и свернуть другое.
   Переключить язык и вкладку: видимые состояния сохраняются.
2. Выполнить Save As DKM, закрыть и открыть результат: состояния прежние.
   Само раскрытие не добавляет шаг в историю и не меняет счётчик правок.
3. Открыть KWD, раскрыть условия, сохранить рабочий DKM; открыть DKM и
   проверить флаги. Игровые records не получают придуманных полей.
4. Проверить стрелки/клавиатуру дерева, выбор скрытого потомка, Undo/Redo,
   смену документа и DPI100/125/150. Это M18/M20/M23, не результат CLI.

Согласованные Ctrl+N = новая карта и Ctrl+Y = Redo сохраняются.
