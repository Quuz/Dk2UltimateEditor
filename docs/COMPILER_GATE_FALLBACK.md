# Компиляция DESTROYGATE без существующей цели

24 октября 2026, CompilerGateFallback-20261024. Исправлено конкретное
расхождение I02: DKM с удалённой целью DESTROYGATE теперь компилируется
с исходными координатами **1,1**. Сам `param5` в рабочем проекте сохраняется.
Предупреждение DK2N026 для ненулевой отсутствующей цели остаётся.

## Правило исходника

`Compiler_GenerateActions`, case ACTION_DESTROYGATE, пишет нулевой DWORD,
затем два WORD: `RectEx_GetRectLocation(&MapGates,param5,axis)+1`.
`RectEx_GetRectLocation` возвращает0, если ID не найден. Поэтому результат
для отсутствующей цели —1,1. Если цель существует, writer использует её
координаты с прибавлением1. Это одинаковый recipe для target13/16/17.

`Compiler_TaskTestAction` не содержит отдельного запрета DESTROYGATE из-за
отсутствующего gate ID. `Compiler_TaskTestGates` проверяет геометрию имеющихся
ворот, а не вводит такой запрет для действия. Полные функции, номера строк,
SHA256 и проверенные условия находятся в
`artifacts/Evidence/CompilerGateFallback-20261024/source-fallback-proof.json`.

Прежний `throw` компилятора и соответствующее ожидание старого теста были
строже исходного поведения. Исправлен только этот маршрут; общая проверка
ошибок карты и guards других сущностей не ослаблялись.

## Текущее поведение

- Нулевая/ненулевая отсутствующая цель записывает1,1; ID не переписывается на0
  или на первые попавшиеся ворота.
- При существующем ID сохраняется прежнее разрешение координат по ID.
- Сгенерированный рабочий native-документ сохраняет missing logical target.
  Другие ворота в0,0 не становятся его рабочей целью из-за fallback1,1.
- Source companion не возвращает старые координаты удалённых ворот поверх
  нового результата writer. Поддержанное изменение остаётся у compiler.
- Повторное использование ID снова разрешает действие в новые координаты,
  как и раньше. Undo/Redo и сохранение DKM сохраняют operand и порядок.
- Официальный игровой экспорт по-прежнему состоит из семи файлов.

У обычного игрового KWD нет поля для логического missing ID. При plain reload
доступны только сохранённые координаты и исходное правило native import.
Для продолжения работы храните DKM вместе с его companion. Этот этап не
меняет оставшуюся политику NativeProjectConversion для повреждённых/отсутствующих
native целей; межформатная полнота остаётся отдельным I03.

## Проверки

Новый `CompilerGateFallbackChecks` и изменённый `ProjectGateRemovalChecks`:
**6 PASS, 0 FAIL**, terminal exit0 на опубликованной Core DLL.

Проверены ID0/1/255 × target13/16/17; все24 bytes действия сравниваются с
независимым literal source recipe, включая нулевой DWORD, WORD coordinates,
ID/next, reserved WORD, type32 и one1. Проверены sparse IDs, другая цель в0,0,
private snapshot, удаление/Undo/Redo и прежний first-free reuse.

Есть фактические DKM Save/reopen и семифайловый SaveCopy/reopen. Один export
fixture проходит gameplay terrain validation; это результат headless
валидатора, не запуск игры. Отдельный native→DKM+companion→delete→повторный
Save/reopen→compile проверяет, что payload retention не отменяет fallback.
При компиляции сравниваются исходные bytes/file set, revision, dirty,
counters, Undo/Redo, snapshot cost и отсутствие уведомлений.

До исправления четыре первоначальные новые группы завершались FAIL на старом
отказе compiler; прежний тест удаления проходил, поскольку ошибочно ожидал
отказ. Все старые guards удаления других сущностей/чужих записей сохранены.
Пятая новая группа добавлена для проверки source companion.

Все41 проекта решения собраны без предупреждений/ошибок. Финальная App и
проверки используют один и тот же Core hash. Промежуточная сборка из другого
workspace path дала другой byte hash DLL; окончательная поставка проверена
после согласования бинарных зависимостей, смешанных DLL нет.

Source/, Binaries/, fixtures, установленные карты и EN/RU literals не менялись.
Полный corpus не повторялся:1840 PASS/63 FAIL остаётся историческим результатом,
не результатом новой DLL. Поиск текста снятого отказа в том отчёте дал0 совпадений;
это не эквивалент нового полного прогона. GUI, аудио, DPI и игра не запускались.
