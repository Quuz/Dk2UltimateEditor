Пользователь уточнил: ориентиром являются официальные карты игры, а не
условная раскладка файлов французского редактора. Компиляция полного проекта
публикует ровно семь игровых файлов в Data/Editor/Maps:

- Name.kwd
- NameGlobals.kld
- NameMap.kld
- NamePlayers.kld
- NameThings.kld
- NameTriggers.kld
- NameVariables.kld

Globals.kld содержит последовательность полных native sections: 6E,78,AA,
8C,82,F0,A0,96,104 и исходные opaque sections 10E/FA, если они присутствуют
в исходном комплекте. Это упаковка, не повторное кодирование записей.
KWD получает ссылку типа0 на Globals и ссылки на пять остальных компонентов
карты и общую Data/Editor/GlobalVariables.kwd. Общий каталог не входит в семь
файлов карты. SaveCopy сохраняет его вне Maps для автономного повторного
чтения экспортированного дерева. GamePreview проверяет hash установленного
каталога до записи и не копирует его в Maps, не изменяет общие данные игры.

В памяти остаются отдельные редактируемые definition families. Полный native
export упаковывает их; изменённые definitions остаются внутри Globals.
Неполные синтетические/рабочие документы без definitions сохраняют прежнюю
возможность записи черновика. Запуск игры для них запрещают missing references.
Не превращать такие черновики в якобы готовые игровые карты пустыми definitions.

Служебные имена переменных/таймеров редактора сохраняются отдельно в
Data/Editor/EditorMetadata/Name.kwd.dk2names. Native loader поддерживает этот
путь и прежний adjacent sidecar (adjacent имеет приоритет). В игровом Maps
они не добавляют восьмой файл. Prepared game preview включает только игровые
семь файлов; DKM/ZIP остаются исходным редактируемым проектом и его архивом.

GamePreview принимает необязательное имя уровня. Ручные игровые тесты всегда
используют DK2Preview_6a88240eaf814f78. Collision refusal и descriptor-last
publication сохранены. Полный GUI/GameRunUi прогон в этом проходе не запускался;
Computer Use запрещён пользователем. Открытие настоящим официальным редактором
