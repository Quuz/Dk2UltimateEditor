## Область редактирования

`ReadExistingCreatureLevelModifiers` читает существующие tuple0x41/0xE0
из map Variables.kld или из сохранённых native records проекта DKM с его
явными поправками. Он не подменяет эту таблицу GlobalVariables.kwd.
`ReadCreatureLevelModifiers` остаётся прежним инвентарём исходных данных:
retained native source в нём по-прежнему побайтово исходный.

`CreateCreatureLevelModifierSession` создаёт независимый230-cell draft.
Для полного окна нужны все23 видимые характеристики ×9 уровней+FirstPerson.
Неполный источник не заполняется выдуманными значениями. Для частичных
существующих таблиц есть атомарный `SetExistingCreatureLevelModifiers`;
отсутствующий ключ не вставляется. Установленные общие определения не являются
целью этих методов. Новый код пока не подключён к окну продукта.

Контекст привязан к owner/revision/full fingerprint. Cancel не меняет живой
документ. Apply целиком проверяет все изменённые ключи, исходные DWORD и границы;
один batch создаёт один шаг Undo/один change increment. Равные signed значения
не нормализуют bytes и не создают команду. Действуют подтверждённые ранее
правила signed DWORD и ноль→100. После успешного Apply контекст закрывается.
Смена owner/revision, Undo/Redo, raw fingerprint change, закрытый контекст и
активный pen не дают применить старые полномочия.

## DKM: исходный архив отдельно от поправок

Исходный `.native-source-<SHA256>.zip` не переписывается. Его прежняя проверка
`ValidateRetainedNativeVariables` сохранена: каждое retained occurrence должно
буквально присутствовать в hashed source bundle. Поправки не выдаются за исходные
байты и не проходят через ослабленную проверку этого архива.

Для изменённых существующих level tuples добавлен частный раздел DKM **D2LM**,
сигнатура `0x4D4C3244`, версия1. Это расширение проекта нашего редактора,
а не дополнительный файл/раздел игрового комплекта. В старом редакторе DKM
такое расширение не проверялось. Официальный редактор использует игровой KWD
и семь скомпилированных файлов; D2LM в них не записывается.

| Смещение в D2LM | Длина | Содержание |
| --- | --- | --- |
| 0 | 12 | signature/version/payload length |
| 12 | 32 | SHA256 исходного retained byte stream |
| 44 | 4 | число поправок, не более230 |
| 48 | 4 | reserved=0 |
| 52 | 24×count | type/statistic/level/source offset/original DWORD/edited DWORD |

Каждая поправка адресует последний существующий occurrence ключа в исходном
retained stream. Проверяются hash, offset/alignment, точный key/original bits,
уникальность ключей/offsets, видимость/уровень и canonical signed edited DWORD.
Ноль в edited DWORD недопустим: его официальный encoding равен100. Поправка,
равная исходному signed значению, удаляется с восстановлением исходных bits.
Неизвестные записи, скрытые характеристики и ранние дубликаты не меняются.

Пустой D2LM имеет52 байта, нулевой hash/count/reserved и не сериализуется.
Без правок старый DKM не получает нового раздела. Непустому D2LM нужен исходный
companion с тем же retained byte stream; отсутствие/подмена/неоднозначность
companion не приводит к угадыванию исходника. Полные SourceFiles ZIP по-прежнему
проверяются существующим кодом архива. D2LM не разрешает придумать исходные
records и не хранит независимые произвольные native payloads.

В рабочем документе D2LM — отдельный внутренний буфер. Он участвует в общей
транзакции/Undo/Redo, dirty state, fingerprints, guarded Save и deep clone;
он не притворяется обычной игровой коллекцией в Files/Records. Все прежние
проектные section buffers остаются отдельными и неизменными при такой правке.
Общее окно свойств карты не разрешает менять D2LM как побочный эффект другого
дочернего редактора: прежняя проверка области продолжает его защищать.

## Сохранение и компиляция

Unified Save/Save As/temporary Save сохраняют D2LM вместе с прежним immutable
архивом. Новый target получает тот же исходный ZIP, а не пересобранный архив
с изменёнными значениями. Baseline после успешного Save включает D2LM.

`SaveCopy`, независимый project writer Save As и полный EditableCopy рядом с
ограниченным MAP также сохраняют необходимый companion для непустого D2LM.
Отсутствие исходного companion у такого проекта приводит к отказу, а не к
публикации заведомо неполной копии. Низкоуровневую conversion.Project сначала
следует сохранять через unified conversion Save, который привязывает архив.

При компиляции создаётся частная копия retained stream, в ней применяются
проверенные поправки, затем records вставляются в map Variables.kld. Сам
retained stream и архив не меняются. D2LM не попадает в игровые ссылки и не
увеличивает число игровых файлов. Размер/count Variables.kld не меняется при
правке существующего ключа. Реальный эффект в игре ещё требует M19.
