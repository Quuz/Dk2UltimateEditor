# Dungeon Keeper 2 Ultimate Editor

[English](../README.md) · [Участие в разработке](../CONTRIBUTING.md) · [Документация](INDEX.md)

**UltimateEditor** — редактор карт и сценариев Dungeon Keeper 2 для Windows. Это перенос редактора NovFR с C/Win32 на C#/.NET 10 и WPF, с русским и английским интерфейсами, Unicode, Undo/Redo и необязательным локальным MCP.

Проект находится на стадии разработки. Полное соответствие исходному редактору, игровые и аппаратные проверки ещё не завершены. Работайте с копиями ценных карт; [перечень приёмки](MANUAL_REMAINING_20261104.md) фиксирует подтверждённые результаты и остаток.

## Запуск

Стабильного релиза с тегом пока нет. Соберите проект или скачайте `UltimateEditor-windows` из успешной [Windows-сборки](https://github.com/Quuz/Dk2UltimateEditor/actions/workflows/windows-build.yml), когда она доступна.

1. Распакуйте всю папку сборки, сохранив DLL и остальные файлы рядом.
2. Установите .NET 10 Desktop Runtime для Windows, если он отсутствует.
3. Запустите `App/UltimateEditor.exe`.
4. Для управления через MCP используйте `Start-Editor-MCP.cmd`. Обычный запуск MCP не включает.

Нужные игровые определения берутся из вашей установки Dungeon Keeper 2. Текущий Save использует DKM/MAP и при необходимости ZIP с исходными native-данными. Native-экспорт или компиляция создаёт семь файлов карты в Maps; общие определения находятся отдельно. Переход обычного Save на KWD без DKM/ZIP ещё впереди.

## Возможности

Ландшафт, комнаты и владения; объекты и существа; параметры игроков; сценарии, отряды героев, области и патрули; маршруты камеры; определения игры, доступность, пул существ и переменные карты. Поддерживаются KWD, DKM, текстовый MAP и архивы выделений. Ограничения отдельных веток описаны в документации.

## Сообщить об ошибке

Создайте issue с номером сборки/коммитом, версией Windows, языком и масштабом экрана. Добавьте шаги воспроизведения, ожидаемый и фактический результат, скриншот/текст ошибки и минимальную карту, которую разрешено публиковать. Укажите результат открытия в официальном редакторе и игре. Один дефект — один issue; приоритет у потери данных, вылетов и неправильной записи карт.

## Сборка

Windows, .NET SDK 10.0.100 (или совместимый patch из global.json), PowerShell и Git:

```powershell
git clone https://github.com/Quuz/Dk2UltimateEditor.git
cd Dk2UltimateEditor
./build.ps1
```

Результат: `artifacts/PreFinal/App/UltimateEditor.exe`. `./build.ps1 -Validate` запускает расширенный валидатор; для corpus/игровых и интерактивных проверок нужны дополнительные входы. Сама компиляция не доказывает игровую совместимость.

Единое решение — `DK2MapEditor.slnx`, текущий C#-код — в `src`, проверки — в `tests`. `Source` и `Binaries` сохраняют оригинальные материалы и используемые ресурсы. Внутренние имена сборок `DK2MapEditor.*` оставлены для совместимости. Подробная структура — в [английском README](../README.md).

Исходный французский редактор — [NovFR](https://github.com/NovFR/DK2-Map-Editor). **Доработка, развитие и новые функции UltimateEditor — Quuz**, при участии сообщества. **DiaLight — автор [Flame](https://github.com/DiaLight/Flame), присоединяется к дальнейшему развитию UltimateEditor.** Flame остаётся отдельным проектом. Авторство и происхождение материалов: [NOTICE.md](../NOTICE.md). История прежних отчётов: [PROJECT_HISTORY_RU.md](PROJECT_HISTORY_RU.md).
