# Проценты характеристик по уровням: окно EN/RU и копия каталога

19 октября 2026, CreatureLevelModifierWindow-20261019.

В **Свойствах карты** появилась кнопка **«Проценты характеристик по уровням…»**
(EN: **Creature level percentages…**). Окно редактирует23 характеристики,
уровни2–10 и First Person/вселение. Диапазон −10000…10000, стрелки изменяют
число на единицу. Ноль записывается как100 по правилу официального writer.

Это дочерний частный контекст: Apply в нём переносит правки в черновик свойств
карты. Только **«Применить всё»** родителя меняет карту одним Undo. Отмена
родителя отклоняет и уже принятые дочерние правки. Непринятый ввод ребёнка
блокирует общий Apply. Экспорт копии каталога — отдельное явное действие;
он не применяет правки карты и не увеличивает игровой комплект.

## Источник общих значений

При открытии используется выбранный ранее в этом окне свойств каталог;
затем настроенный GameResources.Root/Data/Editor/GlobalVariables.kwd;
затем загруженная или сохранённая в native-source ZIP таблица. Если каталога
нет, достаточно полной собственной таблицы карты; иначе окно просит выбрать
GlobalVariables.kwd. Сохранённые пути архива — подписи: Capture читает его
проверенные байты, а не открывает эти пути на диске.

Кнопка **«Выбрать GlobalVariables.kwd…»** открывает системный Open dialog.
Источник нельзя менять при непринятых правках: закрытие/отмена явно отклоняет
такой ввод, а выбранный каталог остаётся доступен при повторном открытии ребёнка
из того же родителя. Повреждённый/неполный файл не заменяет рабочий контекст;
ошибка показывается в статусе. Снимок ограничен64MiB, входные и выходные массивы
не используются как общая изменяемая память.

Переключение характеристики сначала проверяет все10 чисел прежней страницы.
При ошибке прежняя страница и введённый текст сохраняются. Смена EN/RU меняет
подписи/список/статус, сохраняя выбранную характеристику и набранные строки.
Кнопка **«Вернуть значения каталога»** заменяет частную страницу значениями
выбранного источника. В оригинальном dialog238 отдельной кнопки Reset нет;
это явная современная команда, не выдуманный source callback.

Enter — Apply дочернего окна, Escape — Cancel. При открытии фокус получает
список характеристик либо выбор каталога. Реальное поведение фокуса/клавиатуры,
размеры на DPI и системные диалоги ещё требуют ручной приёмки.

## Экспорт общего каталога

**«Экспортировать копию каталога…»** проверяет текущую страницу и формирует
полный снимок230 видимых значений относительно захваченного каталога.
Неизменные signed значения сохраняют исходные DWORD bits; изменённые используют
подтверждённое signed SHORT→DWORD и ноль→100. Ранние дубликаты, скрытые9 IDs,
неизвестные записи, headers и продолжение секции (в реальном каталоге0xBE)
сохраняются побайтово. Это не экспорт произвольных bytes из DKM source archive.

Системный Save dialog по умолчанию предлагает **GlobalVariables-copy.kwd**.
Исходный путь выбранного каталога отклоняется; используйте другой файл.
Перед заменой назначения проверяется тот же owner/input revision, для которого
получен путь. Смена документа/ввода/языка во время диалога отменяет старое
полномочие. Запись идёт через новый staging file, flush и атомарную замену.
Частичная запись или поздняя инвалидность сохраняют прежнее назначение.
После экспорта частные правки карты остаются в ребёнке до Apply или Cancel.

Каталог не становится восьмым файлом карты. Игра получает семь обычных файлов,
а новая копия общего каталога является отдельным пользовательским результатом.
Автоматически заменять установленный GlobalVariables.kwd не требуется.

## Короткая ручная приёмка

1. Запустите текущую сборку, откройте копию карты или создайте новую.
   Вкладка **«Свойства» → «Свойства карты» → «Проценты характеристик по уровням…»**.
2. Если источник не подхватился, выберите
   `D:\Games\DK2\Dungeon Keeper 2\Data\editor\GlobalVariables.kwd`.
   Ожидаются23 характеристики, поля2…10 и «Вселение».
3. Введите для здоровья на уровне2 значение125, перейдите к другой
   характеристике и вернитесь. Попробуйте10001: переход/Apply должны оставить
   текущую страницу и показать ошибку. Верните125. Смените EN/RU: текст/выбор
   должны остаться прежними. Проверьте стрелки на−10000 и10000.
4. Нажмите Apply ребёнка, затем Cancel родителя. Повторное открытие должно
   показать исходные значения. Повторите125, Apply ребёнка и «Применить всё»:
   один Undo должен вернуть прежнее состояние целиком, Redo — правку.
5. В дочернем окне экспортируйте **GlobalVariables-copy.kwd** в отдельную папку.
   Карта при этом не применяется. Исходное имя каталога в качестве назначения
   должно отклоняться. Отмена Save dialog не создаёт файла.
6. Сохраните копию проекта DKM и откройте снова. Для проверки игры используйте
   только семь файлов **DK2Preview_6a88240eaf814f78** и
   `DKII-DX.exe -q -level DK2Preview_6a88240eaf814f78`.
   Изменение125 проверяйте на существе **уровня2**, а не на уровне1.
   Нужна отдельная фактическая проверка значения/эффекта, не только успешной загрузки.

Результаты фокуса/Tab/Enter/Escape/системных диалогов/DPI и игры заносятся в
[MANUAL_ACCEPTANCE_RU](MANUAL_ACCEPTANCE_RU.md). Все23 области полной цели
сохранены; кодовая готовность этого окна не завершает весь проект.
