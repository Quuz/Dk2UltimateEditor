# Отдельные команды добавления условий и действий

ScenarioInsertionCommands-20261018. **MC03 закрыт по коду внутри I17.**
MC04–MC06, вложенные страницы I10 и физическая приёмка M18/M20/M23 остаются
открыты. Этот этап не объявляет завершённым весь сценарный редактор.

## Назначение кнопок

| Команда | Куда добавляется событие |
| --- | --- |
| Новое корневое условие | В конец корневой цепочки выбранной точки сценария, включая пустую точку. |
| Добавить условие | При выбранном условии — в конец его дочерней цепочки; при выбранном действии — в конец цепочки его соседей. |
| Вставить условие перед | Перед выбранным условием или действием по входящей связи именно выбранного в дереве вхождения. |
| Добавить действие | При выбранном условии — в конец его дочерней цепочки; при выбранном действии — в конец цепочки его соседей. |
| Вставить действие перед | Перед выбранным событием внутри условия; исходный запрет перед корневым условием сохраняется. Действие не становится первым событием корня. |

«Новый корень» создаёт условие внутри существующей точки, а не новую точку
сценария. Различие New Point/Open existing остаётся отдельным MC06.
Существующий общий выбор связи/типа сохранён как дополнительный способ
редактирования. Клавиша Insert на событии использует явную InsertCondition;
современное редактирование несвязанных цепочек через прежний generic caller
также сохранено. Insert на корне точки по-прежнему относится к вставке точки.

Все новые команды открывают прежний общий мастер и его private document,
параметры, aliases, repeat и прямоугольные действия. Начальный тип берётся из
ранее сохранённого выбора соответствующей категории и фильтруется по всем
реально затронутым owner scopes. До Finish карта не меняется. Cancel и Back
не вставляют событие; принятое Finish использует существующие атомарные
ApplyScenarioEditorCreation, счётчик и Undo. Для прямоугольного действия
сохраняется прежний пакет нескольких событий с одной историей.

## Контекст и защита связей

ScenarioInsertion.Resolve — новая функция чтения графа, без записи файлов.
Она получает текущую проекцию точки и выбранное вхождение, проверяет
физический root, путь по дереву и все предшествующие связи на этом пути.
Append идёт по OR/next до свободного хвоста; не заменяется вставкой перед
существующим child. Для действия берётся цепочка его фактического родителя.
Для shared events не угадывается единственный parent по числовому ID.

Повреждённые IDs, потерянный target, цикл цепочки, чужая/устаревшая проекция
и неподходящая команда отклоняются. App дополнительно проверяет вкладку,
живого владельца, контекст, ревизию, GameResources, активный карандаш и
неизменность выбранного node после CommitFields. Если мастер уже открыт,
новая команда сохраняет его и показывает EN/RU сообщение.

Исходные места: Triggers_Select.c IDs122/123/124/127/128 и SelectChanged;
Triggers_Triggers.c:1962–2009 — Insert либо child/root TVI_LAST;
Triggers_Actions.c:1965–2011 — Insert либо child/sibling TVI_LAST;
Triggers_Select.c:1261–1347 — связывание с предшественником/родителем/root.

## Доказательства и ручная приёмка

Новый CLI `--scenario-insertion-only` проверяет native/DKM, вложенную смесь
условий/действий, корневые/дочерние/соседние хвосты, вставку перед событием,
полный private Cancel, счётчик/Undo/Redo и все прежние bytes событий с
независимыми packed offsets. Отдельно проверены shared occurrence, пустой
корень, запрет root action, foreign/stale projection, изменённая связь,
cycle/dangling/zero-ID. Фактические результаты — CURRENT_STATUS и
artifacts/Evidence/ScenarioInsertionCommands-20261018.

Четыре WPF случая EN/RU × native/DKM подготовлены и только скомпилированы.
Они охватывают кнопки, категории мастера, отмену/Finish, конечные связи,
Undo/Redo, смену языка, уже открытый мастер, pen/вкладку/закрытого владельца
и общую клавишу Insert. GUI, renderer, Computer Use и игра не запускались.

Вручную:

1. Открыть точку сценария с корневыми A → B и дочерними событиями A:
   C → действие D → E. Выбрать A, добавить условие и действие: каждое должно
   появиться в конце её дочерней цепочки. При выбранном D добавление также
   идёт после E, а не внутрь D или перед D.
2. При выбранном D выполнить «Вставить … перед»: новое событие появляется
   между C и D. «Новое корневое условие» добавляется после B независимо от
   выбранного вложенного события. Cancel оставляет связи прежними.
3. Принять мастер, сделать Undo/Redo, сохранить и снова открыть карту.
   Проверить EN/RU, доступность кнопок, фокус и DPI; выполнить сценарий в игре.
   Игровой комплект всегда7 файлов DK2Preview_6a88240eaf814f78; запуск
   `DKII-DX.exe -q -level DK2Preview_6a88240eaf814f78`.
