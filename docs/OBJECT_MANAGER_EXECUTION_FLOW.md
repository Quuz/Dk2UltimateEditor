# Запуск добавления и изменения из менеджера

17 октября 2026, ManagerExecutionFlow-20261017. Внутри I17 подключён порядок
команд менеджера: Ask Options, редактирование шаблона, single/multi Modify,
обязательный или выбранный Preview и прямое применение. Другие команды и
Config остаются в [конечном перечне](OPEN_FUNCTIONS_RU.md); I17 целиком не закрыт.

## Исходник и действующий код

Эталон — Source/Sources/Things/Things_Manager.c: Things_ManagerModify и
Things_ManagerAdd. Modify использует первоначальное число выбранных строк
до фильтрации связанных со сценарием объектов. Одиночный объект вызывает
Things_Select с THING_FLAGPOSITION; для исходной группы AskOptions решает,
показывать ли ModifyOptions. Add спрашивает options до создания WorkList.
Пустой WorkList завершает команду до Preview. Непустой список показывает
Preview по флагу либо при неразрешённых предупреждениях/запросе замены.

В приложении маршруты находятся в ObjectManagerWindow.Flow.cs и
ObjectBatchWindow.ManagerFlow.cs. ObjectManagerFlowRules.cs содержит чистое
решение о необходимости options/preview; Validation компилирует ссылку на
тот же файл, без второй реализации и без зависимости от WPF.

| Команда | Порядок |
| --- | --- |
| Add | Необязательные Addition options → создание плана из общего шаблона → Preview при необходимости либо применение решений по умолчанию |
| Modify одного исходно выбранного объекта | Локальное окно свойств с абсолютными X/Y → создание плана → Preview при необходимости либо применение |
| Modify исходной группы | Подтверждение связанных объектов → необязательные Modification options → план по оставшимся объектам и общему шаблону → Preview при необходимости либо применение |
| Общий шаблон | Отдельное окно параметров шаблона; не создаёт план, не применяет изменения к карте и не создаёт Undo |

Четыре флажка Ask Options/Preview независимы для Add и Modify. Они хранятся
в runtime-сеансе менеджеров, как остальные их предпочтения. Карта, игровой
экспорт и Undo этих настроек не содержат. Параметры options применяются по OK;
их Cancel не меняет прежние настройки. Общий редактор шаблона сохраняет
runtime/raw draft при закрытии согласно существующему поведению шаблонов.
Закрытие шаблона не означает применение его к карте.

## Область и решения Preview

Для режима One используется общая точка назначения. Rectangle/Random
используют карту либо фактический прямоугольник выделения согласно режиму
менеджера. Добавление в выделение без прямоугольника отклоняется. Его X/Y
не перезаписывают сохранённую точку назначения менеджера.

Флаг Preview можно выключить. Неигнорируемые terrain/fatal/enemy/incompatible
предупреждения, replacement Ask и source IgnoreAsk для границ всё равно
открывают решения. Игнорирование одного предупреждения не скрывает другое.
Hard-limit строки остаются заблокированными; показ окна не даёт права
записать объект за пределами карты. Подтверждение удаления сценарной связи
также остаётся явным. Preview показывает список решений, без повторного
редактирования шаблона. OK принимает эти решения, Cancel не применяет план.

Прямое применение использует те же Core-планы, проверки layout/актуальности
и [локальную историю менеджера](OBJECT_MANAGER_COMMANDS.md). Отдельного writer,
обхода Undo или обхода stale guards не добавлено. Пока выполняется команда,
другие команды менеджера блокируются; закрытие/смена документа освобождает
дочерние окна. Ошибка до применения не сообщается как успех. Если данные уже
приняты, а последующее обновление завершилось ошибкой, сообщение прямо
говорит о выполненной операции; предыдущие принятые правки не откатываются
под видом ошибки ещё не выполненной команды.

## Ручная приёмка M20

На собственной копии карты, с Undo после каждого применённого шага:

1. Выбрать семью существ, настроить общий шаблон, закрыть его. Число объектов
   и история карты прежние; повторное открытие показывает шаблон.
2. У Add выключить оба флажка. Добавить один объект в допустимую точку:
   команда применяется напрямую; локальный Undo возвращает карту.
3. Включить Preview: перед записью появляется список решений. Cancel сохраняет
   карту, OK применяет выбранное. Включить Ask Options и отменить options:
   Preview не открывается и объект не добавляется.
4. В Rectangle выбрать режим только выделения и прямоугольник 2×2. Добавление
   использует его клетки; сохранённая точка назначения менеджера прежняя.
5. Выбрать два объекта, применить один изменяемый параметр из шаблона с
   Ask Options, без Preview. Проверить оба объекта и один локальный Undo.
6. Выбрать один объект при включённом Ask Options: открываются его свойства
   с X/Y. Изменить координаты и отменить; затем применить и проверить Undo.
7. При выключенном Preview создать предупреждение или replacement Ask:
   окно решений всё равно появляется. Заблокированную строку нельзя принудить
   к недопустимой записи. Проверить подтверждение разрыва сценарной связи.
8. Проверить EN/RU, Tab/Enter/Escape, длинные сообщения, DPI и закрытие
   документа с дочерним окном. Общая инструкция —
   [MANUAL_ACCEPTANCE_RU](MANUAL_ACCEPTANCE_RU.md).

Для игрового результата использовать только DK2Preview_6a88240eaf814f78,
ровно семь файлов и DKII-DX.exe -q -level DK2Preview_6a88240eaf814f78.
Ранее подтверждённый пользователем запуск карты сохраняется как результат
того экземпляра; новые команды менеджера им автоматически не приняты.
