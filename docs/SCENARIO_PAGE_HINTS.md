# Информация об отряде и ввод на страницах псевдонимов

Текущий основной код,13 октября2026. Доказательства этого блока находятся в
`artifacts/Evidence/ScenarioPageHints-20261013`. Окна и игра не запускались.

## Численность выбранного отряда

Оригинальный `Triggers_TriggerDlgParams` обрабатывает `LVN_ITEMCHANGED` для
трёх условий: `TRIGGER_DEATHSINBAND`, `TRIGGER_JAILEDINBAND` и
`TRIGGER_STUNNEDINBAND`. После выбора отряда он обновляет подпись102 через
`Heros_GetHerosCount`. Эта функция считает последовательные активные слоты
до первого `isvalid==0`; активные слоты после разрыва в число не входят.
Подпись носит информационный характер и не ограничивает числовой операнд
условия. Временный list ID равен `Band->id+1`; Store вычитает1. Поэтому
хранимый ID0 обозначает настоящий отряд0, а не отсутствие выбора.

Современная страница показывает «В отряде героев: N» и обновляет эту подпись
при выборе отряда, Reset и переключении EN/RU. Для native используются
исходные stop-условия загрузчика `Files_Game.c`: нет ID существа или behavior —
конец активного префикса. Предел16/stride32/start51 и смещения28/15 сверены
с оригинальным `GAMEBANDHERO`. Для проекта читается исходный `isvalid`.

`ReadScenarioBandPopulation` проверяет владельца/ревизию/снимок черновика и
читает данные без записи. Неизвестный или неоднозначный ID, неподтверждённый
layout и повреждённый конечный маркер не получают выдуманной численности:
страница сообщает, что она недоступна. Это защитное поведение для malformed
imports; оригинальный поиск возвращал первый совпавший ID. После изменения
документа старая подпись очищается вместе с инвалидированием страницы.
Apply, Cancel, операнды, aliases, счётчики и Undo подсказкой не меняются.

## Ограничения обычного ввода

| Страница | Элементы исходника | Ограничение набора текста |
| --- | --- | --- |
| `TRIGGER_VARIABLE` |210|4 символа числа|
| `ACTION_SETVARIABLE` |210|4 символа числа|
| `TRIGGER_TIMER` |300/301/302|2 символа каждого из часов/минут/секунд|

Эти `EM_LIMITTEXT` восстановлены через WPF `MaxLength`. Они ограничивают
обычный набор/вставку текста. Программное заполнение при открытии не обрезает
старые импортированные значения. Raw-поля и запись проверенного черновика
остаются прежними. Минуты и секунды страницы `TRIGGER_TIMER` по исходнику
принимают60–99 и участвуют в обычном сложении; ограничения0–59 относятся к
другим страницам, `TRIGGER_TIMEELAPSED`/`ACTION_DISPLAYTIMER`.

## Проверка и её границы

Source capture связывает семь исходных файлов с хешами: оба диалога, построение
списка отрядов, исходную функцию подсчёта, native загрузчик и две структуры.
Модель проверяет три страницы × семь независимых масок активных слотов × два
формата:42 случая, включая пустой/полный отряд, отряд0 и активный хвост после
первого неактивного слота. Отдельно проверены обе native stop-причины,
повреждённый проектный end marker, неизвестные/дублированные ID и
foreign/stale/nested guards. Чтение сравнивается с полными буферами, историей,
ревизией и editor counter. Случаи включены в существующую named-page группу.
WPF проверка показа/смены языка подготовлена и компилируется; не исполнялась.

Проверки и сборка фиксируются в CURRENT_STATUS. Последний полный корпус
отдельно привязан к своему checkpoint/Core SHA; адресный запуск текущих
страниц не выдаётся за новый полный прогон, физическую проверку или готовность
«только ручные». Полная цель и все23 строки FEATURE_PARITY сохраняются.

## Ручная проверка EN/RU

1. На копии карты создайте отряд с двумя героями. На странице условия
   «Погибшие в отряде», «Заключённые в отряде» или «Без сознания в отряде»
   выберите его. Подпись должна показать2; выберите другой отряд — число
   должно обновиться. Операнд количества остаётся введённым вами.
2. Переключите EN/RU: подпись переводится, выбор/количество не меняются.
   Cancel не меняет карту. Apply меняет только ваши параметры одной операцией
   Undo. После изменения карты заново откройте окно.
3. На странице сравнения/изменения переменной проверьте набор пятой цифры
   в числовом поле. В сравнении таймера проверьте третью цифру каждого поля
   времени; минуты60 и99 должны вводиться. Старый импортированный операнд
   при простом открытии/Cancel должен сохраниться.

файлов и `DKII-DX.exe -q -level DK2Preview_6a88240eaf814f78`.

Оригинальные три AREA-условия показывают площадь, а `TRIGGER_CLAIMAREA`
также число клеток периметра по формуле исходника. Подсказки привязаны к

информация ещё не показана; нельзя подменять выбранный контекст произвольным
ID зоны или первой найденной связью при shared graph. Требуется передать
подтверждённого владельца в страницу и сохранить его через мастер/Back/Next.
Остальные caller/исторические и физические ворота не закрываются этим блоком.
