# Named map speech and text editing

Source-derived implementation, 2026-10-07. The [source/resource audit](MAP_SPEECH_TEXT_SOURCE_SCOPE.md) separates map metadata from read-only game resources. This stage implements the named editing workflow; it does not establish external-player, historical visible-GUI or in-game acceptance, and it does not author or translate STR/SDT files.

## Human workflow

The Properties-tab Speech and text button opens a modeless EN/RU panel. Its two tabs expose all **thirty storage fields**: a speech-bank name, five speech IDs, a text-table ID, seven ordinary text IDs and eight creature/text replacement pairs. Numeric controls have explicit increment/decrement buttons. The text table contains all 59 original entries including None, with their actual nonordinal IDs and Current/Briefing filenames; creature replacements include ordinary creatures, elites and heroes. Unknown imported values remain visible and are not silently selected as None.

Changes remain drafts until Apply all metadata. Apply is one atomic edit with exact Undo/Redo; Discard/refresh drops the draft, and Close/Escape does not apply it. Switching language retains invalid/pending input, the active tab and selected preview rows. Current ordinary-property edits are committed before applying the panel and invalidate old authority rather than silently rebasing it. Raw byte mutation, edit+Undo, replaced/restored documents, unloaded workspaces and closed shells also invalidate authority. Configuration and resource browsing do not dirty map bytes, history, terrain selection or the internal copy buffer.

The original asymmetry is explicit: **None in the text-table selector leaves the stored table ID unchanged**; None in the speech-bank selector clears only the bank name, not its five IDs. Generic raw field editing remains separate. Changed text IDs use 0–9999. Changed speech IDs use 0–Mentor-count, with fallback 1505, not the length of the selected custom bank. Imported out-of-range values may remain unchanged during unrelated edits. Preview IDs are one-based and zero is no sound; typed rows carry actual IDs instead of relying on a visually sorted index.

## Resources and playback

The panel can select a game/resource-root folder and an external player, or use the system's default MP2 association. Explicit settings survive the existing JSON/session settings route; detection only walks ancestors of an existing loaded map looking for the resource layout. A portable resource folder is allowed and no game executable is launched by detection. New/exported DKM projects are not assumed to live inside a game installation.

Current/Briefing STR browsing and corresponding speech captions use bounded immutable readers. SDT rows show resource ID, stored name and payload length. Missing or malformed files give localized unavailability without changing metadata or inventing audio; missing corresponding text does not disable otherwise valid audio. Folder choices retain the three installed demo folders which have no bank file. Resource payloads use the original configured glyph diagnostics, not an invented UTF-8/CP1252 text decoder or game-asset translation.

Play selected sound/double-click extracts the selected header-40 payload unchanged to a uniquely owned MP2 file. Default playback uses the file association; custom playback uses a separate argument-list entry, not a composed shell command. Closed/replaced owners cannot launch playback. Launch failures are reported locally. Cleanup considers only files created by this preview session, rejects a replaced reparse directory and never recursively deletes a directory or removes unrelated files. An external player can keep an owned preview locked: cleanup then leaves that file rather than forcing deletion. Retry/notification for real locked-player cases remains an acceptance/workflow limitation, not a proven cleanup guarantee.

## Formats and guards

The fields update original metadata, not new game fields or an editor companion. Native speech names now use strict Windows-1252 like the project's ANSI char[32]. Changed names must be enumerated safe SPEECH_ folder names and fit 31 bytes plus NUL. Unchanged imported names can occupy all 32 bytes; no-op/unrelated editing retains opaque bytes after NUL. Native compilation follows original CopyMemory and copies exactly **32 raw bytes**, rather than re-encoding a display caption. Native text-table storage is **BYTE**, while project storage is **WORD**; other text/speech IDs are WORD and replacement creature IDs are BYTE.

Project V1 exposes no fields in this panel; V2/V3/V4 expose the bank name only; V5/V6/V7 expose all thirty fields. Absent fields are disabled, never inferred from padding. Explicit historical upgrade introduces missing fields through the existing guarded route. Future/unknown layouts refuse panel edits. A complete available-field request is preflighted against owner, monotonic revision, original bytes and verified field layout; invalid/partial/duplicate requests do not mutate data. Mixed-transaction failure restores bytes and redo; no-op produces no notification/history, and zero history disables tracking without disabling editing.

## Evidence and acceptance boundary

It tests all 58 nonzero source tables and every source creature in all eight replacement slots for both formats, numeric bounds, malformed imports, full-width/padded speech names, exact compiler copying, stale/foreign/raw/rollback/no-op/zero-history behavior, every historical/future metadata fixture, upgrades and save/reopen. The corpus runner compares read-only speech/text projections before/after save/reopen and metadata Undo; real text-project checks also compare project save/reopen. Installed resources and source input copies remain unchanged.

Four actual-command WPF fixtures cover EN/RU × project/native, actual controls, None behavior, Mentor bounds independent of custom-bank size, current/briefing/caption previews, payload extraction, launch interception, JSON configuration, pending DataGrid commits, raw changes, draft/language retention, bank-only historical layouts and document/shell lifetime. Automated playback interception proves extraction and dispatch preparation, **not audible playback by a real codec/player**. Owned/unowned cleanup has a separate fixture.
