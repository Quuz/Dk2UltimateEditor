# Длинное имя карты в общих свойствах

Этап MapNameOverflow-20261017. Основной продукт — единый `src/` и решение
`DK2MapEditor.slnx`; исходники Source/Binaries остаются эталоном.

## Поведение формы

При Apply общих свойств имя длиннее64 символов вызывает вопрос с ответами
«Да», «Нет» и Cancel. «Да» копирует начало нового имени, до63 символов.
«Нет» сохраняет прежнее имя черновика и применяет остальные настройки.
Cancel, крестик и Escape оставляют родительскую форму открытой, без записи
новых общих параметров даже в приватный документ. Ранее принятые изменения
вложенных редакторов остаются в черновике до общего Apply или Cancel.

У исходника есть граница: имя ровно64 символа не вызывает вопрос, но при Apply
сокращается до63. Это поведение сохранено именно в команде свойств. Обычный
API UpdateMapGeneralSettings продолжает отклонять новое слишком длинное имя;
неизменённые импортированные полные поля и их padding он сохраняет как раньше.
Пустое имя и имя длиной63 принимаются без вопроса.

«Да» — ответ по умолчанию. Флажок «Запомнить Да» отключает «Нет», но Cancel
остаётся доступен. Флажок запоминается только по «Да». Память действует для
новых форм и карт текущего запуска, переживает Undo/Redo и Cancel родительской
формы после ответа, но не записывается в карту или настройки. Отдельная кнопка
возврата вопроса сбрасывает только этот ответ.

## Исходник и форматы

`Source/Sources/Properties/Map/Properties_Map_Global.c:Properties_MapReset`
проверяет `WM_GETTEXTLENGTH > 64`, использует REQUEST_BUFOVERFLOW=0x4,
MB_ICONQUESTION, default1, MBF_AUTOREPLY и MBP_FOLLOWMOUSE. `Result==0`
возвращает к форме, `Result==1` читает имя через GetDlgItemText с buffer64,
`Result==2` пропускает чтение имени и продолжает сохранение. Последний gadget
в Misc_Requests.c переводится в ReturnCode0. Ответы и тексты определены
в `Source/Sources/Datas/Texts_Map.c`. Misc_Requests.c сохраняет бит только
после ответа по умолчанию; исходная Config.RequestsFlags живёт в сеансе.

MAPPROPERTIES v1–v7 хранят64 байта имени Windows-1252, native GAMEINFO хранит
128 байт UTF-16LE. Оба проверенных writer требуют завершающий ноль, поэтому
новое имя занимает до63 ANSI-байтов или UTF-16 units. Native Unicode, включая
русский, остаётся современным расширением: сокращение не разрывает surrogate
pair, поэтому на такой границе результат может занимать62 units. Непредставимое
новое ANSI-имя по «Да» отклоняется прежним encoder; «Нет» может его отбросить
и сохранить другие допустимые настройки. Никакая глобальная кодировка не меняется.

## Реализация

EditorMapNamePlan фиксирует исходный MapGeneralDraft и введённый текст. Для
общих свойств он связан также с MapPropertiesSession: проверяются живой
документ, приватный документ, revision/fingerprints, закрытие/подмена session,
активные транзакции и pen stroke обоих документов. EditorMapNamePolicy
использует общий EditorRequestPreferences и единственный активный lease.
Copy/Keep меняют только результат запроса и предпочтение0x4, сами не пишут карту.

MapPropertiesWindow сначала проверяет размеры и прочие общие поля. Затем
получает Copy/Keep, повторно проверяет форму и план и только после этого
записывает общие параметры в приватный документ. Изменение полей, смена языка,
документа, вкладочного черновика или отдельного дочернего окна не даёт старому
ответу применить устаревшие настройки; изменение и возврат прежних значений
тоже не оживляют запрос. Повторный Apply во время вопроса блокируется.

Следом действуют прежние отдельные запросы большой карты и обрезки. Ответ
на имя не разрешает их автоматически. Ошибка показа вопроса не считается
согласием. Общий Apply остаётся одной принятой операцией с полным Undo и
исходным счётчиком; «Нет» может принять равные настройки и прежнее имя, как
существующая команда свойств. Выбранные пользователем современные Undo
предметов с прежним порядком/целью и Undo паузы/сценария сохранены.

Окно имеет EN/RU, оригинальный Question32.ico, default Yes, Cancel/Escape
и размещение около указателя в рабочей области монитора с CenterOwner fallback.
Физические focus/keyboard/mouse/audio/multimonitor/DPI требуют ручной приёмки.
Новые sidecar или игровые файлы не добавляются; экспорт по-прежнему семифайловый.

## Проверки и ручная приёмка

Evidence: `artifacts/Evidence/MapNameOverflow-20261017`. Модель проверяет
18 native/DKM вариантов длин0/63/64/65/100 и ответов Copy/Keep/Cancel,
полные ожидаемые bytes по независимым offsets, приватность подготовки,
композицию с числом игроков, один родительский Undo/count, Save/reopen,
исторические MAPPROPERTIES v1–v7, Unicode boundary и импортированное полное
поле. Дополнительно проверяются remember/reset/restart/Undo/outerCancel,
общий lease с большой картой, callback/raw/foreign/stale/private/live pen,
закрытие session и сохранность прежней общей валидации.

WindowsSmoke подготовлен и собран: native/DKM × EN/RU, default Yes,
checked No/Close, Keep, ровно64, remember через Cancel/Undo, reset,
смена языка и полей, ошибки доставки и недопустимые размеры. Он не запускался.
Редактор, renderer, игра и звук инструментами не исполнялись.

Ручная проверка: открыть общие свойства, по очереди ввести имена длиной63,
64 и65; для65 проверить «Да», «Нет», Cancel/Escape/крестик. Вместе с именем
менять другую общую настройку и проверять её сохранение по «Нет». Проверить
флажок, его сброс, новый запуск, Undo/Redo, русское native-имя, вложенные
настройки и запрос размера после вопроса об имени. Сравнить EN/RU, фокус,
клавиатуру/мышь/audio/DPI. Реальный игровой тест только
DK2Preview_6a88240eaf814f78 через `DKII-DX.exe -q -level DK2Preview_6a88240eaf814f78`.

Общие результаты: [CURRENT_STATUS](CURRENT_STATUS.md). Все23 области и семь
очередей сохраняются в [REMAINING_WORK](REMAINING_WORK.md); этот маршрут
не объявляет завершение полного соответствия редактора.
