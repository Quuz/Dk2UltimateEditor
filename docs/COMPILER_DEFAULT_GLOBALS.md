# Базовые определения при возврате параметров к исходным

24 октября 2026, CompilerDefaultGlobals-20261024. Исправлен выбор между
копированием определения из выбранной native-базы и его генерацией из DKM.

## Ошибка и исправление

DKM создаёт массив глобального семейства при первом изменении его параметров.
Если затем вернуть все значения к исходным, массив остаётся в документе.
Раньше компилятор всё равно переписывал известные поля выбранной базы
значениями DKM. Поэтому результат зависел от того, менял ли пользователь
параметры раньше, даже когда итоговые значения были одинаковыми. Отличающиеся
значения базы могли пропасть; её дата при этом оставалась прежней.

В исходном `Compiler_TaskGenerate` генератор каждого из семи семейств
вызывается только при `Properties_GlobalChanged`. Иначе карта ссылается на
базовое определение, а прежний файл переопределения удаляется. В нашем
семифайловом формате базовые секции включаются в общий `Globals.kld`.
Теперь при исходных значениях сохраняются **все байты выбранной базовой
секции**, независимо от наличия массива DKM. Семейство с реальным изменением
по-прежнему проходит проверку layout, запись параметров и обновление даты.

Проверка изменения остаётся прежней: исходные project-значения сравниваются
с reset defaults до сужения к BYTE/WORD. Отсутствие массива также сохраняет
базу. Разбор полей, порядок definitions, обработка параметров выстрелов,
запись остальных файлов, Undo и raw native SaveCopy не изменены.

## Подтверждение

Новые девять групп проверяют:

- Все семь семейств — terrain, rooms, doors, traps, keeper spells, creatures,
  creature spells — после изменения и возврата к исходному значению, для
  целей 13/16/17. База содержит намеренно отличающиеся значения. Сравниваются
  целые секции, включая заголовки, даты и непрозрачные байты.
- Поочерёдное реальное изменение каждого семейства при остальных шести
  массивах с исходными значениями: изменение применяется, остальные секции
  сохраняются буквально.
- Реальную запись ровно семи игровых файлов на основе установленной
  `level1.kwd`: `Globals.kld` совпадает целиком с вариантом без массивов;
  после загрузки совпадают все семь полных секций внутри общего файла.

Компиляция не меняет source/basis bytes, историю, revision, dirty state,
счётчики и уведомления исходного документа. До исправления получено 9 FAIL;
после — 9 PASS, ExitCode0. Первый запуск после исправления дал 8 PASS/1 FAIL:
сам `Globals.kld` уже совпадал, но тест ошибочно сравнивал весь упакованный
файл после загрузки с одной standalone-секцией. Исправлен только способ
выделения секций в тесте; продукт дополнительно не менялся.

Связанные пять групп дат повторены из-за изменения общей ветки генерации:
5 PASS, включая сужение WORD, отказ для изменённого future layout и raw
SaveCopy. Полное решение из 41 проекта собрано без предупреждений и ошибок;
проверки и опубликованное приложение используют один Core. Архивы обновлены.
Логи, terminal codes, source-ветки и hashes:
`artifacts/Evidence/CompilerDefaultGlobals-20261024/`.

Полный корпус и несвязанные успешные группы не повторялись. Исторические
1840 PASS/63 известных отказа не являются полным результатом текущей DLL.
Редактор, игра, WPF и Computer Use не запускались; игровая проверка остаётся
ручной. Установленные карты и эталонные файлы не менялись.

Это конкретное исправление I02, а не закрытие всей сверки компилятора.
Продолжается конечное сопоставление metadata/player/AI, других writers,
validator и version routes. Открыты прежние 8 кодовых и 23 ручные группы.
