В GAttribs 38 редактируемых строк: 11 fixed-point, 13 знаковых целых и 14

## Исправленное поведение

EN_CHANGE сразу ограничивает целую часть. Для fixed-point — 0…32767 с выводом
`0.0`/`32767.0` при ограничении; дробь внутри целых границ сохраняется. Для
незнаковых целых — 0…32767; для знаковых целых — только верхняя граница32767,
отдельного нижнего ограничения исходный обработчик не имеет. В частности,
Health=`-1` сразу становится `0`, HungerRate=`40000.75` — `32767.0`.

Все ветви исходного ModifyValue вызывают именно Misc_SetUpDownIntSigned.
Пустой/нечисловой ввод при явном нажатии стрелки считается нулём, шаг меняет
целую часть на единицу; затем выполняется EN_CHANGE. Прибавление к `1.75`
даёт `2`. Уменьшение `0` для незнакового атрибута сохраняет ноль; для знакового
даёт `-1`. Обработка signed LONG overflow сохраняет исходный порядок.

В текущем коде CreatureAttributeInputs используется реальным TextChanged и
CreaturePageControls.Step. Доступ разрешён только текущему редактируемому
окну. Чтение строки, построение окна, смена языка и неизменённый Apply не
запускают исправление импортированных значений или signed WORD aliases.
Промежуточные строки сохраняются; изменённое невалидное число по-прежнему
отклоняется существующей строгой проверкой Apply.

Существующая граница native/DKM сохранена: DKM хранит исходные LONG, native
редактируется в пределах физического WORD (кроме DWORD HungerRate). Для native
Speed максимальный целый шаг15, для DKM32767. У знаковых native WORD нижняя
граница−32768. Ввод вне packed width не обрезает байты молча: Apply выдаёт
ошибку. Это прежняя [защита native ширины](GLOBAL_DEFINITION_NUMBERS.md),
а не новая попытка объявить native WORD равным исходному LONG.

## Остальные маршруты Attributes

| Исходный маршрут | Текущий эквивалент и граница |
| --- | --- |
| LVN_ITEMCHANGED → ChangeValueType | Все38 числовых полей и их default hints доступны отдельно; выбор одного общего контрола больше не требуется. Смена фокуса не теряет ввод соседних полей. Групповые заголовки не выдаются за редактируемые поля. |
| Нет валидной выбранной строки / Offset=0xFFFFFFFF | Пустой или неизвестный field отклоняется helper; read-only page не получает активные controls. |
| GetParamsCr page0 → ChangeValueType | CreateCreaturePageDraft/Rebuild выводят current/default каждого поля без нормализации импортированных байтов. |
| SaveChangesCr page0 — пустая ветвь | Исходник пишет в приватный Context при EN_CHANGE; современная форма сохраняет ввод в локальном draft, который родитель переносит в свой WorkingDocument перед переходом/общим Apply. Живая карта меняется только общим Apply. |
| BN_CLICKED998/999 | Существующий ResetCreatureGlobals для выбранного существа/всех существ, затем новая страница из private context. |
| LBN_SELCHANGE, PSN_KILLACTIVE | Существующий SaveCurrent перед сменой существа/страницы. Невалидный изменённый ввод сохраняется в форме до исправления. |
| PSN_APPLY | Частный контекст → общий Prepare/Apply, одна Undo-операция. Согласованный полный Undo сохранён. |
| Draw/Measure/Invalidate | Изменение значения отражается в соответствующем поле и статусе draft; реальные фокус/размер/отрисовка остаются ручной приёмкой. |

Таблица сопоставляет функции и объясняет различие формы, а не доказывает
физическое поведение окна. Reset/общие lifecycle/storage/262 поля не ставятся
на повторную реализацию. I11 остаётся открыт по остальным pages/callers.

## Проверки

Новая CLI группа использует буквальный список38 полей независимо от production
parser: все три числовых вида, верх/низ, целую часть, пустые/нечисловые строки,
overflow, source spin и native width. На native/DKM проверены private Apply,
точные изменённые raw values, общий один Undo/Redo, Cancel, отказ native overflow
и неизменённый импорт за границей со signed alias. Другие успешные числовые
проверки без изменения их кода не повторялись.

EN/RU × native/DKM WPF cases подготовлены и скомпилированы, **не исполнены**.
Старый invalid-input case теперь вводит `invalid`: Health=`-1` должен
ограничиваться автоматически. GUI/игра/Computer Use не запускались.

## Ручные шаги M19/M21/M23

1. Откройте определения существ → Attributes. Введите Health=`-1`:
   сразу получится `0`; HungerRate=`40000.75` — `32767.0`.
2. Введите Speed=`1.75`, увеличьте стрелкой: получится `2`. Очистите поле,
   увеличьте: получится `1`. Проверьте отрицательный знаковый атрибут.
3. Измените несколько полей, переместите фокус, переключите EN/RU:
   строки и подписи default должны сохраняться. Отмените общее окно —
   карта и история прежние.
4. Повторите и примените общее окно. Один Undo возвращает все поля.
   Для native Speed=`40000` ограничится исходной границей32767.0, но Apply
   должен сообщить о невозможности записать это в WORD; DKM допускает LONG.
5. Проверьте native/DKM, Tab/каретку/клавиатуру/DPI. Импорт за границей не
   должен меняться от одного открытия страницы или смены языка.
