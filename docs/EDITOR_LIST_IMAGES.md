# Значки маршрутов, дерева сценария и предпросмотра объектов

21 октября 2026. Этап EditorListImages-20261021, часть I13.

Восстановлены три записанных ранее source callers: `PathAreas` в Things_Paths,
`TrImages` в Triggers_Select и `PvIcons` в Things_Manager. Номера ресурсов
получены из Datas_Effects.c, Datas_Triggers.c и Datas_Manager.c, а назначение —
из реальных присваиваний `iImage` в потребителях этих таблиц. Bitmap ID не
приравнивается к ID игрового объекта или порядку текущей строки.

**Маршруты.** Исходный список областей использует один значок PathAreas[0],
ресурс1501. Он добавлен к точкам маршрута, выбору области и дочернему окну
Append/Insert. У диагностической строки без существующей области картинки
нет. Выбор, пауза, локальный порядок, linked/ambiguous/missing описания,
доступность команд и принятие операции не меняются.

**Сценарий.** TrImages загружается исходником как 16×16. В текущем дереве
применяются следующие номера:

| Категория / scope | Ресурс |
| --- | --- |
| Условие / действие |200 /201 |
| Игрок |202 |
| Существо / участник отряда |203 |
| Область |204 |
| Отряд |205 |
| Дверь |206 |
| Предмет / магический предмет |207 /208 |
| Уровень |209 |

Проверяются точные scope bits 1/2/4/8/16/32/64/128/256. Составной или неизвестный
scope не получает придуманной картинки. Native-события различаются по
сигнатуре D5/D6 и размеру записи24, project — по проверенной категории/схеме
TRIGGER/ACTION версий2/3. Это категория события, а не его subtype code.
Циклы, shared/missing markers, неизвестные ID и текст диагностики остаются.
Современная дополнительная группа несвязанных событий не получает вымышленного
исходного значка. Ширина текста дерева учитывает место16+4 пикселя под картинку.

**Предпросмотр объектов.** Things_ManagerPreviewPbsInfo назначает ресурс800
заблокированной строке. Если строка не заблокирована, flags BadTerrain/Enemy/
Fatal/Incompatible выбирают802, а OutOfMap/Replacement затем имеют приоритет
и выбирают801. Boundary/SameType/SameFamily сами по себе картинки не дают.
Последняя исходная проверка `Template->modify` убирает значок даже у строки
с предупреждением. Этот порядок сохранён, несмотря на обычные предположения
о «серьёзности» названий файлов Erreur/Avertissement/Information.

Значок показан рядом с прежним текстом предупреждений в существующей колонке,
без изменения порядка/числа колонок. У добавления он обновляется вместе с Add,
у изменения — с Decision и повторным review Candidate. Решения, source flags,
приоритет предупреждений, блокировки и число вызовов команд не изменяются.

`EditorListImageResources` в Core возвращает только nullable resource IDs.
`OriginalEditorListImages` в App загружает встроенный BMP, приводит к исходным
16×16 либо32×32, замораживает и кеширует. Ресурс1501 уже встроен и используется
повторно; добавлены13 деклараций исходных BMP без копирования файлов.

Независимый fixture `tests/DK2MapEditor.Validation/EditorListImagesSource.json`
содержит14 исходных ресурсов, размеры, пути, SHA256,9scope associations и
защищённые hashes9 файлов исходника. Headless `--editor-list-images-only`
сравнивает их с байтами managed PE App, проверяет2048 сочетаний flags/locked/
accepted, неизвестные bits/scopes, native/DKM события и сохранность bytes/
revision/history от чтения. App, WPF, bitmap-декодер, GUI и игра не исполняются.

Этот этап закрывает кодовое подключение трёх конкретных callers, а не весь
I13 или все81 вызов создания image lists из предыдущего inventory. Остальные
draw/control consumers и object/custom/dynamic captions ещё требуют сверки.
Прежние успешные группы без изменения их реализации не запускались повторно.

Для ручной проверки: откройте текущую сборку и рабочую карту. В маршруте
проверьте картинки областей; в дереве сценария — условия, действия и владельцев.
В предпросмотре добавления/изменения переключите решение строки и убедитесь,
что значок обновляется, а текст предупреждения остаётся. Проверьте EN/RU,
перенос длинного текста, прокрутку и свой масштаб Windows. Принимать операцию
над картой для визуального осмотра не требуется. Эти проверки пока не выполнены.
