Первый частичный ручной проход M20, настоящий native GUI RU/DPI125%.

## Проверено в интерфейсе

Через Правка → Существа открыт настоящий менеджер. Без выделения карты
«Только внутри выделения» недоступно. Показана ровно одна запись: Колдун ID5,
Хранитель1, координаты15,20, уровень4, без сценарной привязки. Показ/изменение
без выбора недоступны. Поиск несуществующего имени дал0строк, поиск «Колдун»
вернул1. Выбрать все видимые дал1выбранную запись и включил показ/изменение.
Дубликатов при фильтрации не появилось.

Показ выбранного скрыл менеджер, центрировал карту на15,20 и открыл палитру
возврата. Возврат сохранил фильтр и выбранную строку. Координата X999 немедленно
ограничилась43 для карты шириной44. Тестовый нечисловой токен `abc`, введённый
через UI Automation, оставался виден; команда трактовала его как0 и показала
0,1. Это согласуется с текущим RegionCoordinateRules и исходным
GetDlgItemInt(FALSE), а не является отказом валидации. Прямой ввод букв с
клавиатуры запрещён PreviewTextInput; его физическая проверка ещё не выполнена.
Старый шаг инструкции «неверные X/Y не показываются» уточнён ниже.

Палитра второго просмотра закрыта штатным крестиком; менеджер вернулся.
X/Y восстановлены в1/1, фильтр очищен, менеджер закрыт через Отмена.
При управлении вложенной палитрой Computer Use дважды не находил её элементы
в кэше и не показывал её как отдельное окно. Возврат выполнен по свежему
снимку штатной кнопкой заголовка. Второй захват показывал содержимое палитры
неполно, хотя дерево содержало текст/кнопку. Корректность её отрисовки во всех
положениях/масштабах остаётся ручным остатком; это не объявлено исправленной
ошибкой продукта и не скрыто итоговым PASS навигации.

В статистике карты показаны44×38,1672клетки,1281земля,160непроходимая скала,
одно существо, средний уровень4, самый частый вид Колдун5. Значения1672/1281/160
пересчитаны из всех клеток через MCP; вид/уровень/владелец/координаты сверены
с реальной GAMEKEEPER записью. Прочие числовые строки пока только наблюдались.

Статистика по умолчанию открылась на Героях: сердца нет, кнопка показа
недоступна. У Хранителя1 она стала доступна, сердце15,17; существо1/уровень4.
Показ сердца открыл карту и выделил одну клетку15,17. В исходных клетках
найдены25клеток сердца ID14, первая13,15; исходный сдвиг центра+2,+2
подтверждает показанные15,17.
