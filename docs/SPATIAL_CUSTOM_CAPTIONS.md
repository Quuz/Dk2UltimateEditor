цвета области и её четыре опции; четыре эффекта и шкала частоты; список

начальная/конечная координата, имя, описание, цвет прямоугольника/текста.

Найден и исправлен пропуск двух подписей шкалы эффектов. Исходный диалог6703
ставит «Souvent» слева и «Très rarement» справа, callback задаёт диапазон1–255.

теперь видны «Часто (1)» / «Очень редко (255)» и соответствующие EN переводы.
Общий helper создаёт только две текстовые подписи, с динамическими ресурсами.
Положение/обработчики/значение slider, private draft и применение не меняются.
Единица времени для частоты не придумана: исходник её не указывает.

что специальное окно; project freq больше не выглядит как техническое «Freq».
У области пауза теперь явно указана в секундах до следующей области; nextid
получает существующую подпись «ID следующей области». Основание единицы —
исходная подпись DIALOG_AREAPATHPTDELAY. Отдельное окно паузы уже называло секунды
правильно и не менялось. Gate и чужие/неподтверждённые записи не получают
подписей area/effect. Различные назначения общей project MAPRECTEX отделены
по node.type, native — по категориям и поддержанным полям.
