Закончено сопоставление двух текущих каталогов с исходными таблицами и
подписями:371 эффект (ID0–370),193 переменные карты и20 групп. Для каждой
строки записаны ID, source symbol, исходное название, файл/строка и текущие

в исходных подписях (секунды, клетки, проценты), сопоставлены с подписями
каталога; это не измерение поведения игрового движка. Четыре source20.12
display поля переменных сохранены; их код и форматы этой правкой не меняются.

из-за общего французского coup: названия не доказывают такую смену смысла.
