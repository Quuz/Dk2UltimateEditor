# Отсутствующая цель ворот при переводе игровой карты в DKM

25 октября 2026. Часть I03; весь перенос между форматами этим изменением не закрыт.

В игровой записи `ACTION_DESTROYGATE` хранятся две координаты WORD,
а в DKM — логический ID ворот. Исходный загрузчик читает координаты минус
единица, выбирает первые физические ворота в этой точке и возвращает ID0,
если их нет (`Files_Game.c:1595`, `Things_RectEx.c:2521`). Исходный compiler
при отсутствующем ID записывает координаты (1,1). DKM не имеет отдельного
поля для исходных координат отсутствующей цели.

Подготовка преобразования теперь сообщает `MissingDestroyGate` как **Loss**,
сохраняя отсутствующий ID: 0 при обычном импорте либо прежний ненулевой ID
после удаления ворот в рабочем документе. Само отсутствие цели больше не
блокирует преобразование. Сохранение требует явного подтверждения потери;
отказ от подтверждения не записывает и не принимает новый документ.
Сопутствующий архив исходника сохраняет исходные файлы и отчёт Loss.
Он относится к проекту DKM; игровой комплект по-прежнему содержит семь файлов.

При компиляции DKM без исходного архива отсутствующая цель получает (1,1).
При наличии проверенного архива неизменённое действие может сохранить свои
исходные восемь байтов параметров. Восстановление запрещено, если в старой
точке отсутствующей цели теперь стоят новые ворота: иначе старая запись
могла бы начать уничтожать посторонний объект. В этом случае остаётся свежая
запись с (1,1). Undo удаления новых ворот снова допускает точное сохранение
старых байтов; Redo снова запрещает его. Изменённые параметры действия,
координаты существующей цели и связи проходят прежние проверки сохранности.

Семь игровых файлов кодируют координаты, а не отсутствующий логический ID.
Поэтому координатный fallback (1,1) нельзя считать гарантией отсутствия
физических ворот в игровом мире. Рабочий документ сохраняет объявленную
отсутствующую цель; при преобразовании эта граница явно сообщается как Loss.

Существующая цель, которую нельзя представить подтверждённой записью DKM,
остаётся блокирующим `UnprojectableDestroyGate`. Повреждённый граф сценария
также остаётся блокирующим. Проверенные дубликаты координат используют первую
физическую запись, как исходный загрузчик. Никакого исправления входной карты
или выбора «похожих» ворот нет.

Проверка в `artifacts/Evidence/NativeMissingGateConversion-20261025`:

- До изменения преобразования: четыре отказа и две успешные группы; тестовые
  фикстуры с воротами предварительно исправлены отдельно от продуктового кода.
- После разрешения преобразования: пять успешных групп, одна воспроизвела
  ошибочное восстановление координат на новые ворота.
- После защиты восстановления: все шесть новых групп успешны. Они проверяют
  крайние WORD-координаты, удалённый ID, подтверждение/отказ, настоящий Save As
  и повторное открытие DKM с архивом, новые ворота, Undo/Redo, дубликаты и цикл.
- Связанные проверки преобразования: пять успешных групп. Проверки сохранности
  данных: шесть успешных групп, включая все 1800 клеток и 711 параметров событий,
  изменение/Undo, смену размеров и перемещение зависимых ворот и кристалла.
- Все 41 проекта собраны без ошибок и предупреждений; опубликован тот же Core,
  который использовали проверки. EN/RU имеют по 2880 ключей; изменено одно
  существующее сообщение и добавлено одно сообщение в каждом языке.

Новых полных прогонов корпуса не было. Исторические 1840 PASS/63 FAIL относятся
к прежней сборке и не представлены как результат этой. GUI, игра и Computer
Use не запускались. Source/, Binaries/, установленные карты и фикстуры сохранены.

Привязка к исходнику и хешам: `source-conversion-proof.json`; конечные коды
завершения — `*-exit.json`; публикация и проверка архивов — `delivery.json`
в указанном каталоге доказательств. Остаток — [конечный перечень](OPEN_FUNCTIONS_RU.md).
