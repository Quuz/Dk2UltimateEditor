# Вычисляемые native цели при изменении размера

15 октября 2026. Общее окно свойств пересчитывает `ACTION_SHOWCRYSTAL` (2)
и `ACTION_DESTROYGATE` (32). Их WORD-координаты — результат исходного writer,
а не независимые координаты проекта. Прямой перенос трёх других действий
описан в [EDITOR_RESIZE_SCRIPT_TARGETS](EDITOR_RESIZE_SCRIPT_TARGETS.md).

## Правила исходника

- Кристалл: `Things_GetThingPos(&MapObjects,0x1C,axis)` выбирает первый предмет
  ID28 в порядке списка. `List_AddEntry` добавляет в конец: сохраняется
  физический порядок, а не сортировка по координатам.
- Ворота: reader преобразует `(X-1,Y-1)` в ссылку на прямоугольник с точно
  совпадающей начальной позицией. Сердца типа14 не входят в MapGates.
  `bGateID` — игровой вид, а не уникальный ID прямоугольника.
- После сдвига/удаления writer вычисляет первую оставшуюся копию кристалла
  и начальную позицию прежних ворот плюс1 по обеим осям.
- Без кристалла `-1` переходит в WORD `65535,65535`. Без ворот
  `RectEx_GetRectLocation` возвращает0, и writer записывает `1,1`.
  Этот результат записи не объявляет отсутствующую цель исправленной.

Связь с воротами фиксируется до перемещения. Равные позиции нескольких ворот
дают одинаковый результат общего сдвига/обрезания; ближайшие другие ворота
не выбираются. Кристалл выбирается после удаления объектов, включая
окончательную фиксированную границу. Если первая копия удалена, используется
следующая сохранившаяся копия в том же порядке.

Пересчёт меняет только четыре байта координат по смещениям12/14 действия.
ID, связи, repeat/one, резервные слова и остальные импортированные байты
сохраняются. Обрабатываются все физические действия, включая повторные IDs;
сами IDs не исправляются. Будущие непроверенные layouts не угадываются.

## Границы операции

Пересчёт выполняется только при реальном resize через общее окно свойств,
внутри частной подготовки. Preview/Cancel сохраняют оба исходных документа;
общее применение даёт один Undo. Счётчик определяется свойствами/resize,
сдвинутыми и удалёнными сущностями; вычисляемые цели не добавляют увеличений.

Общий низкоуровневый Resize сохраняет прежний контракт работы с байтами.
Равное принятие свойств, загрузка, диагностика и простое сохранение карты
не нормализуют payloads. В DKM остаются исходные ссылки и параметры;
действующий compiler вычисляет native координаты при экспорте.
Другие способы перемещения/удаления сущностей и полная политика компиляции
остаются отдельными требованиями; этот блок не доказывает все такие маршруты.

Read-only `DK2N032` EN/RU сообщает об отсутствующей или устаревшей native цели:
для кристалла сверяет первую копию, для ворот — точную позицию.
Предупреждение не изменяет данные, не выполняется при проверке без сценариев
и не заменяет фактическую проверку в игре.

## Код и проверки

Core: `NativeResizeDerivedTargets.cs`, `NativeDerivedTargetDiagnostics.cs`,
`NativeMapDocument.cs`, `NativeMapValidator.cs`. Семь исходных файлов и четыре
полных функции поиска/порядка списка зафиксированы в
`tests/DK2MapEditor.Validation/NativeResizeDerivedSource.json` и
`artifacts/Evidence/NativeDerivedResize-20261015/source-capture.json`.

Проверки:27 матриц размера/привязок; девять буквальных случаев удаления,
границы, отсутствующих целей, сердца, одинаковых позиций и вида ворот;
точные полные действия, счётчики, общий Undo/Redo, save/reopen, Cancel,
отказ от неподтверждённого crop, повторные физические события, нулевая история,
неизменённый общий Resize/равный Apply и сравнение с компилятором проекта.
98 других типов сохраняют проверку неизменности в блоке прямых целей.
Результаты — в [CURRENT_STATUS](CURRENT_STATUS.md).
WPF-тест класса окна native EN/RU подготовлен и собран. Окна, рендерер,
официальный редактор, звук и игра агентом не запускаются.

## Ручная последовательность

1. На копии native карты разместите кристалл и проход героев. Добавьте
   действия показа кристалла и уничтожения выбранного прохода.
2. Увеличьте карту через общие свойства с привязкой, перемещающей сущности.
   Проверьте, что обе цели следуют за ними, затем проверьте общий Undo/Redo.
3. Разместите две копии кристалла. Уменьшите карту так, чтобы первая добавленная
   копия удалялась. Цель должна перейти к следующей сохранившейся копии.
4. Проверьте Cancel и отказ от удаления. Без целей проверьте предупреждение
   EN/RU и задайте правильную цель перед игровой проверкой.
5. Игра проверяется только на семифайловом комплекте
   `DK2Preview_6a88240eaf814f78` через
   `DKII-DX.exe -q -level DK2Preview_6a88240eaf814f78`.
