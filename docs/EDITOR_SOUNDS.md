17 октября 2026, EditorSounds-20261017. Внутри I17 подключены 15 оригинальных
WAV из Binaries/Sounds. Это звуки интерфейса и работы на карте; отдельное
воспроизведение речи/MP2 через внешний player описано в
[MAP_SPEECH_TEXT](MAP_SPEECH_TEXT.md).

## Источник и маршруты

Source/Sources/Map/Map_Sounds.c, Sound_Play, выбирает sample по действию,
режиму рисования, terrain ID, владельцу и размеру фигуры. Пути объявлены в
Source/Sources/Datas/Texts_Global.c:67–81. Source Map_Mouse.c вызывает звук
после проверки начальной позиции, при старте карандаша/фигуры и принятии
фигуры; Windows_Toolbar.c — при выборе инструмента и terrain.

В App чистая политика EditorSoundRules.cs использует те же значения.
Validation компилирует ссылку на этот единственный файл без зависимости
от WPF. MapCanvas.Sounds.cs и реальные pointer callers передают только
значения действия/terrain/владельца/размера. EditorWorkspace.Sounds.cs принимает
их и выборы палитры; object brush передаёт семейство и ID своего шаблона.

Сначала звучит определение фигуры, при отпускании — её terrain sample.
Для ограниченного footprint берётся исправленный прямоугольник, а не сырое
расстояние мыши. Фиксированный footprint и немедленное размещение используют
исходный путь Pen. Движение внутри одного pen stroke не перезапускает звук
на каждой клетке. Отмена фигуры не создаёт звук её применения. Region picking,
GeometryOnly, выделение, взятие образца и прямые Core API не приобретают
звуковые побочные действия. Для Brush звук запускается до подготовки Undo,
как исходный Mouse caller; это не запись карты и не шаг истории.

Смена языка и взятие образца подавляют звуки программной перебиндовки.
Вне загруженного workspace аудиоплеер не создаётся. Поэтому конструирование
контролов и CLI-проверка правил не обращаются к устройству.

## Воспроизведение и поставка

EditorSoundPlayer использует отдельный MediaPlayer для каждого sample.
Повторный вызов останавливает этот sample и начинает его с позиции0, другие
samples сохраняют собственное воспроизведение. Это соответствует отдельным
DirectSound buffers исходника. На Unloaded все players закрываются; повторная
загрузка workspace может лениво создать их заново. Реальное смешивание,
задержка и audible restart требуют ручной проверки устройства.

Исходные SoundsFlags=3: interface и terrain включены. Категории независимы;
SoundCategories и SoundVolume — runtime-свойства workspace, не поля карты.
Default SoundsVolume=−500 centibels преобразуется в amplitude
10^(−500/2000), примерно0.56234. Системная громкость устройства не изменяется.
Новый settings dialog для несуществующей исходной команды не добавлялся.

15 WAV копируются проектом в Sounds рядом с EXE и попадают в publish/ZIP.
Их bytes остаются исходными, без перекодирования, временных файлов и поиска
в установленной игре. Ошибка файла/медиасистемы сохраняется в
LastEditorSoundError и не превращается в ошибку операции редактирования.
Опциональный EditorSoundPresenter предназначен для приёмки с перехватом
вызовов без воспроизведения; он не доказывает наличие слышимого звука.

## Ручная M14/M21/M23

1. В текущей поставке выбрать другой инструмент, затем water/wall terrain:
   слышны разные короткие кнопочные звуки. Смена EN/RU и загрузка карты
   не должны вызывать каскад звуков палитры.
2. Начать карандаш на water/wall/gold/gems. Один звук при старте; движение
   внутри stroke не запускает его на каждой клетке. Взять образец — тихо.
3. Начать и отменить фигуру: слышно определение, но нет звука её применения.
   Принять маленькую/большую комнату, проверить Room/Tiles и min footprint.
4. Разместить heart хранителя и neutral heart, Imp1/другое существо, предметы
   gold1/2/3. Door/trap/special и обычная заливка остаются без build sample.
5. Быстро повторить один sample: он начинается заново. Вызвать другой во время
   первого: проверить смешивание. Закрыть окно во время проигрывания.
6. Проверить громкость, доступный codec/device, отсутствие задержки ввода и
   влияние системного mute. Agent этого не выполнял. Карта/Undo не должны
   меняться от самого выбора палитры или воспроизведения.

Кодовый пропуск SoundsVolume/SoundsFlags снят в этом объёме; фактическое аудио
остаётся ручной приёмкой. Остальной I17 и вся цель ещё не завершены.
