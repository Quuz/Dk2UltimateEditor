# Цель ворот при экспорте сценариев в текстовый MAP

25 октября 2026. Исправлена отдельная ветка I03: игровая карта → текстовый MAP
в режиме поддерживаемых сценариев.

Экспорт раньше заново искал ворота по двум координатам `ACTION_DESTROYGATE`.
Этого достаточно для первого импорта игровой карты, но недостаточно после
редактирования. Рабочий документ различает выбранный физический дубликат и
отсутствующую цель. Повторный поиск мог незаметно выбрать первые ворота в той
же точке, превратить отсутствующую цель ID0 в новые ворота или привязать
удалённую цель к чужим воротам в точке fallback (1,1).

Writer теперь сопоставляет физическую запись ворот `(NativeFile, Offset)` с
её ID в создаваемом MAP. Действие использует существующий `NativeGateTarget`,
а не повторный поиск по координатам. Поэтому явно выбранный второй дубликат
сохраняет свой экспортируемый ID, даже если координаты у двух ворот одинаковы.
Нумерация ворот в MAP остаётся последовательной, как раньше.

Если рабочая цель отсутствует или её ворота не вошли в поддержанную проекцию,
действие не переносится в ограниченный MAP; отчёт содержит потерю `Scripts`.
Исходные игровые байты остаются в обязательной `EditableCopy`.
Потеря поддержанной строки не заменяется выбором посторонних ворот.

`NativeEditorState` явно предупреждает перед экспортом: игровая копия не
сериализует частные рабочие ID, orphan state и привязки редактора. Для их
сохранения служит DKM с исходным архивом. Это уже принятый контракт I01/R19:
при обычном повторном открытии KWD действует исходный поиск первых ворот по
координатам. Предупреждение также включено в двуязычный дисковый отчёт.

Согласованная исходная политика повторного использования освобождённого
ненулевого ID не менялась: добавление ворот с этим ID может намеренно вернуть
ссылку удалённому действию. Исправление следует текущей рабочей ссылке и в этом
случае. Это отличается от самовольного поиска совпавших координат у ID0 или
у отсутствующего ID, который не принадлежит оставшимся воротам.

Ветви DKM → MAP и «оригинальный редактор: без сценариев» не менялись.
Исторический `Text_GenerateFile` всегда пишет `TRIGGERS 0`; экспорт
поддерживаемых сценариев является явно выбранным расширением, а не обещанием
дословно повторять тот writer. Обычное сохранение MAP использует прежнюю
политику без сценариев и явное подтверждение потерь.

Проверки в `artifacts/Evidence/TextGateIdentity-20261025`:

- До правки: одна успешная группа, пять воспроизводят ошибочный перенос цели.
  В первой попытке отдельная фикстура ошибочно ожидала отсутствия цели после
  намеренного повторного использования освобождённого ID. Она исправлена до
  изменения продукта; этот случай добавлен как контроль сохранения политики.
- Шесть новых групп проверяют исходный первый выбор, намеренное повторное
  использование ID, появление ворот возле отсутствующей цели, явно выбранный
  дубликат, удаление, Undo/Redo и отсутствие изменений входных байтов/истории.
- Настоящий экспорт MAP + EditableCopy повторно открывается: MAP содержит
  выбранный ID2, игровая копия сохраняет исходные wire bytes. Текущая рабочая
  цель остаётся вторым дубликатом. Копия KWD при открытии следует первому
  координатному совпадению, что явно сообщается как `NativeEditorState`.
  Отчёт остаётся двуязычным; исходная политика без сценариев проверена отдельно.
- Промежуточно пять групп прошли, одна ожидала от native game-file snapshot
  сохранения private identity. Это ожидание исправлено согласно I01/R19 до
  финального прогона; вместо него проверяются точные игровые байты и явное
  сообщение о границе рабочего состояния. Проверка ID2 в самом MAP сохранена.

Конечные результаты сборки, связанных проверок и поставки записаны в
`*-exit.json` и `delivery.json` этого каталога. Полный корпус не перезапускается
ради этого изменения. GUI, WPF, игра и Computer Use не требуются этой проверке.
Игровая запись из семи файлов не менялась.

Финальный результат: шесть новых успешных групп, одна связанная группа режима
без сценариев (native/project, повреждённые графы, девять владельцев) и семь
связанных групп обычного MAP Save/отказа/повторного открытия/сбоев/Undo.
Все 41 проекта собраны без ошибок и предупреждений. EN/RU имеют по 2881 ключу;
прежние 2880 значений сохранены, добавлено сообщение `NativeEditorState`.
