# Контекстные подписи глобальных параметров элементов

21 октября 2026. Этап GlobalElementCaptions-20261021, часть I13.

Сопоставлены пять основных страниц исходного редактора: Terrains, Rooms, Doors,
Traps и Spells, диалоги 6820–6824. В них 95 хранимых полей. Из них 87 связаны
с основными контролами, включая девять компонентов трёх RGB-выборов. Семь
принадлежат дочерним настройкам активации/выстрела. `ShotDelay` — хранимое поле
сброса, отдельного контрола на основной странице у него нет. Эти категории
сохранены в `fields-before.json` и `fields-after.json`, без выдуманных контролов.

Источники — `Source/Resources/Editor.rc`, `Source/Includes/Strings.h`,
`Properties_GlobalGetParams` и `Properties_GlobalSaveChanges` в
`Source/Sources/Properties/GlobalVariables/Properties_Global_Elements.c`.
Для каждого основного поля записаны явные номера контрола/подписи/группы,
исходная французская надпись и места использования поля. RGB-компоненты
соотносятся с одним исходным выбором цвета, а не с тремя вымышленными контролами.
Номера контролов не определялись по ближайшему тексту автоматически.

Исправлены десять подписей полей на обеих языках:

| Поле и контекст | Причина и новое значение |
| --- | --- |
| Terrains.Damage | Исходная подпись «Modification de la santé des créatures» означает изменение здоровья существ; прежнее «Урон» сужало смысл знакового значения. |
| Terrains.MaxManaGain | Исходный control134 подписан «Mana max.», поэтому показывается «Максимум маны», без неподтверждённого слова «прирост». |
| Rooms.Cost | Control143 с подписью144 задаёт стоимость клетки комнаты в золоте. |
| Doors.DeathEffect, Traps.DeathEffect | Для конструкций исходник говорит о разрушении; название «Эффект смерти» заменено на «Эффект при разрушении». |
| Traps.IdleEffectDelay | Control120 задаёт интервал между срабатываниями эффекта бездействия, а не только начальную задержку. |
| Traps.PowerlessEffect | Control116 относится к эффекту при отсутствии маны. |
| Spells.HandAnim, Spells.NoGoHandAnim | Явно указаны анимация руки по умолчанию и при недоступном применении. |
| Spells.UpgRechargeTime | Control130 подписан «Bonus de temps après amélioration»: «Бонус времени после улучшения», а не «Время перезарядки улучшенного заклинания». Поле и его числовая обработка прежние. |

`GlobalElementFieldLabels` хранит только выбор ключа подписи. Контекстные
названия применяются и в дочерних окнах страниц, и в общей таблице определений.
Общие `Field.Damage`, `Field.Cost`, `Field.MaxManaGain`, `Field.DeathEffect`
сохранены для других контекстов. Обычная обработка массивов `Effects[n]` и
`Objects[n]` в общей таблице и в окне комнаты остаётся прежней.

Отдельно восстановлена контекстная подпись `TriggerData` в окне параметров
активации ловушки. `Properties_GlobalTypeProc` выбирает для control101:

| TriggerType | Исходная строка | EN / RU |
| --- | --- | --- |
| 1 | `szGlobalLineOfSight`: Champ d'action | Area of effect / Область действия |
| 2 | `szGlobalPressure`: Pression nécessaire | Required pressure / Необходимое давление |
| 3 | `szGlobalTrigger`: Donnée | Trigger Data / Параметр активации |

Для третьего типа остаётся существующий общий ключ `Field.TriggerData`.
Неизвестные типы не получают придуманной специализированной подписи.
Смена языка перестраивает эти надписи существующим обработчиком, не меняя
локальные значения дочернего окна. Тип, диапазон 0…32767, Apply/Cancel,
инкременты и байтовая запись не менялись.

Добавлены шесть ключей в каждый словарь EN/RU; уточнены пять существующих
ключей. Значения остальных 2796 прежних ключей сохранены. Данная правка не
переименовывает wire fields, не меняет каталоги, варианты выбора, маски,
диапазоны или формат файлов. Core, тесты, исходный эталон Source/Binaries,
fixtures и установленные карты сохраняются побайтно относительно предыдущей
поставки. Новые тесты для замены подписей не добавлялись; проверяются точный
набор изменений, словари/связи с источником и сборка всех 41 проектов.

Остаются остальные подписи полей существ и объектов, оставшиеся reference
previews/callers и ручная проверка настоящих окон. Числовые callbacks I11
заново не реализуются. Совпадение исходной подписи не доказывает неизвестную
внутреннюю механику игры; для `Visible` сохраняется прежнее краткое название,
а в evidence записана полная исходная строка о поле восприятия.
