## Исправления

Ввод Shot1Delay=`1001.75` теперь сразу становится `1000.0`; Shot1X=`40000.5` —
`32767.0`; Dammage=`32768` — `32767`. У границ допускаются дробные части:
например, RechargeTime=`255.75` сохраняется. Стрелка из `2.75` даёт `3`, из
пустого поля вверх — `1`. Уменьшение нулевого unsigned fixed-point возвращает
`0.0`, обычного integer — `0`, signed координаты — `-1`.

Ранее современная панель проверяла числа только при Apply и не имела кнопок
шага этих полей. Теперь CreatureAttackInputs реализует исходные преобразования,
а существующий EditorWorkspace.CreatureAttacks использует их в TextChanged,
кнопках удержания−/+ и клавишах Up/Down без модификаторов. Уровни остаются
ComboBox. Обработчик строки ограничивает число без потери остальных16 полей,
уровней и выбранных типов в четырёх cached slot forms.

Эта же панель используется в общем CreatureGlobalsWindow через
CreatureWorkspacePageWindow; второй реализации числовой формы нет. Применяются
guards текущего документа/строки/baseline/зарегистрированного контрола, editable,
активного типа и владельца общего окна. Новый owner callback запрещает
нормализацию и шаг устаревшей/закрываемой hosted страницы. Отложенное событие
старого контрола не получает разрешения редактировать новую строку.

None отключает параметры и кнопки, сохраняя уже введённые значения. Общий
Save/Apply по-прежнему записывает их вместе с ID=0, как исходник. Unknown
nonzero imported type не отключает известную общую схему параметров. Открытие,
смена языка и неизменённый Apply не ограничивают импортированные bytes.
Промежуточные пустые/нечисловые строки сохраняются; строгая проверка Apply
остаётся. Нормализация относится к явному активному вводу, а не к decoder.

## Ручная проверка M19/M21/M23

1. В глобальных определениях существ откройте Attacks. Выберите Shot1 и тип,
   отличный от None. Введите задержку1001.75 и X40000.5: сразу должны появиться
   `1000.0` и `32767.0`. Проверьте также Shot2/Shot3 и четыре поля Melee.
2. Введите X=`-1.75`, нажмите увеличение: получится `0`. Очистите задержку,
   нажмите увеличение: получится `1`. Проверьте удержание кнопок и Up/Down.
3. Введите задержку7.5, выберите None: поле и кнопки отключатся, число останется.
   Верните тип, переключите слот и EN/RU: pending значения должны сохраниться.
4. Отмените общее окно: карта и история прежние. Повторите, затем примените
   общее окно с None: изменённые параметры сохранятся; один Undo вернёт всё.
5. Повторите на native/DKM, в отдельной панели и общем окне. Проверьте размеры,
   клавиатуру и DPI. Импорт за границей не должен меняться от открытия страницы.

Эти проверки не требуют игры. Последующие игровые прогоны используют только
DK2Preview_6a88240eaf814f78 через DKII-DX.exe -q -level.
