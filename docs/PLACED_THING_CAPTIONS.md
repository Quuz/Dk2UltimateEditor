# Подписи размещённых объектов / Placed-thing captions

Этап PlacedThingCaptions-20261021 начат21 октября, завершён23 октября2026.

Исправлены подписи одного физического поля `MAPTHING.data` в зависимости от
вида размещённой записи. У существа это уровень; у современной двери —
состояние (0 не заперта,1 заперта,2 чертёж); у современной ловушки —
оставшиеся заряды. Предметы с ID1/2/3 хранят количество золота, ID4 — заклинание
книги. Остальные предметы, особые предметы и неизвестные IDs получают общую
подпись «Данные (исходное значение)». Это не утверждение, что у них есть
редактируемое количество золота. Источник — union в Things.h, отдельные ветви
Things_Selection.c и assignments Compiler_Generate.c.

Общее окно добавления/изменения раньше называло данные двери «Заперта» и
данные любого обычного предмета золотом. Теперь оно использует те же правила,
что и сырые свойства. Подсказки0/1/2 для двери и0/4 для ловушки, выбранные
числа, видимость полей и commands остаются прежними. Для неизвестного или
неполного ID подпись не предполагает конкретного предмета. В частности,
числовая запись04 корректно распознаётся как ID4, не сравнивается как строка.

Различия исторических DKM сохранены. MAPTHINGV1/V2/V4 (версии1–4) содержит
BOOL locked вместо status; поэтому дверь получает «Заперта», а сырые данные
старой ловушки остаются общими. MAPTHINGV5/current (версии5/6) используют
status/shots. Никакой upgrade, нормализация значений или исправление карты
для выбора подписи не выполняется. Исходное поле behavior старых версий
не переименовано в современные flags: подтверждения одинакового смысла нет.

У native GAMEHERO и GAMEBANDHERO поле bGlobalPlayer хранит противника:
исходный compiler присваивает List->ennemy / Hero->enemy. Подпись теперь
«Противник». У keeper/door/trap/object оно означает владельца и получает
«Владелец». Это устраняет прежнюю потерю смысла при удалении префикса Global.
Hero options и creature options обозначены как соответствующие битовые поля.

Поля dwObjectVersion/dwDoorVersion/dwTrapVersion/dwHeroVersion/
dwNeutralVersion/dwKeeperVersion в этих native структурах содержат длину
payload после8байт заголовка. Они уже исключены из редактируемых свойств,
поэтому нового поля или подписи для них не добавлено. Размеры сняты из
исходных присваиваний компилятора и сверены с раскладками для проверки
пригодности контекстной подписи. Для неизвестной сигнатуры,
категории, длины, заголовка или исторической версии применяется прежний
общий маршрут подписи. Структурные поля не получают новых прав изменения.
