# Состав отрядов в списках сценария

19 октября2026. Этап ScenarioBandPreviews-20261019, часть I13.

В пяти исходных контекстах под строкой отряда показаны его существа:
создание отряда, оглушённые/заключённые/погибшие в отряде и выпуск отряда.
Строка существа содержит исходную картинку, имя EN/RU и уровень. У лидера
показана цель; у цели23 дополнительно показан номер области. Как в исходнике,
цель обычного участника в этом списке не выводится.

Источник — Triggers_DisplayCreateHerosList, Triggers_DisplayGetImageId и
Things_GetCreatureNameFromID. Показываются первые16 слотов до первого
неактивного. Native использует существующую проекцию активности по ID и
behavior; DKM — isvalid. Непустой импортированный хвост после разрыва
не показывается и не исправляется. Пустой отряд остаётся строкой без участников.

Справочные строки существ недоступны для выбора мышью/клавиатурой.
Программная попытка выбора возвращает прежнюю строку без изменения параметра.
В исходном списке у строки существа lParam0; она не задаёт ID отряда.
Настоящие параметры сохраняют прежние IDs, включая допустимый0. Временный
source ID+1 не записывается в карту. Совпадающие IDs отрядов не объединяются:
каждое вхождение показывает собственный состав и сохраняет выбранную строку
при смене языка.

Список отрядов и состав читаются один раз при открытии/явном сбросе черновика.
Смена языка переводит сохранённые данные; она не подхватывает чужое изменение
карты. Проверки owner/stale/закрытия и общей Apply/Cancel остаются прежними.
Неизвестное существо или цель отображаются с номером; картинка неизвестного
существа не угадывается. Импортированные уровни не нормализуются ради подписи.
Непроверенная структура получает понятную EN/RU строку о недоступном составе.

Headless проверки охватывают все45 исходных creature images/names и пять
контекстов в native/DKM; используются независимые packed offsets32/44 байта,
начало51/12, а не product field offsets. Проверены лидеры, все10 source целей,
area23, unknown IDs/objectives, raw уровни,16 слотов, разрыв, пустой отряд,
повторяющиеся IDs, неизменность bytes/revision/Undo, immutable snapshot,
foreign/stale/nested guards. Настоящий App formatter подключён к CLI проверке
и читает текущие EN/RU ресурсы; WPF для этого не запускается.

Четыре подготовленных WPF suite EN/RU×native/DKM проверяют реальную форму,
порядок справочных/выбираемых строк, bitmap, disabled/focus container,
повторяющийся band ID, перевод, попытку выбора участника и stale snapshot.
Они только компилируются. Настоящее выпадающее окно, контраст, scroll,
клавиатура и DPI остаются ручной приёмкой по указанию пользователя.
