## Corrected reference/fallback collision

The loader previously added local same-named companion files even when the descriptor's explicit reference had already resolved to a different file in a parent game root. Both then targeted the same export path. Eight real maps exposed this conflict, including `SampleHeroPMap`, the two DK2 tutorial maps and several Homeworld campaign maps.

Fallback now refuses to shadow an existing explicit export path. `NativeReferenceChecks` constructs stale local companions for all five map collections, verifies the original explicit bytes win, checks exact saving/reopening and input/history immutability. The focused test passes Debug/Release; the repeated corpus no longer has these eight collisions. No stale user files were deleted or rewritten.
