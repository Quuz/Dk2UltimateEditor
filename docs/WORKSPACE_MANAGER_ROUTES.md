# Команды отрядов, областей, проходов, эффектов, патрулей и сценариев

Этап WorkspaceManagerRoutes-20261018, часть I17. Это подключение шести
исходных команд меню к существующим редакторам текущего проекта.
Сопоставление команд и SHA256 исходников — в
`artifacts/Evidence/WorkspaceManagerRoutes-20261018/source-scope.json`.

| Исходная команда / caller | Текущий маршрут | Доступные действия |
| --- | --- | --- |
| IDM_HEROS / Heros_Select, окно6600 | Правка → Отряды героев → Свойства, категория «Отряды героев» | Список отрядов, Добавить, Изменить в BandPanel, Удалить; существующее отдельное окно свойств с приватным черновиком |
| IDM_AREAS / RectEx_Select(AREA) | Правка → Области → панель областей на карте | Список только областей, показать, свойства, добавить через выбор геометрии, удалить |
| IDM_GATES / RectEx_Select(GATE) | Правка → Ворота → та же панель с видом Gate | Те же действия для проходов/ворот; сердца хранителей в этот список не входят |
| IDM_EFFECTS / RectEx_Select(EFFECT) | Правка → Генераторы эффектов → вид Effect | Те же действия для генераторов эффектов |
| IDM_PATHS / RectEx_MakePaths, окно6710 | Правка → Пути патрулирования → вкладка патрулей | Список маршрутов и областей, создание/изменение пути, паузы, выбор и рисование; используются существующие sessions |
| IDM_EVENTS / Triggers_Select, окно7000 | Правка → Сценарии → вкладка сценариев | Выбор владельца, дерево событий, добавление/изменение/удаление и перемещение веток, параметры, мастера и псевдонимы |

Исходное окно7000 содержит владельцев и дерево условий/действий, поэтому
команда открывает полноценную вкладку сценариев, а не только сырой список
записей Action/Trigger. При входе снимается поиск владельца и выбирается
глобальный контекст32. Сам вход не создаёт корень или новую привязку.

Категория отрядов существует и при пустом списке. Она объединяет только
поддержанные IsBand записи native/исторического проекта, не обычных героев
на карте. Для новой карты выбирается подходящий шаблон Band/GAMEBAND;
при отсутствии поддержанного шаблона кнопка добавления отключена.
После добавления/дублирования и удаления последнего отряда категория
сохраняется. Исторический неизвестный layout не превращается в другой тип.

Вход в область/проход/эффект ограничивает список выбранным видом. Переключение
вида меняет этот фильтр. «Все виды областей» возвращает общий список.
При пустом списке показать/свойства/удалить отключены; добавление доступно.
Это состояние представления, без изменения файла карты и без записи в JSON.

Как в исходном RectEx_MakePaths, отсутствие областей не открывает патруль:
показывается сообщение с предложением сначала создать область действия.
Новая область автоматически не создаётся, текущая вкладка сохраняется.

Все девять команд менеджеров в меню недоступны без документа. Шесть новых
маршрутов используют общий RequestSourceManager: проверка владельца и живого
карандаша, CommitFields и повторная проверка того же документа. При успешном
входе отменяется незавершённый выбор геометрии и сбрасывается локальное
редактирование патруля; прежние окна отряда/свойств области закрываются.
Закрытый MainWindow не принимает отложенный Click. Неподтверждённое поле
блокирует переход через существующий CommitFields. Сам переход не записывает
байты карты, историю, выделение карты или буфер обмена. Явное принятие поля
перед переходом остаётся обычной операцией редактирования.

повторного подтверждения этого решения не запускался.

## Ручная приёмка M12/M13/M18/M20/M21

1. В EN и RU открыть любую рабочую копию карты. В «Правка» последовательно
   выбрать шесть команд таблицы; убедиться, что открывается указанная панель,
   меню целиком доступно при текущем размере окна и масштабе экрана.
2. В отрядах проверить пустой список, Добавить/Изменить/Удалить/Undo; после
   удаления последнего отряда список остаётся выбранным. Не путать отряд
   с размещённым на карте существом.
3. В областях/проходах/эффектах проверить тип списка, переключение вида,
   «Все виды областей», выбор геометрии, Escape, свойства и Undo удаления.
4. На карте без областей выбрать патрули: сообщение, без новой записи.
   После явного добавления области команда должна открыть редактор маршрутов.
5. В сценариях проверить владельцев, дерево и псевдонимы. Начатое неверное
   поле свойств должно блокировать переход; после исправления переход доступен.

Computer Use, WPF, renderer и игра на этапе не запускались. Игровая приёмка
по-прежнему использует семь файлов DK2Preview_6a88240eaf814f78 и
`DKII-DX.exe -q -level DK2Preview_6a88240eaf814f78`.
