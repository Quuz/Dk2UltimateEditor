## Граница текстовой совместимости

Исходный C writer вызывает MultiByteToWideChar с CP_OEMCP и длинами63/1023,
хотя поля имеют64/1024 WCHAR. Текущий редактор использует уже описанный
контракт: project char — строгий CP1252, native текст — строгий UTF16;
логический текст переносится без повторного OEM-декодирования. Изменённый
текст ограничен размером с NUL, переполнение/непредставимый текст отклоняются.
Это явная адаптация к текущему формату и корректному тексту, а не утверждение
побайтовой эмуляции OEM-зависимости или ошибок C API на предельной длине.
Реальное отображение и шрифты остаются ручной группой M14.

Speech bank отличается от остальных строк: writer использует CopyMemory32,
и наш compiler копирует32 сырых байта, включая хвост после NUL. Это не
перекодирование отображаемого имени. Полные импортированные строки и потери
при других межформатных преобразованиях не объявляются закрытыми: это I03/I04.

## Исправление инвентаря и остаток

В прежнем списке было24 функции с return type int. Он пропускал четыре
BYTE*-функции записи переменных: GeneratePlayerVariables,
GenerateCreaturesVariables, GenerateAlliesVariables и GenerateGlobalVariables.
Теперь в Compiler_Generate.c учтены **28 writers и отдельный SetDate**.
Это уточнение перечня исходных функций; число пользовательских требований
и открытых групп не увеличилось. Исправлен только инвентарь, не код writer.

Две таблицы полей выше завершены в указанном контракте. Оставшиеся26 writers
не объявлены полностью сверенными: их уже доказанные ordering/date/fallback/
retention части сохраняются, а недостающая сверка полей продолжается с things
и четырёх helpers переменных. Общие validator/version routes также остаются
в I02. Результаты прошлых этапов не ставятся на повторный запуск без причины.

AI-профилей, metadata/general settings, speech, версий, terrain/heart checks и

отказа. Это исторические доказательства отдельных групп, не зелёный полный
результат текущей DLL. Более поздние точечные данные перечислены в текущих
документах по dates, defaults, Things order и I05.

Открыты прежние8 кодовых и23 ручные группы. I02 целиком и вся исходная цель
