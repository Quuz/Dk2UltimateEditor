# M10: безопасный ручной показ ошибки Undo

Обновлено1ноября2026. Это изолированный режим тестового проекта.
Первый фактический запуск выявил отказ WPF LoadComponent для производного
Application. Исправлено: точный App(startEditorOnStartup:false), без загрузки
настроек; посторонний отчёт synthetic load подавлен только в стенде.
Computer Use к процессу dotnet завершился app approval timed out.
Позднее запущен apphost WindowsSmoke.exe и получен доступ Computer Use.
Настоящий RU-notice проверен при125%: текст/флажок читаемы, Escape/X,
remember+OK, повтор подавлен; Undo=False/Redo=True/Changed=False/counter0
сохранены. Сброс/UndoRedo в стенде/EN/другиеDPI остаются непроверенными.
Обычный --history-only программно закрывает окна и не заменяет этот проход.

## Запуск пользователем

Из PowerShell выполни одну команду для русского окна:

```powershell
dotnet "D:\Games\DK2\DK2-Map-Editor\tests\DK2MapEditor.WindowsSmoke\bin\Release\net10.0-windows\DK2MapEditor.WindowsSmoke.dll" --manual-history-memory-notice ru
```

Для английского повтори команду, заменив последний ru на en. Команды предназначены
для текущего проекта в рабочей папке; standalone runtime ZIP не содержит test DLL.
Если тестовая сборка отсутствует, из корня проекта сначала собрать её:

```powershell
dotnet build tests/DK2MapEditor.WindowsSmoke/DK2MapEditor.WindowsSmoke.csproj -c Release
```

Откроются редактор с временной DKM14×14 и небольшая панель M10.
Свои карты в этом режиме не открывай. Настройки не сохраняются, автосохранение
выключено; исходные/игровые файлы режим не загружает. Имитация подменяет один
copy callback, а не расходует heap. Изменения только в synthetic memory buffers;
временная папка удаляется после закрытия.

## Проход

1. Запомни показанные Undo/Redo/Changed/counter. Первоначально есть одна ветка Redo.
2. Поставь курсор у края экрана и нажми «Показать безопасную ошибку Undo».
   Настоящее окно приложения должно быть читаемым, находиться в рабочей области
   монитора и блокировать родителя до закрытия. Это штатный dispatcher/error-window
   маршрут приложения с изолированными настройками запуска.
3. Закрой через Escape. Повтори и закрой крестиком. Повтори и нажми OK.
   Прежние карта/Undo/Redo не должны пропасть или добавиться как failed edit.
4. Отметь «Запомнить» и нажми OK. Следующий запрос должен обработаться без
   повторного notice в этой сессии. Это не повторная попытка failed operation.
5. Открой «Настройки истории / сброс уведомления», нажми сброс показа ошибки,
   закрой настройки. Повтори имитацию: notice должен снова появиться.
6. Через кнопки Undo/Redo проверь возврат ранее существовавшего шага. Окно ошибки
   не должно создавать новый шаг. Закрой оба окна; при вопросе о synthetic DKM
   можно отказаться от её сохранения.
7. Повтори EN/RU и масштаб125/150/200%, если эти режимы доступны. Проверь текст,
   Tab/Enter/Escape, фокус после закрытия, checkbox и положение у края монитора.

Выход с code0 означает только закрытие инструмента. Он не выставляет M10=PASS
и не записывает автоматическое принятие. Сообщи язык/DPI, выполненные шаги и
наблюдения; при ошибке — конкретный шаг и текст. Полный [ручной план](MANUAL_ACCEPTANCE_RU.md)
и [согласованная политика](HISTORY_MEMORY_NOTICE.md) остаются основными.

App получил явный режим изолированного старта; обычный конструктор по-прежнему
запускает редактор. Исправленный helper собран; оставшиеся подпункты notice требуют ручного прохода. Агенту разрешён Computer Use.
