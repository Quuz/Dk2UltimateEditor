# Смена языка заголовков таблицы свойств — 2 ноября 2026

Исправлена подтверждённая ошибка M23: в открытом редакторе при EN → RU
заголовки таблицы свойств оставались английскими. DataGridColumn не входит
в визуальное дерево, поэтому DynamicResource его Header не обновлялся вместе
с остальным окном. `EditorWorkspace.RefreshLanguage` теперь явно обновляет
все четыре заголовка: поле, значение, именованное значение и смещение.

Проверка `--workspace-language-headers-only` добавлена в существующий проект
DK2MapEditor.WindowsSmoke. Она открывает изолированное окно MainWindow
без записи настроек и без запуска пользовательской сессии. На новых DKM
и native-картах в одном и том же открытом окне выполняется EN → RU → EN.
Для каждой стадии проверяются реальные DataGridColumnHeader в визуальном
дереве (всего 24 заголовка), выбранная запись, наличие строк свойств,
полный отпечаток транзакционных буферов и метаданных, revision и вся история.

До исправления: exit 1, первая стадия EN успешна, затем RU сохраняет Field.
После: exit 0, все шесть стадий успешны. Полное решение из 43 проектов
собрано: exit 0, ошибок и предупреждений нет. Остальные успешные тесты
не повторялись: изменение затрагивает только перевод четырёх заголовков.

Команда проверки:

```powershell
tests/DK2MapEditor.WindowsSmoke/bin/Release/net10.0-windows/DK2MapEditor.WindowsSmoke.exe --workspace-language-headers-only
```

Доказательства: `artifacts/Evidence/WorkspaceLanguage-20261102/test-before.log`,
`test-before.exit.txt`, `test-after.log`, `test-after.exit.txt`,
`build-solution.log`, `build-solution.exit.txt`.

Исправление установлено2ноября в прежнюю `artifacts/PreFinal/App` после
закрытия редактора пользователем. Install-Ready.ps1 сверил все372файла
манифеста; App DLL совпала с проверенной ccbdd52f… (полный SHA256 в result.json).
Новая сессия MCP подключена. Через настоящее меню выполнено RU→EN→RU:
все четыре заголовка, выбранный GAMEBAND, полная карта и история сохранены.
Наблюдения: Evidence/NativeNested-20261102/ui-observations.json.gz.
Архивы исходников и поставки обновлены; текущая поставка имеет приоритет
над временной Ready из Evidence. Исходники остаются в одном проекте.

M23 целиком не закрыт: это точечная WPF-регрессия, не полный ручной проход
всех окон, языков и DPI. [Состояние native-проверки M13](NATIVE_BAND_CHECKPOINT_20261102.md).
