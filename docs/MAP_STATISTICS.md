[Первый настоящий native RU125% проход 3 ноября](MANAGERS_LIVE_20261103.md): менеджер/навигация и часть статистики; остальной конечный объём открыт. Координаты назначения нормализуются исходными callback: X999→43, нечисловой токен читается как0, поэтому прежнюю фразу о запрете любого неверного X/Y следует читать с этим уточнением.

The statistics workspace contains bilingual read-only map/player/band calculations and an implemented activity panel. Calculated-content rules below come from the preserved `Map_Stats.c`; activity implementation and its remaining acceptance are described in [the current source scope](ACTIVITY_STATISTICS_SOURCE_SCOPE.md). This does not complete editing parity or establish in-game acceptance.

## Source rules and calculations

- `Source/Sources/Map/Map_Stats.c`, `Map_CreateStats`: total tiles, water/lava/solid/rock/unclaimed counts and percentages; creature, trap, door, ordinary-object and special-item counts; species counts, integer level averages and most-common types. Equal counts prefer the smaller ID. Map creature counts include imps; player creature counts/averages/preferred species exclude them and show imps separately.
- `Source/Sources/Compiler/Compiler_Info.c`, `Compiler_InfoEnumTerrainInRect`: source edge types 30/254 count as solid. Rooms, gates, walls and claimed paths count as player terrain; closed mana vaults belong to Neutral and heroes' rest belongs to Heroes. These owned-tile totals are not room-object counts.
- `Compiler_InfoGoldAmountInRect`: gold terrain uses its `GoldValue`; gems indicate unlimited gold without adding a finite amount. Object IDs 1–3 contribute their stored gold; Influx Cash special 0x79 contributes map variable 0x1B per item. The three finite gold totals remain separate.
- `Compiler_InfoTreasuryCapacityInRect`: treasury tiles use variable 0x18; a recognized heart adds sixteen times variable 0xB2. The heart position follows the original first-tile/centre rule, not a search for a later valid heart.
- `Compiler_InfoManaInRect`: read applicable terrain `ManaGain` values in row order until the room cap 0xEB, add 30 for a heart only while below that cap, clamp to 0xEB, then add open mana-vault gains and clamp to total cap 0xA6. Open vaults bypass the first limit. Lair capacity is its tile count.
- `Map_CreateStats`: band statistics stop at the first inactive member; imps (1), dwarfs (14) and other creatures are separate. Average level includes all active members; preferred band species excludes imps/dwarfs. Release counts match `ACTION_RELEASEBAND` parameter 1, including band ID zero. The source's displayed hero total is other band creatures plus all placed heroes, while its level average includes all band members and placed heroes; labels make this asymmetry explicit.
- `Source/Sources/Files/Files_Game.c`: native heroes belong to player 1 and neutrals to player 2. A native hero's `bGlobalPlayer` stores its enemy, not its ownership. Object IDs 0x75–0x81 import as special items.
- `Properties_Map_Players.c`: starting gold greater than treasury capacity warns for keepers but is not a save prohibition. The new player tab shows terrain gold (plus the gems indicator), treasury capacity and mana, with a warning evaluated against the current gold draft. Existing input/range/encoding validation remains independent.

## Definitions, preservation and deliberate fixes

Verified project `GLOBALTERRAIN` overrides use the 38-entry `GTerrains` order. Native terrain records use the 41-entry `GTOrder`; packed containers use the terrain section's own header/version, not the first unrelated section. Gold/mana defaults come from the preserved `Binaries/Globals/DefaultTerrain.dkg`, embedded read-only and decoded using source compiler offsets. Missing map-variable overrides use the original editor's reference defaults; shared game-variable collections are not treated as map overrides. These are original-editor calculations, not a claim to reproduce all effective game-engine behavior.

No calculation edits buffers, normalizes owners, upgrades sections, changes history or raises `Changed`. Unknown layouts produce notices; dependent resource values and unverified scenario release counts are not reported as guessed zeroes. Unknown tile combinations are excluded from categorized counts but remain in the total percentage denominator. Source fixed world/gate owners are used for calculation without rewriting noncanonical input bytes. Sparse bands retain the source initial-active-prefix behavior and are flagged.

Totals use 64-bit arithmetic instead of overflowing the original 32-bit accumulators. Unknown species IDs do not index a fixed 256-element array. Duplicate band IDs retain separate physical rows and a warning instead of sharing/double-counting the original per-ID accumulator. The source mana routine can reuse an uninitialized/stale terrain ID on world tiles; the new code does not reproduce that undefined behavior and gives world terrain no room-mana contribution.

UI statistics snapshots are lazy and invalidated on document refresh/edit/undo/redo; hidden statistics do not scan the map for every player-draft keystroke. The player and band choices survive live language changes. Navigation can select/show a heart centre or open the selected band's typed properties. Closing a document clears all statistics/resources/warnings.

## Verification and remaining acceptance

`MapStatisticsChecks` independently anchors source binary offsets/default values, constructs native/project terrain and placed-entity fixtures, and checks counts/percentages, resource categories, hearts/treasuries, both mana caps, zero room cap, hero ownership, integer averages/ties, band-zero release actions and the source hero-total formula. It covers project overrides and native compilation/reopening, unknown definition/scenario formats, unknown species/owners/tiles, sparse and duplicate bands, over-32-bit gold totals, exact source-buffer/history preservation and undo/redo. Logical statistics projections are also compared before/after saving all 57 local native maps and six text inputs; original input buffers/files remain unchanged.

Four WPF EN/RU × native/project cases exercise actual read-only grid bindings, seven player choices, physical band selection, labels and live localization, heart/property navigation, draft warnings and nonblocking player application, snapshot refresh on paint/undo and document-close cleanup. Optional `DK2_STATISTICS_UI_ARTIFACTS` writes offscreen PNGs of all three pages and the player warning for inspection. Rendered inspection caught collapsed star-width columns; readable minimum widths and wrapping are now checked. This is not native mouse/keyboard or historical-GUI testing.
