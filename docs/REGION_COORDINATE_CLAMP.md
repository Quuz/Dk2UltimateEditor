# Координаты областей: ввод и стрелки

RegionCoordinateClamp-20261018. MC05 — подпункт I17. Общий редактор свойств
области, прохода и генератора эффектов ограничивает введённые координаты
сразу: X1/X2 находятся в 0..Width−1, Y1/Y2 — в 0..Height−1. Это работает
как при создании, так и при изменении существующей записи. Размеры X/Y
берутся отдельно, поэтому прямоугольная карта не использует ширину для Y.

Кнопки ▲/▼ меняют поле на единицу и останавливаются на границах.
Удержание кнопки использует WPF RepeatButton; Up/Down внутри числового поля
без модификаторов имеют то же действие. Подсказки и доступные имена EN/RU:
«Увеличить на 1»/«Уменьшить на 1». У прохода конечные X2/Y2 недоступны
вместе со своими стрелками и повторяют принятые значения X1/Y1.

Обычный ввод принимает ASCII цифры, как ES_NUMBER исходного ресурса.
Промежуточное пустое поле не заменяется текстом «0» при каждом нажатии.
Для вставленного/программного текста используется unsigned decimal prefix:
начальные пробелы пропускаются, чтение заканчивается на первом нечисловом
символе, нечисловой ввод и UINT overflow дают 0. Исходное присваивание UINT
в LONG учтено перед clamp. EN_CHANGE переписывает текст только при выходе
полученного значения за границы; Apply/стрелка используют полученное число.
Это поведение основано на вызове GetDlgItemInt(FALSE) в исходнике и
[документации Microsoft](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getdlgitemint).
Фактические Win32/WPF доставка ввода, paste/IME и repeat остаются ручной M20.

Изменяются только поля окна. Открытие и закрытие черновика не записывают
координаты или неизвестные байты в карту. Общие сессии свойств/создания,
вложенные options/generation, проверка владельца и атомарный Apply сохранены.
Gate synchronization не применяется к неизвестным импортированным байтам
при загрузке. Stale owner, pending geometry pick и открытый дочерний диалог
не дают стрелкам менять черновик; CommitFields и проверка актуальности
перед Apply остаются прежними. Core и формат семи игровых файлов не менялись.

## Ручная приёмка M12/M20/M23

1. На прямоугольной карте открыть создание области и изменить X/Y за верхние
   границы: в полях сразу появляются Width−1/Height−1. Проверить оба конца.
   Повторить для генератора эффектов и существующей записи через «Свойства».
2. Нажимать/удерживать ▲/▼ на каждой границе и использовать Up/Down в поле.
   Координаты не выходят за карту. У прохода X2/Y2 повторяют X1/Y1,
   конечные поля и стрелки недоступны.
3. Очистить поле, ввести число, вставить текст с числом/без числа. Проверить
   каретку, Tab, клавиатурный фокус, EN/RU и DPI100/125/150.
4. Закрыть без применения — карта прежняя. Применить — один шаг Undo;
   Undo/Redo восстанавливают геометрию. Смена документа блокирует старое окно.

Остаток parent-команд I17 — MC06 (отдельная команда New Point).
Ctrl+N = новая карта и Ctrl+Y = Redo остаются по решению пользователя.
