# Ввод положения и радиуса света существа

Этап CreatureLightCallbacks-20261019, часть открытого I11. Исправлены четыре
числовых обработчика страницы Light. В исходном Properties_GlobalLightProc
контролы 104/106/108 ограничивают целую часть координат диапазоном −32767…32767,
контрол 114 — целую часть радиуса диапазоном 0…3. Проверка происходит сразу
при EN_CHANGE, а не только при применении страницы.

Дробь сохраняется, когда целая часть внутри диапазона: радиус `3.75` остаётся
`3.75`, координата `32767.75` остаётся `32767.75`. Ввод `4.25` для радиуса
немедленно становится `3.0`; координата `−32768.75` — `−32767.0`.
Исходный GetDlgItemInt читает целую часть. Spin сначала изменяет эту целую
часть на единицу через Misc_SetUpDownInt[Signed], затем запускает EN_CHANGE:
для координаты `−1.75` увеличение даёт `0`, для радиуса `2.75` — `3`.
Уменьшение нулевого радиуса проходит исходный unsigned/LONG маршрут и даёт `0.0`.

В текущем редакторе CreatureLightInputs реализует эти текстовые преобразования;
CreaturePageControls направляет в него Light spin, CreaturePageWindow — явный
TextChanged. Это обработчики пользовательского ввода. Загрузка импортированного
значения, смена языка и применение неизменённой страницы не исправляют исходные
байты. Промежуточные пустые/нечисловые строки не заменяются произвольными
значениями; существующая проверка Apply сообщает о невалидном изменении.

Сохраняется частный черновик CreatureGlobalsSession: ввод и Apply страницы
не меняют живую карту. Общий Apply — одна операция Undo; Cancel сохраняет
исходное состояние. Код сериализации, сборки семифайловой карты и защиты
исходных каталогов не менялся. Новых строк локализации нет: 2781 ключ EN/RU.

## Ручная проверка

1. В редакторе откройте глобальные определения существ, выберите существо и
   страницу света. Введите X=`32768.75`, Y=`−32768.75`, радиус=`4.25`:
   поля должны сразу показать `32767.0`, `−32767.0`, `3.0` (минус вводить обычный `-`).
2. Введите X=`−1.75`, увеличьте стрелкой: получится `0`. Для радиуса `2.75`
   увеличение даёт `3`; уменьшение `0` — `0.0`.
3. Введите X=`1.25`, радиус=`3.75`, переключите EN/RU: строки должны сохраниться.
   Отмените общее окно: карта и история не должны измениться.
4. Повторите изменение и примените общее окно: один Undo возвращает всё.
   Проверьте на native и DKM. Импортированная координата за границей не должна
   меняться от одного открытия страницы или смены языка.

Игра для этой проверки не требуется. Все последующие игровые прогоны используют
только DK2Preview_6a88240eaf814f78 и DKII-DX.exe -q -level.
