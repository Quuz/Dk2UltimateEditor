# Изображения комнат в приоритетах строительства ИИ

21 октября 2026. Этап AIRoomPriorityImages-20261021, часть I13.

В текущем списке приоритетов строительства отображались только номер и имя
комнаты. Исходный `Properties_Map_Computer.c` создаёт из `CPURooms` список
изображений 32×32, присоединяет его к списку комнат и сохраняет отдельно
`CPURooms.Id` в `Item.lParam`; `Item.iImage` является индексом исходной строки.

Теперь `PlayerAIOptions.RoomImageResource(id)` возвращает номер исходного BMP
по ID из `CPURooms`. Это отдельное пространство ID: например, 1 — сокровищница
с ресурсом403, 2 — логово с401, 3 — портал с411. ID5 отсутствует.
Нельзя использовать позицию приоритета, ID местности или номер комнаты из
другого каталога. Все 15 соответствий записаны вместе с исходными путями и
SHA256 BMP в `artifacts/Evidence/AIRoomPriorityImages-20261021/source-scope.json`.

Строки `PlayerAIRoomOrder` получили свойство Icon и существующий шаблон
изображение+Label. Текст, номер позиции и выбор по индексу остаются прежними.
При перестановке изображение следует за ID комнаты; смена языка использует
прежний локальный порядок. Неизвестное импортированное значение сохраняет
текст `#ID`, пустую картинку и прежние ограничения перестановки. Нулю и
отсутствующему ID не подставляется изображение другой комнаты.

Используются уже встроенные изображения и существующий frozen image cache.
Новые копии BMP, resource declarations и fallback-картинки не добавлены.
Применение настроек, отмена, приватный контекст общих свойств карты и формат
записи параметров ИИ не менялись. Подписи и словари EN/RU прежние.

Фокусный headless check `--player-ai-room-images-only` проверяет 15 literal
ID/resource пар против исходного `CPURooms`, исходные RC/BMP против байтов
managed PE собранного App, неизвестные/граничные IDs, прямой и обратный порядок,
native/DKM buffers и историю до/после чтения изображений. App и WPF не
загружаются. Проверка также подключена к группе PlayerAIOptionsChecks.

В существующий PlayerAISmoke добавлены проверки шаблона, картинок строк,
позиции после перемещения, сохранения черновика при смене языка и неизвестной
строки. Этот WPF-код только компилируется; его исполнение и ручная проверка
настоящего списка, прокрутки, контраста и DPI остаются M-группами.

Также сохранён конечный inventory активных вызовов Misc_CreateImageList из
сохранённых .c, без Obsolete и деклараций. Он не доказывает полноту всех
draw/control consumers. Следующие конкретные места: PathAreas в Things_Paths,
PvIcons в Things_Manager, TrImages в Triggers_Select, затем остальные
потребители из записанного списка. Прежние доказательства definition/scenario/
reward/object images переиспользуются; неизменённые успешные группы не
запускаются ради счётчика.

Ручная проверка: откройте текущую сборку, выберите игрока и раскройте настройки
ИИ. В списке приоритетов должны быть картинки комнат. Переместите строку
вверх/вниз: картинка должна следовать за названием комнаты. Переключите EN/RU:
локальный порядок и выделение должны сохраниться. Проверьте прокрутку и
читаемость при своём масштабе Windows; применять изменения карты для этого
не требуется.
