# Параметры снарядов: выбор и подтверждение

15 октября 2026. Специализированные элементы параметров снарядов повторяют
Properties_GlobalShotInit/Save оригинала. Это касается ловушек, обычного и
улучшенного заклинания хранителя и заклинания существа — четырёх независимых
мест хранения. Все 66 исходных типов и их пять форм остаются доступными.

## Выбор при открытии и принятие

| Исходная форма | Показанный выбор | Результат подтверждения |
| --- | --- | --- |
| 2: существо и количество | Неизвестная цель → первый вид из исходного каталога | Сохраняется показанная цель и количество |
| 3: существо и уровень | Неизвестная цель → первый вид; уровень вне 1–10 → 1 | Сохраняются показанные цель и уровень |
| 4: предмет и золото | Неизвестная цель → первый предмет | Для предмета с ID ≠ 1 второй параметр становится 0 |
| 0, 1: числовые параметры | Прежние значения и исходная знаковость | Прежние правила активных параметров |
| FF: без параметров | Поля скрыты | Неактивные сохранённые параметры сохраняются |

Первый вид и первый предмет исходных каталогов имеют ID 1. Подстановка
существует в черновике. Открытие, смена языка и отмена сохраняют исходные
байты, историю и счётчик. При подтверждении дочернего окна выбранные значения
возвращаются в частный черновик родителя; карта меняется только после общего
Apply. Встроенная панель записывает их своей явной кнопкой Apply.

Ранее встроенная панель показывала неизвестную цель отдельной строкой и
сохраняла неактивную сумму для неизменённого предмета. Дочерние окна также
сохраняли неизвестный выбор. Эти различия исправлены в текущем маршруте UI.
Базовый SetGlobalProjectile и прямое редактирование полей сохраняют возможность
удержать импортированные неизвестные данные. Никакие установленные файлы
автоматически не исправляются. Неизвестный тип снаряда остаётся доступным
через поля и не получает угаданную специализированную форму.

## Реализация

GlobalProjectiles.EditorInputs формирует показанные значения без доступа
к документу. Его используют встроенная панель и три класса дочерних окон:
GlobalTrapOptionsWindow, GlobalSpellOptionsWindow, CreatureSpellOptionsWindow.
Смена языка удерживает текущие частные значения. Формирование списков,
знаковость, диапазоны, изображения и проверки владельца окна сохранены.

SetEditorGlobalProjectile применяет исходные показанные значения и обнуляет
неактивную сумму даже при неизменённых типе и цели. Он использует прежнюю
атомарную запись определения. Дочерние окна возвращают прежние типизированные
черновики и используют общий Apply родителя. Дочерняя исходная функция
Properties_GlobalShotSave не создаёт отдельный MapChanges/Undo — она меняет
GLOBALSHOT в контексте; современный родитель тоже не получает лишнюю операцию.

Неактивный второй параметр формы 1/FF и знаковые WORD-алиасы сохраняются.
Правила компилятора для ловушек и обоих слотов хранителя не изменены.
Диапазоны native WORD остаются проверяемыми; проектная сумма золота может
достигать исходного предела 80000. Остальные правила ввода и физическое
поведение числовых контролов требуют своей приёмки.

## Доказательства и границы

Снимок Properties_GlobalShotInit/Save связан с хешами исходного обработчика
и двух каталогов. 1320 сочетаний всех 66 типов, пяти значений цели и четырёх
значений второго параметра проверяют показанные выборы. 96 сочетаний двух
форматов, четырёх слотов, трёх составных форм, известной/неизвестной цели
и двух вариантов параметра проверяют встроенное принятие и частный дочерний
черновик/общее применение. Сравниваются полные байты, счётчики, история,
Undo/Redo и отсутствие статистики рисования. Прежние тесты базового API,
всех типов, диапазонов и компилятора сохранены.

Проверки WPF дополнены действительными дочерними классами: выборы, Cancel,
принятие частного черновика, общий Apply, перевод EN/RU и Undo. Они только
скомпилированы; окна, renderer, официальный редактор и игра не запускались.
Общий результат: [CURRENT_STATUS](CURRENT_STATUS.md). Доказательства:
artifacts/Evidence/ProjectileAcceptance-20261015.

## Ручная проверка

1. Откройте параметры снаряда создания существа с неизвестным импортированным
   видом либо уровнем вне 1–10. Должны быть показаны первый вид и уровень 1.
   Отмена должна сохранять исходные поля.
2. Подтвердите дочерние параметры, затем отмените общий родитель: карта должна
   сохраниться. Повторите с общим Apply и Undo: выбранные значения должны
   записаться одним действием и полностью отменяться.
3. Для предмета ID ≠ 1 с сохранённой суммой подтвердите параметры: сумма должна
   стать 0. Переключение на золотой предмет ID 1 должно включать её поле.
4. Повторите для четырёх слотов, встроенной панели и EN/RU. Проверьте сохранение
   черновика при смене языка и отказ при устаревшем окне после изменения карты.
