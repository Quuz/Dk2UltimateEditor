Остальные игроки сохранили прежние состояния. Через Shift+Right выделены

отсутствии частичных изменений; в таблице осталось32. Допустимые18 записались
только выбранному игроку. Союз Хранитель1↔Хранитель2 отобразился симметрично;
диагональ матрицы осталась только для чтения.

полный fingerprint карты и метаданных совпал с базовым, revision0/dirty=false,
Undo/Redo пусты. Принятый дочерний контекст не попал в живую карту.
