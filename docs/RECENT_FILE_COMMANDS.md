# Недавние файлы: очистка и проверка доступности

17 октября 2026, RecentFileCommands-20261017. Закрыты три конкретных маршрута
внутри I17 из [перечня функций](OPEN_FUNCTIONS_RU.md): очистка списка, удаление
недоступных записей и исходный вид имени файла. Это часть I17, не завершение
всей сверки менеджеров/Config и не новая возможность сверх исходника.

## Исходник и реализация

| Маршрут | Эталон | Текущий App |
| --- | --- | --- |
| Очистить список | Windows_MainWindowProc.c: IDM_RECENTREMOVEALL → Config_RemoveAll; сохранить recent entries, информационное OK | Файл → Недавние файлы → Очистить список; очистить только settings.RecentFiles, обновить меню и JSON, информационное сообщение EN/RU |
| Убрать недоступные | IDM_RECENTREMOVEOBSOLETE → Config_RemoveObsolete; CreateFile с access0, READ/WRITE sharing, OPEN_EXISTING, SEQUENTIAL_SCAN | Тот же Win32 probe через CreateFileW/SafeFileHandle; убрать только неоткрываемые записи, сохранить порядок оставшихся, обновить JSON; отдельные сообщения «все доступны» и «записи убраны» |
| Имя в списке | Config_SetToDefault обнуляет RecentPaths; Config_UpdateRecentMenu берёт basename, полный путь хранится в RECENTFILE | Имя файла в TextBlock без интерпретации подчёркиваний; полный путь остаётся tooltip и аргументом OpenMap |

Код: `src/DK2MapEditor.App/MainWindow.Save.cs`; шесть новых строк в каждой
`Localization/Strings.en.xaml` и `Strings.ru.xaml`. Прежние 2619 literal values
сохраняются; всего 2625 ключей на язык. Команды остаются доступны при пустом
списке; вместо файлов показана неактивная строка. Перевод команд привязан к
DynamicResource и обновляется вместе с языком окна.

Win32 probe запрашивает только метаданные, без прав чтения содержимого: обычный
FileStream мог бы ошибочно отсеять файл, у которого запрещено чтение данных.
Каждый handle закрывается. Исходная логика отказа доступа/блокировки сохраняется,
но обход списка не копирует потенциально опасный сброс linked-list iterator
исходника. Форматы/данные карты, текущий документ, его Undo и обычная цель
сохранения не меняются. Команды отклоняются у закрытого владельца и во время
активного сохранения. LastOpenedFile остаётся отдельной настройкой.

## Ручная приёмка M20

1. На собственной копии открыть два файла, включая имя с подчёркиванием.
   В списке видны имена; tooltip содержит полный путь, нажатие открывает именно
   этот файл. Переключить EN/RU: команды и сообщения переводятся.
2. Закрыть одну тестовую копию и переместить её вручную в другую тестовую папку.
   «Убрать недоступные файлы» удаляет только её запись. Другая запись сохраняет
   порядок и работает. Повтор команды сообщает, что все файлы доступны.
3. «Очистить список» оставляет пустой список и обе команды обслуживания.
   Файлы на диске остаются. Текущая карта, несохранённая правка и Undo сохраняются.
4. После перезапуска список остаётся очищенным. Отдельно проверить файл с
   запретом доступа/несовместимым sharing на собственной временной копии;
   недоступность должна совпасть с описанным Win32 probe.

Эти шаги ещё не выполнены. Остальные пункты I17 и все необходимые M-группы
сохраняются. Полная цель остаётся активной.
