# Отдельные параметры добавления и изменения

17 октября 2026, ManagerOptionsDialogs-20261017. Внутри I17 подключены две
исходные команды: параметры добавления и параметры изменения. Это отдельные
приватные настройки сеанса, не правка объектов и не шаг Undo.

## Исходник и область

Things_Manager.c:117/127 открывают ModifyOptions/AddOptions без необходимости
выбирать объект. Оба caller копируют MNGRMODPARAMS/MNGRADDPARAMS в Context,
открывают6450/6451/6452/6460 и возвращают значения в Config лишь после OK.
Cancel/ошибка создания выбрасывают копию. Эталонные Init/Save и Editor.rc
сопоставлены; исходные файлы не менялись.

В App появились две кнопки и ObjectManagerOptionsWindow. До применения
изменяются только элементы окна. Все числа разбираются до записи runtime
полей; ошибка не сохраняет даже часть новых флагов. Закрытие/Escape/Cancel
оставляют прежние значения. Флажки AskOptions/Preview не подменяются этими
окнами и сохраняются; не затрагиваются templates, координаты и другие семьи.

| Окно | Видимые параметры | Что сохраняется скрытым |
| --- | --- | --- |
| Добавление | One/Rectangle/Random, частота2–32, четыре Ignore-флага, replacement для несуществ | AskOptions/Preview, IgnoreIncompatible и другие биты, координаты/whole-map scope, template; replacement существа не переписывается |
| Изменение существ | Coordinates/Type/Owner/Level/Gold/Health/CreatureOptions/HeroOptions/Objective, Same/Relative, оба режима битов и UInt32 masks, пять Ignore-флагов | Data mask и replacement другой семьи, template и координаты назначения |
| Изменение door/trap/object/special | Coordinates/Type/Owner/Data, forced Relative, replacement и пять Ignore-флагов | Режим координат существ, их masks/modes и прочие семейные биты |

Нулевые/старшие и неизвестные32-битные маски не преобразуются в signed int.
Числовые ограничения нового окна сохраняют существующее строгое поведение
raw drafts: неверная маска требует исправления, не нормализуется молча.
Частота применяется в Random; в остальных режимах её прежнее значение
сохраняется. Source AddSave забывал сохранять slider frequency; уже принятое
современное исправление с действующей частотой сохраняется и здесь.

Добавление и изменение имеют независимые options. В трёх исходных list families
команда доступна и без selection. В дополнительном modern All Families режиме
параметры изменения требуют выделения одной семьи, чтобы не выбирать её
произвольно. Диалог локализован EN/RU, смена языка сохраняет draft/ID, follow-mouse
ограничен рабочей областью монитора через существующий placement helper.

Смена/закрытие документа отменяет дочерний draft. Пока он открыт, Add/Modify/
Remove/local Undo и navigation не принимают параллельную команду. Применённые
настройки используются следующим общим batch window; данные карты, история,
copy buffer и game-format bytes в настройках не хранятся. Открытие менеджера
по-прежнему может предварительно принять pending property edit своим обычным
маршрутом; это не запись из options dialog.

## Проверка и оставшееся

Все41 проекта build01 и publish01 завершились с кодом0, без предупреждений
и ошибок. GUI/редактор/игра не запускались. Это обратимая правка настроек;
отдельные повторяющие реализацию тесты не добавлялись. Настоящее окно и
клавиатура/focus/DPI остаются ручной M20, компиляция их не подтверждает.

Core и все tests/ не менялись; полный корпус и успешные CLI/official проверки
не повторялись. Последний full1815 PASS/63 прежних отказа — ManagerCommandHistory
на той же Core. EN/RU2641 keys,6 новых на язык; прежние2635 literal values
сохранены. Source/Binaries/fixtures и прежний seven-file TestMap неизменны;
установленные карты не записывались. Evidence: artifacts/Evidence/ManagerOptionsDialogs-20261017.

I17 **не закрыт целиком**. Пока существующий combined batch window всё ещё
показывает preview/confirmation явно. Следующий конкретный объём:

1. AskOptions: вызывать отдельные окна только при этом флаге; Modify учитывает
   source выбор single/multi до script filtering.
2. Preview: использовать источник RequiresPreview/forced warning/replacement
   decisions; отсутствие флага не означает разрешение игнорировать обязательный
   warning или stale/layout guard. Прямой путь должен использовать тот же Undo.
3. Связать Manager on-map/selection с прямоугольным Add; отдельный full-template
   editor нужен до прямого запуска, поскольку source редактировал template
   прямо на основной панели менеджера.

На момент ManagerOptionsDialogs эти пункты оставались открытыми. Теперь они
реализованы в [ManagerExecutionFlow](OBJECT_MANAGER_EXECUTION_FLOW.md): там
описаны текущий порядок команд, доказательства и ещё требуемая ручная M20.
Остальная сверка I17 и все прочие I/M пункты сохраняются.

## Ручная проверка M20

1. Выбрать семейство без selection. Открыть оба окна, поменять параметры,
   отменить и открыть снова: прежние настройки сохраняются. Карта/Undo прежние.
2. Применить Rectangle/Random с частотой17, затем открыть добавление: режим
   и частота перенесены. Настроить другое replacement в семействе дверей,
   открыть параметры существ: скрытые настройки другой семьи сохраняются.
3. Для существ проверить high-bit masks и плохой ввод: ошибка оставляет
   окно открытым и прежние настройки нетронутыми. Исправить, применить,
   проверить следующий multi-edit. Отдельно проверить hidden coordinates/masks
   после посещения несуществ и live EN/RU с набранным draft.
4. Проверить закрытие/смену документа с открытым draft, Escape/Enter/Tab,
   положение у краёв экрана, второй монитор и DPI. Агент эти шаги не выполнял.
