# Количество второго привлечения: исходные обработчики ввода

CreatureParameterInputs-20261019, часть I11. В Properties_GlobalParamsProc
EN_CHANGE обрабатывает ровно одно числовое поле — 129, количество второго
привлечения. Если тип 127 не «Нет», исходный GetDlgItemInt(...,FALSE)
возвращает unsigned результат, присваиваемый LONG, после чего поле ограничивается
0…16000 через SetDlgItemInt. UDN_DELTAPOS вызывает Misc_SetUpDownInt для 129:
целая часть меняется на единицу, затем применяется тот же EN_CHANGE.

Теперь ввод `16001` сразу становится `16000`. Уменьшение `0` остаётся `0`,
стрелка из пустого поля вверх даёт `1`. Внутри границ промежуточный текст
сохраняется; применить изменённое количество можно после ввода целого числа.
Существующая проверка Apply остаётся строгой. Открытие импортированного
значения за границей, смена языка и неизменённый Apply не ремонтируют данные.

CreatureParameterInputs реализует два преобразования; общий SourceIntegerInput
содержит прежний буквальный parser из CreatureLightInputs. Поведение света
сохранено отдельной повторной проверкой после выделения parser. Реальный
CreaturePageWindow.TextChanged вызывает нормализацию только для текущего,
доступного поля активного типа и живого владельца. Spin использует прежние
guards. «Нет», неизвестный импортированный тип и устаревшее окно не получают
разрешения менять поле. Типы/списки привлечения продолжают использовать
[уже реализованные зависимости](CREATURE_ATTRACTION_CALLBACKS.md): смена второго
типа восстанавливает количество из приватной строки, смена первого его сохраняет.

Черновик, Apply страницы, общий Apply/один Undo и Cancel сохранены. Native/DKM
writer, compiler, shared data и игровой формат не менялись. Новых ключей EN/RU
нет; все 2781 прежних значений ресурсов сохранены.

## Ручная проверка

1. Откройте определения существ → Parameters. Выберите для второго привлечения
   золото, введите `16001`: сразу должно появиться `16000`. Проверьте также
   комнату, ману и существо.
2. Уменьшите `0`: остаётся `0`. Очистите поле и увеличьте: получится `1`.
   Введите `123`, переключите EN/RU: число сохраняется.
3. Переключите второй тип: количество снова берётся из исходной приватной
   строки. Выберите «Нет»: поле пустое и отключено. Отмените общее окно —
   карта и история прежние.
4. Повторите изменение и примените общее окно. Один Undo возвращает всё.
   Повторите для native и DKM. Импортированное количество за границей не
   должно изменяться от одного открытия или смены языка.

Эти шаги не требуют игры. Для последующих игровых проверок сохраняется только
DK2Preview_6a88240eaf814f78 через DKII-DX.exe -q -level.
