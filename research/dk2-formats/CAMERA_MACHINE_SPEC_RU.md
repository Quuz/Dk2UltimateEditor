# Камеры CD: зависимость от Machine Spec Level

Этап46, 26 октября 2026. Установлено назначение globalDWORD759AEC, оставленного неизвестным на этапе40. Это поле **Machine Spec Level** объекта настроек759A78+74. Наименование подтверждается строкой из самого EXE, инструкциями setter566520 и полной цепочкой setter→camera store449A30.

## Доказательство имени и адреса

Setter566520 сначала записывает переданный DWORD в this+74. При успешном открытии настроек использует указатель66F560→6BDA30 на строку `Machine Spec Level`. Wrapper562670 передаёт её в импортированный `ADVAPI32.RegSetValueExA`: type4, size4, точные32 бита значения. При this=759A78 запись оказывается именно по759AEC. Камерный store449A30 читает этот абсолютный адрес.

Строка, pointerDWORD и таблица профилей сверены с живой памятью Ghidra и исходным PE. Название функции из сторонней карты использовалось только как адресная подсказка; итоговая идентификация опирается на исходные инструкции и строку.

В setter нет ограничения значения:0/2/3/4/5/10/80000000/FFFFFFFF проверены нативно. Это не доказательство допустимости произвольного DWORD во всех игровых подсистемах или GUI. Неуспех открытия реестра и ошибки RegSetValueExA не откатывают уже записанное значение в памяти.

## Как меняется загруженный зум

Для camera ID1..18 полный449A30 делает unsigned сравнение Machine Spec Level с5:

```text
если level <5:
    difference = signed32(ZoomMax - ZoomMin)
    loadedZoomMax = low32(ZoomMin + trunc0(difference /3))
    intermediate presenceDWORD20 =1
иначе:
    loadedZoomMax = исходный ZoomMax
```

| Machine Spec Level | Raw ZoomMin | Raw ZoomMax | Loaded ZoomMax |
|---:|---:|---:|---:|
| 4 | 3000 | 12000 | 6000 |
| 5 | 3000 | 12000 | 12000 |
| FFFFFFFF | 3000 | 12000 | 12000 |

Старший бит здесь не превращает значение настройки в отрицательное: сравнение unsigned. Зато difference у зума делится как signed с усечением к0; переполнение разности сохраняется. Проверены обратные bounds, переходы через signed границу и разности1/2.

Store принимает snapshot настройки при вызове. Само изменение Machine Spec Level не доказано как автоматический пересчёт ранее заполненного банка. Полная активация44ACE0 и изображение камеры не проверялись.

**Файл камеры не меняется.** Уменьшение относится к загруженной intermediate-копии/слоту банка. Независимый редактор должен хранить исходные ZoomMin/ZoomMax и opaqueBYTE53, а зависимую от настройки проекцию использовать отдельно для предварительного просмотра. Нельзя сохранять уменьшенный предел поверх исходного при обычном открытии/сохранении карты.

API `native_cameras.preset_for_machine_spec(raw, machine_spec_level)` явно называет настройку. Прежний `preset_projection(raw, global_setting=...)` сохранён для совместимости; теперь смысл аргумента подтверждён.

## Отличие параметра запуска -SPEC

В5A63B0 опция `-SPEC` передаёт число в565CF0. Эта функция выбирает один из11 профилей0..10 в таблице66F5A0 со stride36, затем меняет восемь полей настроек44/4C/50/54/60/58/5C/68. Она **не присваивает поле74** Machine Spec Level. Полная565CF0 проверена на всех11 профилях и11/FFFFFFFF, сравнивается весь объектB4, включая сохранность74. Полный parser командной строки не эмулировался; связь -SPEC→565CF0 подтверждена assembly.

Следовательно, нельзя считать запуск с `-SPEC4` эквивалентным установке Machine Spec Level в4. Полный механизм загрузки реестра и автоматического определения производительности не входил в эти проверки.
