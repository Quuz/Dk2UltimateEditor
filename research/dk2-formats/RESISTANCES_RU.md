# Сопротивления Creature: читаются, но не применяются в проверенном ближнем бою

Актуализация этапа125: для четырёх типов резистов первичный Editor подтверждает категории0–15, а не прежний справочник конкретных заклинаний. Новый enum `Creature.ResistanceCategory` применён только к этим четырём полям обеих Creature-размерностей. Тип1 этой melee-проверки остаётся Melee Blade. Для Shot категории4–15 совпадают с резистами;9новых повторных цепочек проверили совпавшие8/6. Значения16/30/32 в источниках неизвестны и сохраняются. См. `COMBAT_CATEGORIES_RU.md`.

Этап113, 29 октября2026. Только предоставленный `DKII-DX.exe`, SHA-256 `d7a8b854e4e4f02709eba271bead6fe2307dd6e332b5a96e70857e5b0e19fb8a`.

**Игра способна прочитать таблицу резистов. В проверенной полной ветке ближнего боя таблица не используется.** Это различие установлено выполнением оригинального кода, а не только отсутствием ссылок в Ghidra. Для всех заклинаний и других версий общий вывод ещё не доказан.

Схема — `creature-resistance-semantics.json`, компонент `creature_resistance_semantics`. API физической правки — `native_creature_resistance.py`.

## Проверка реального удара

Получатель — CreatureVampire ID8, исходный HP1000. Его полное определение загружено из исходной записи с изменением только четырёх пар резистов. Атакующий и сцена подготовлены из прежнего нативного снимка. У атакующего явно выбран тип1 в definition77A; его связь rawF50→mid1340→definition77A подтверждается исходным загрузчиком. У всех четырёх сопротивлений тоже тип1.

После загрузки в **той же памяти одного CPU** запускается целая498E30, затем настоящий обработчикHP4B2CE0. Базовый удар20, атакующий и получатель без вселения.

| Значение каждого из4совпадающих резистов | Загруженные значения | Итоговый HP | Урон |
|---:|---|---:|---:|
|0|0/0/0/0|980|20|

255 — диагностический u8, не рекомендация диапазона GUI или процента. Наличие поляValue само по себе не доказывает формулу «100−Value процентов».

Наблюдатель памяти показал8 чтений счётчика78A только в самом загрузчике4936B4/4936C8. После загрузки ни пары61C..623, ни счётчик78A в выбранном боевом пути не читаются. Настоящая записьHP в4B2F03 одна,значение980. Тип атаки совпадает с типом резиста, поэтому простое несовпадениеID этот результат не объясняет.

Полный исходный вывод варианта0 измерен как базовый образ. Для100/255 предсказаны изменения только соответствующих байтов raw,intermediate иdefinition; остальные подготовленные области совпали целиком. Это парное сравнение не объявляется независимой расшифровкой всех2199байт определения. HP,таблица,count,совпадение типа и исполненные функции проверены отдельно. Два сценария0/100 также полностью совпали в независимом эмулятореGhidra.

## Поиск потребителя

Линейный проход исполняемых секций сохранил20 прямых операндов для61C..623/78A и точных immediate61C/61D/78A. Все адреса сверены с каноническими функциямиGhidra:

- НастоящиеCreature-ссылки — создание,загрузка,копирование определения,деструктор и exception-unwind очистка массива.
- Остальные совпадения — менеджер ресурсов/путей,MovieRenderer и заполнение видеобуфера с такими же численными смещениями.
- Прямого игрового применения резистов к урону среди этих20кандидатов не найдено.

Это ограниченный поиск: смещённые/индексированные указатели,динамические копии,другиеDLL/EXE и всеspell-ветки не исчерпаны. Поэтому общий вывод «резисты абсолютно нигде ни в одной версии не работают» не делается.

**Рабочая интерпретация:** загрузка реализована, а применение таблицы выглядит неподключённым или оставленным в незавершённой механике. Для проверенного melee-пути отсутствие эффекта подтверждено; чтобы эти поля начали менять такой урон, одного изменения значений KWD недостаточно — нужен потребитель в коде.

Отдельная невосприимчивость к молнии через CreatureFlags2 raw1545/mask1 — другая проверенная ветка,см.`KING_LIGHTNING_RU.md`. Её нельзя отождествлять с этой таблицей.
