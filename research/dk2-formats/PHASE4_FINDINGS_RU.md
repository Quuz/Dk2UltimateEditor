# Продолжение исследования: 22 октября 2026

Следующий проход описан в `EFFECTS_RUNTIME_RU.md`: суммарное число скалярных путей увеличилось с 242 до 266, число компонентов пакета — с 13 до 14. Числа ниже описывают результаты этого этапа, последующие уточнения имеют приоритет.

## Вложенные поля Creatures

`CREATURE_SUBRECORDS.md` / `creature-subrecords.json` сопоставляют 48 игровых слотов ресурсов с raw-смещениями и парами FootstepFrames. WALK — слот 1, ресурс по +0x74 и пара кадров по +0x1327. Слот 0 переносится в intermediate, но не загружается обычным циклом ресурсов runtime. Номер enum OpenKeeper нельзя прямо использовать как номер игрового слота.

В Creatures ровно три физических записи заклинаний по 24 байта с raw +0xDC4. Поля: XYZ i32 по +0/+4/+8, неизвестный +0xC, PlayAnimation +0xD, неизвестные +0xE/+0xF, ShotDelay u32 +0x10, неизвестные +0x14/+0x15, ID +0x16, уровень +0x17. Loader уплотняет существующие заклинания в записи runtime по 19 байт. Добавление четвёртой записи изменением общего N не поддерживается этим форматом.

Игровой ShotDelay вычисляется как `(uint32(rawDelay * ticksPerSecond)) >> 12`: промежуточное произведение ограничено 32 битами; это отдельно проверено по assembly. Байты +0xE/+0xF/+0x14/+0x15 не читаются просмотренным converter; +0xC читается converter и редактором Pro, но не передаётся в просмотренный runtime loader. Все байты сохраняются при сборке.

## Нулевое число записей

Для всех 11 каталогов assembly подтверждает DIV на N до проверки N в ветке активного record callback. Нулевой каталог может быть формально корректным, но такой путь загрузки игры делит на ноль. При отсутствии callback отдельная ветка пропускает данные. Адреса инструкций и оговорки: `CATALOGUE_LOADER_LIMITS.md` / `catalogue-loader-constraints.json`.

В исследовательский codec добавлена диагностика всех 11 семейств; для Creatures сохранён прежний код `zero_creature_count`, для остальных — `zero_catalogue_count`. Чтение/сборка контейнера и диагностика совместимости остаются отдельными операциями. Фиктивные записи автоматически не вставляются.

## Пути хранения и источники

`scalar-storage-paths.json` связывает 242 буквальных скалярных переноса raw → intermediate → runtime для девяти семейств. У каждой связи сохранены выражения и строки декомпиляции. Извлекатель ограничен явными присваиваниями; циклы, вызовы getter и условные пути не превращаются автоматически в заявления об использовании.

У Creatures +0xF55 подтверждён путь intermediate +0x1345 → runtime +0x6EB. Раннее указание +0x788 исправлено; +0x788 — счётчик attraction entries. Смысл потребления +0x6EB ещё не установлен.

OpenKeeper дополнительно проверен за пределами парсера: `OPENKEEPER_AUDIT_RU.md` содержит полезные потребители, ограничения реализации и новые подсказки по Effects. 21 путь Effects добавлен после чтения native loader `0x4358C0`. Перенос поля в структуру не означает подтверждения каждой формулы его дальнейшего использования.

## Материалы и проверка

Новые представления записей вошли в JSON-дампы, единый пакет схем содержит 13 компонентов. Повторная проверка 22 октября: 17 основных файлов / 38 секций и 733 файла карт восстановлены из JSON побайтово; входные SHA-256 не изменились. Четыре ранее найденных противоречивых Variables по-прежнему отвергаются строгим чтением. Точные результаты лежат в `validation.json` и `corpus-validation.json`; ограничения перечислены в INTEGRATION_RU.md. Это проверка структуры и сохранения байтов, без запуска новых карт в игре.

Для продолжения Ghidra-анализ восстановлен в отдельной копии проекта `headless-project/DriverResearch.gpr`. `start_research_headless.ps1` запускает сервер только на 127.0.0.1:8089 и направляет настройки/кеш в папку исследования. Исходный Ghidra-проект и исполняемые файлы игры не патчатся. Объект анализа редактора — именно предоставленный `DK2 Editor pro.exe`; его происхождение как неизменённого официального редактора Bullfrog отдельно не установлено.
