## Неизвестное Terrain+0x224 имеет масштаб в редакторе

Converter редактора `0x42ED90` переносит четыре байта raw+`0x224` в intermediate+`0x2DC`. Callback `0x49F5E0` при наличии поля переводит это значение в double модели по +`0x320` с коэффициентом по адресу `0x50AC48`. Значение коэффициента в PE — точно `1/4096`.

Writer `0x4A7690`: инструкция `0x4A7919` загружает double по +`0x320`, `0x4A791F` умножает на константу по `0x50AC58` (=4096), затем вызывает преобразование в целое и пишет DWORD в запись. Значит, исходные четыре байта — целое значение с масштабом в модели редактора, а не IEEE float в файле. В ваших самостоятельных Terrain значение4628 представляется как1.1298828125.

Игровой loader переносит тот же raw DWORD в runtime+`0x1B5` без этого преобразования. Назначение поля и его связь с конкретным видимым контролом пока не установлены. Нельзя называть его яркостью, размером, таймером или навязывать масштаб `/4096` всем игровым потребителям только по поведению редактора. Исходное имя Unk224 сохраняется.

## Traps+0x204: два байта составляют одно слово

Подтверждённая цепочка редактора:

```text
raw+0x204 (2 bytes)
  → converter 0x431530, intermediate+0x2AC
  → callback 0x4A1770, editor model+0x238
  → writer 0x4A8F40, двухбайтовый слот записи
```

В assembly callback: `0x4A1926` читает WORD из intermediate+`0x2AC`, `0x4A192D` пишет WORD модели+`0x238`. В writer сохранённое выражение `uStack_60 = (undefined2)piVar1[0x8e]` читает тот же model+`0x238`. Это дополняет игровую цепочку в runtime+`0x98`.

В ресурсе диалога326 действительно присутствует подпись `Mana Gen.`. Но это скрытый статический текст с ID−1, без доказанного соответствующего редактора значения. Она не устанавливает назначение raw+`0x204`. Раннее предположение о её связи с другим редактируемым полем снято после проверки ID.

Отдельная проверенная цепочка `Research Time`:

```text
raw+0x1E8 → intermediate+0x290 → editor model+0x158
  → dialog+0x64 → control12984 (0x32B8)
```

В ресурсе это именно `Research Time`, также скрытый в шаблоне. Нельзя перепутать model+`0x158` с model+`0x238` или считать, что любая скрытая подпись поблизости относится к неизвестному слову.

Диапазоны таблиц — ограничения GUI исследованного редактора. Они не являются доказанными пределами формата или движка. Собственный редактор может сохранять полные значения поля, одновременно показывая предупреждение о том, что исходный GUI их не принимает.

## Require Mana может изменить стоимость при применении свойств

`0x471E00` проверяет dialog+`0x120`, связанный DDX с контролом1798 `Require Mana`. При нуле присваивает model+`0x23C` ноль; иначе переносит dialog+`0x84`. Getter флагов `0x426000` связывает соответствующий model+`0x2BC` с битом`0x100` файловых Flags по raw+`0x1EC`.

Таким образом, успешное применение свойств в предоставленном редакторе может обнулить ManaCostToFire при снятом Require Mana, даже если само числовое поле не меняли. Это отдельное поведение GUI; исследовательский codec не должен повторять его неявно при побайтовой пересборке.

`native_editor_views.trap_commit_projection(record)` только показывает это присваивание без изменения байтов. Это не эмуляция полного сохранения: другие поля могут помешать прохождению валидации диалога. В трёх просмотренных наборах нет текущих записей, для которых эта ветка меняла бы ненулевую стоимость.

## Что сохранять разработчику

Для Unknown Terrain+`0x198` установлен также путь в model+`0x3D0`; для Objects+`0x34C` — в model+`0x3BE`. Назначение обоих остаётся неизвестным. Не удалять их и не отождествлять по похожим смещениям в структурах разных классов.

`editor_views(record,family)` возвращает исходное unsigned значение, числовое представление редактора, control ID и статус диапазона ввода. Оно не заменяет основной raw record и не используется как автоматическая команда записи.

Проверено19 граничных случаев: signed16, условное обнуление стоимости, точное масштабирование DWORD и отличие двух путей Traps. Дополнительно171 запись — по57 Terrain/Traps в самостоятельных каталогах и двух Globals — проверена в трёх отдельных областях. Оригинальные файлы не менялись. Игра и редактор с изменёнными файлами не запускались.

Новые MCP-запросы декомпиляции в конце прохода не выполнились: автоматическая проверка разрешений сообщила исчерпание лимита аккаунта. Четыре таких ответа сохранены с суффиксом`-unavailable.txt` и не включены в доказательства. Разбор Lean по контролам и неизвестных ресурсов Objects/Rooms остался продолжением для новых запросов Ghidra после восстановления доступа.
