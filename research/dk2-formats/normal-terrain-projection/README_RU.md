## Наблюдено в исполнении

1. Ещё30 подготовленных цепочек raw Terrain→оригинальный loader→World/CMap→5A3590, теперь с global759AE8=1. Выход — те же20 точек, но уровни Z=-2.5+iz/2, iz0..4. Выбранное слово «полная высота» описывает эту сетку; название игрового переключателя и естественное значение global в живой игре не установлены. Сдвиги Lean/Wibble и базовая волна сохраняются. Входные raw/map/nav не меняются, код и vtable защищены, внутренних подстановок0. Файл full-height-cases.json.

2. Четыре цепочки с двумя настоящими загруженными определениями Terrain8/9. В клетках ID чередуются шахматно, деформационные величины второй записи вдвое меньше. Проверены LeanH/V128 против64 и WibbleH/V128 против64 на изолированной и шахматной заполненности. Это исполнение минимума соседних параметров в59E480/59E3A0/59E400, а не перенос только статического чтения. Все80 выходных точек совпали с C#-реализацией точно. Проверки сохранности включают обе исходные записи Terrain. Файл mixed-height-cases.json.

3. Оригинальные58EE60 и58F030 исполнены на подготовленном массиве16 сеток.58EE60 строит таблицу выбора четырёх сеток и внутренних индексов.58F030 интерполирует восемь точек по X/Y/Z. Клетки таблицы имеют шаг0.5; для Z используется исходное начало-2.5. За проверяемой областью функция возвращает исходную вершину. Этот тест не исполняет bootstrap/KMF-loader и не доказывает естественную расстановку сеток всей карты.

Взяты15 координат из штатного ROCK WALL и24 из Rock Corner. Каждый набор повёрнут на0/90/180/270° и перенесён в заданные координаты стенда; добавлены шесть дробных/граничных контрольных вершин. Две топологии ×три набора параметров ×162 позиции =972 результата. Это координаты реальных KMF в подготовленном transform, а не полный вызов создания модели. Сетки для этого отдельного теста поданы независимой ранее проверенной Python-моделью; не выдаются за полученные в той же непрерывной CPU-цепочке. Файлы wall-positions.json и vertex-interpolation.json.

## Реализация и проверки редактора

В Dk2TerrainDeformation используется общая сетка в координатах половины клетки. Параметры узла берутся как минимумы соседних определений, Lean зависит от заполненности, Wibble получает детерминированный seed половинных координат и слоя. Поэтому соседние модели запрашивают один и тот же узел. В предпросмотре Z направлен вверх и пол равен0; преобразование к renderer-Z: -1-previewZ. Выбран режим полной высоты, сохраняющий прежнюю высоту стен редактора. Прежний «низкий» режим не добавлен в пользовательский интерфейс.

C# совпал по600 точкам нового полного режима и80 точкам смешанных определений побайтово; прежние600 точек низкого режима также совпадают. На972 интерполированных позициях максимальное пространственное расхождение5.3330314e-7 клетки при допуске2e-6. Здесь допускаются float32/x87-погрешности промежуточного интерполирования, побайтовое совпадение этих972 позиций не заявляется.

В UltimateEditor подключены рельеф, статические модели, анимации и привязка пламени. Поворот исходных нормалей сохранён; обычный KMF-потребитель57AD20 статически показывает отдельное преобразование нормалей после58F030, без их пересчёта по новой геометрии. Это статическое наблюдение данного потребителя, не проверка всех путей нормалей игры. Повторяющиеся индексы KMF-позиций проецируются один раз на позу, чтобы не считать UV/normal-швы повторно.

Изолированный WindowsSmoke проверил реальную общую границу двух соседних стен, изменение деформации после Paint, точное восстановление всех зарегистрированных координат после Undo, стабильность при перестроении камерой, освобождение кэша и побайтовую сохранность карты. Также прошли GROP, двери/blueprint, комнаты, прозрачность решёток, выбор через отверстия, HeroFloor и анимация. Это тесты предпросмотра, не кадр игры.

На том же level1 после оптимизации повторных проекций: загрузка3.65с, managed93.35MiB после диагностического GC, private828.98MiB, working set872.50MiB. Обновление анимации в пяти пробах40.12мс в среднем/44.57мс максимум; это CPU-обновление, не полный GPU-кадр. Принудительный GC остаётся только в стенде. По времени есть накладные расходы относительно варианта без деформации.

## Воспроизведение

В исследовательском окружении предыдущего дополнения:

```powershell
python emulate_full_height.py --research-root D:/Games/DK2/Tools/dk2-format-research --output <новая временная папка>
python emulate_mixed.py --research-root D:/Games/DK2/Tools/dk2-format-research --output <другая временная папка>
python emulate_interpolation.py --research-root D:/Games/DK2/Tools/dk2-format-research --exe <DKII-DX.exe> --output <третья временная папка>
```

Сохраняются прежние требования к Python3.12/Unicorn2.1.4, импортам старого стенда, его расположению каталогов игры и точному EXE. Full/mixed используют backend из normal-terrain-grid; его отличие — только host timeout. Модель normal_terrain_model.py импортируется как библиотека интерполяционным стендом. Её старый самостоятельный main с локальными путями не является переносимой командой этого дополнения.

В WindowsSmoke доступны --terrain-deformation-core (для каждого файла сеток), --terrain-interpolation-core и --terrain-deformation-scene. audit.py проверяет целостность сохранённого пакета/счётчики и, с --exe, полные первичные диапазоны58EE60 и58F030. Он не заменяет native-перезапуск или WindowsSmoke.

## Открытые границы

Живой игровой кадр, естественные runtime-флаги2000h/8000h после KLD-loader, динамическая занятость объектами, глобальные fallback-Wibble, все края мира, иные переключатели высоты и все версии EXE не закрыты. Предпросмотр определяет статическую заполненность по уже проверенным флагам сплошности Terrain и не симулирует объекты навигации. При выходе за карту он использует консервативную заполненность и нулевые параметры.

Остаётся отдельная задача о пространстве расчёта освещения: нынешний предпросмотр вычисляет свет по отображаемым деформированным позициям; потребитель57B0E0 статически использует исходные позиции для57BF00. Полное игровое ambient/мерцание/динамическое освещение не заявляется. Включение деформации не делает остальные комнаты, состояние кампании или ориентацию предметов полностью совпадающими с игрой.
