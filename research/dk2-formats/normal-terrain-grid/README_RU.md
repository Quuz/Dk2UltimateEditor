# Деформация обычного рельефа: контрольная сетка из 20 точек

14 ноября 2026. Отдельное дополнение к `TERRAIN_LEAN_RU.md` и `PROCEDURAL_CURSOR_RU.md`. Профиль: DKII-DX.exe, SHA-256 `d7a8b854e4e4f02709eba271bead6fe2307dd6e332b5a96e70857e5b0e19fb8a`. Существующие физические схемы, неизвестные поля и замороженный пакет форматов не меняются.

## Исполнено

На подготовленных Raw Terrain и World/CMap выполнены оригинальные constructor `4F6570`, initializer `56EB60`, converter `56ED20`, loader `4F66E0`, затем путь обычного рельефа `5A3590`. Деформация включена полем GFX+C5; особый глобальный режим `75AD4B == 5` не выбран. Навигационная карта и runtime-флаг клетки `2000h` заданы явно. Это не полный bootstrap карты из KLD.

Путь использует `5A3220` для сетки, `59ECF0` для заполненности через настоящие методы World/CMap, `59E480` для производных samples, `5A37F0` для Lean и `59E750` для Wibble. Остановка по `5A37D1`, до вызова `575FA0`: снят буфер из240 байт, который далее передаётся в загрузку геометрической сетки. Аллокация/загрузка этой сетки, деформация вершин KMF и GPU здесь не исполнялись.

Это отдельный путь от исследованного ранее процедурного Cursor: обычный рельеф передаёт сетку2×2×5, Cursor использует3×3×3. Перенос результата Cursor прямо на вершины стены без проверки отображения координат этим исследованием не обосновывается.

## Независимая модель и результаты

Для каждой из шести топологий выполнены zero, H128, V128, H128+V128 и WibbleH128+WibbleV128: всего30 native-результатов. Проверены свободная область, занятая восточная половина, занятая половина Y>=4, отдельная клетка, угол и шахматная сетка. Во всех клетках одинаковые определения Terrain; не смешанные материалы.

`model.py` независимо строит выход по входным параметрам и ранее проверенной проекции Lean из `native_terrain_lean.py`. Совпали600 точек /7200 байт, включая все float32. Модель не берёт ожидаемые координаты из native-выхода. Входные Raw Terrain, карта и navigation bitmap сохранились; записи в исходный код/vtable запрещены раннером, внутренних подстановок0. EXE не запускается средствами Windows.

В обычном height-режиме координаты исходной сетки:

```text
X = x + ix/2, Y = y + iy/2, Z = -1.75 + iz/4
ix,iy = 0..1; iz = 0..4
порядок в буфере: ix, затем iy, затем iz
```

Это система координат renderer с Z вниз. Для iz1..3 используются соответствующие слои0..2 производных samples; крайние iz0/4 в проверенных сценах сохраняют исходные координаты. Для четырёх углов берутся позиции0/1/3/4 из27-точечного промежуточного буфера. Базовая волна первого деформируемого слоя: float32(-0.15 -0.125×sin((2x+ix+2y+iy)/2)). Её временная анимация здесь не установлена.

Wibble использует оригинальный `5558D0`: seed = seed×1664525 +1013904223 с переполнением uint32; результат ROR(seed,13) modulo range. Для данной сетки seed до трёх выборок равен2x+ix+65536×(2y+iy)+16×layer; вызовы идут Z,Y,X. При нулевом диапазоне вызов пропускается. В дополнение к случайным смещениям `59E750` даёт горизонтальный сдвиг по заполненности; независимая модель учитывает и его. Это не временной PRNG игры и не утверждение о каждом другом потребителе `5558D0`.

Физические поля остаются прежними: WibbleH/V raw+1CE/+1D2, LeanH[3] raw+1CF..1D1, LeanV[3] raw+1D3..1D5. Диапазоны Wibble = BYTE<<7; Lean = BYTE/512. Формат хранения не меняется, новых writer-проверок это дополнение не заявляет.

## Воспроизведение

Сверка сохранённых результатов без исполнения игры:

```powershell
python model.py --research-root <папка существующих скриптов dk2-formats> --cases cases.json
```

Повторение native-исполнения:

```powershell
python emulate.py --research-root D:/Games/DK2/Tools/dk2-format-research --output <новая временная папка>
python model.py --research-root D:/Games/DK2/Tools/dk2-format-research --cases <новая временная папка>/normal-terrain-cases.json
```

Требуются Python3.12, Unicorn2.1.4 и зависимости прежнего исследовательского стенда, включая MCP Python package для его импортов. Подготовка Raw Terrain наследует пути `emulate_cursor_procedure.py`: каталог `Dungeon Keeper 2/Data/editor` должен находиться относительно research-root так, как ожидает этот скрипт. Команды проверены с приведённым расположением на текущей машине; автономный перенос всего старого стенда на произвольную структуру каталогов не проверен. SHA исходных helper-файлов — в manifest.json.

Копия `terrain_native_trace.py` отличается от прежнего `native_unicorn_factorytrace.py` только пределом host timeout30с вместо5с. Это не замена эмулируемых инструкций. Два предварительных диагностических запуска остановились по временному лимиту; они не входят в принятые30 результатов. Кэш результатов имеет digest входных аргументов. В принятом запуске все вызовы дошли до заданной остановки, входы сохранились, исключений нет.

## Открыто

Не проверены смешанные определения Terrain, края мира, другие height-режимы, естественные runtime-флаги после полного KLD-loader, интерполяция этой сетки в KMF-вершины, нормали, швы между клетками и конечный кадр DKII-DX. Применение деформации к 3D-предпросмотру UltimateEditor ещё не включено. Контрольные результаты не объявляются визуальной сверкой игры и не закрывают остальные неизвестные семейства форматов.
