# Terrain → навигационная карта → шаг существа

Этап99, предоставленный DKII-DX.exe SHA-256 `d7a8b854e4e4f02709eba271bead6fe2307dd6e332b5a96e70857e5b0e19fb8a`.

**Подтверждена полная связь флагов Terrain с навигационной категорией и проверенным шагом существа.** В20 native-сценариях настоящие функции построили кэш определений, разместили ландшафт и записали навигационный байт. Затем оригинальный callback прочитал этот байт при выполнении4D5A40/4D4760. Восемь сценариев дополнительно начинаются с сырой552-байтовой записи Terrain и настоящего загрузчика.

Схема — `navigation-map-semantics.json`, компонент `navigation_map_semantics`. Новое API — `native_navigation_map.py`.

## Физическое поле и приоритет

```text
Terrain raw DWORD+190
 → converter56ED20: intermediate DWORD+248, presence DWORD+B0
 → loader4F66E0: definition DWORD+17B
 → CMap44FC40: выбор одного навигационного байта
```

Все смещения raw относятся к началу записи Terrain, не всего KWD. В поле сохраняются полные32 бита.

| Условие, проверяется сверху вниз | Навигационный байт |
|---|---:|
| flags & 1, базовое имя SOLID | 8, блокировка |
| Иначе flags & 80h, WATER | 1 |
| Иначе flags & 100h, LAVA | 3 |
| Иначе | 0 |

Это присваивание **всего байта**, а не OR с прежним значением. Комбинация180h выбирает1: вода имеет приоритет над лавой. Комбинации81h/181h выбирают8: блокировка имеет приоритет над жидкостями. Установка только флага Creature «ходить по лаве» не разрешает проверенный шаг на Terrain180h.

Не следует переносить эту таблицу на raw byte2 AutoSaveMap.kld: это отдельные поля и структуры. У мостов, дверей и изменений карты есть дополнительные пути; весь жизненный цикл навигационного байта этим правилом не исчерпывается.

## Какие функции действительно выполнялись

455D40 строит кэш через настоящие World vslot60/74/70:50CEB0,508DF0,508DD0. Использована исходная World vtable, а не таблица адаптеров. Выделенный стендом массив имеет8 слотов и два определения с ID1/7; исходное перечисление выбирает их, затем кэш используется размещением клетки. Это искусственные определения стенда; ID1 здесь задан как обычная поверхность, хотя в текущем исходном Terrain ID1 — Impenetrable Rock.

44FC40 выполнена целиком с `this=World+9DA`, координатами6,6, TerrainId7, владельцем0 и двумя нулевыми дополнительными флагами. Настоящая50CF80 проверяет наличие ID.455B90 меняет TerrainId клетки,4559D0 обрабатывает владельца. WORD+6 клетки получает3456h из definition+1AB; очищаются низкие12 бит roomWORD+2 и bytes4/5. CMapDWORD+1C (World+9F6) получает Session tick100. Эти изменения входят в сравнение всего подготовленного мира и карты.

У WorldBYTE+7239 явно установлен40h: оригинальная функция выбирает4D1970, которая записывает байт без пересборки графа. Другой режим выбирает4D1930→4CE770. Их исходные тела сохранены и проверены, но **пересборка графа не выполнялась**. Loading-mode — условие стенда, а не новая рекомендация менять этот флаг в живой игре.

После размещения выполняется существующая цепочка скорости и шага с настоящими callbacks. Для воды дополнительно вызывается48EBF0, которая обновляет разрешение категории1 из definition686/10. Разрешение категории3 оболочка движения получает из definition686/20.

## Результаты

Начальная XY `(22528,26624)`, запрошенная скорость4096 поX. База1000 и possession-процент200 дают ограниченную скорость3000. Целевая клетка получает Terrain через оригинальный44FC40.

| Terrain | Разрешение Creature | Итоговый X |
|---|---|---:|
| Обычный, flags0 | Нет жидкостных разрешений | 25528 |
| WATER80h | Без water-флага | 22528, шаг остановлен |
| WATER80h | С water-флагом | 25528 |
| LAVA100h | Без lava-флага | 22528 |
| LAVA100h | С lava-флагом | 25528 |

Восемь raw-композиций проверяют ground,solid,water blocked/allowed,lava blocked/allowed,180h и181h. Выполняются настоящие initializer56EB60,converter56ED20 и полный loader4F66E0; все552raw/736intermediate/460definition и защитные байты сравниваются. Это минимальные исследовательские записи с нулевыми ресурсами и gate1, который исключает checksum/audio/graphics-ветки. Они не объявляются неизменёнными ресурсами текущей карты.

Новые сценарии проверяют результат контроллера XY/скорости; применение XY к самому экземпляру в этом этапе не добавлялось. Четыре ранее подтверждённых actor/map-application случая этапа98 остаются отдельным доказательством.

## Редактирование и сохранение

```python
from native_navigation_map import patch_terrain_navigation_flags
changed = patch_terrain_navigation_flags(raw_terrain, 0x80, True)
```

API принимает известные размеры548/552 байта и только явную маску из набора181h. Меняет выбранные биты DWORD190, сохраняя остальные. На82 исходных Terrain-контейнерах/3306 записях выполнены19836 полных точечных пересборок: включение/выключение каждого из трёх битов на каждой записи. Остальные31 бит, байты, заголовки, длина, секции и порядок сохранены; результат повторно разобран. Исходные файлы не перезаписывались.

Текущие Water4/Lava5 и примеры других Terrain экспортированы со значениями флагов и SHA в `current_source` схемы. Это данные данной установки, не универсальная таблица ID для других версий.

## Границы подтверждения

20 успешных композиций, восемь полных raw-loader путей;217 полных диапазонов функций и13 исходных блоков данных сверены с PE. Число диапазонов включает прежние и статические зависимости и не означает исполнения каждой ветки. Сравниваются все32768 байт подготовленного World, карта32×32×16, актёры, таблица определений, кэш1024 и остальные подготовленные буферы. Новых полных образов существа не объявляется.

Ни одна игровая функция, vtable или исходный collision-pointer не подменялись. Остаётся конечный пустой массив сил, нейтральное управление и unowned/no-room карта. Реальные силы, A*, физика, графика, нормальная пересборка графа, карты с комнатами/мостами/дверями, жидкостный урон и полный rawKLD→world запуск не проверены этой композицией.

Две диагностические ошибки измерительного стенда исправлены: сохранение callbackEAX между вызовами и ожидаемая запись tick100 вWorld9F6. Старые результаты сохранены и исключены из20 принятых. Ошибка определения функции по предположенному внутреннему адресу5090B0 также сохранена; использован настоящий вход5090C0 из World vtable. Это не ошибки игры или редактора.

Priority/Jump, Terrain198/224, Traps204, Objects34C, Doors236, scalar98/113/114 и остальные существенные неизвестные остаются открыты. Пакет78 компонентов; прежние77 схем сохранены побайтово. Четыре исходных EXE и игровые данные не изменены.

Воспроизведение: `prepare_navigation_map_primary.py`, `ghidra_probe.py phase99-primary-queries.json`, `emulate_navigation_map.py`, `build_navigation_map.py`, `build_format_package.py`, `audit_navigation_map.py`. Принятые native-результаты повторно не исполнялись при сборке и аудите; точные входы, ожидаемые буферы и SHA проверены из кеша.
