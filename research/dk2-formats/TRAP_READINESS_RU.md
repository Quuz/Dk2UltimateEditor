## Результат функции

Все смещения hex, размеры и число сценариев десятичные. Проверка возвращает числовые коды в следующем порядке:

Полное назначение кодов3/4 и WORD115 этим этапом не переименовывается. Это функция допуска внутри более длинного алгоритма; возврат3/4 не объявляется гарантией выстрела.

ManaCostToFire переносится из rawDWORD1D4 в definition9A, Flags — из rawDWORD1EC в definition88. Настоящий mana helper4C1740/4B79F0 допускает нулевую стоимость независимо от запаса; остальные стоимости сравниваются как signed32. Например, FFFFFFFF рассматривается как−1 и при запасе0 проходит. Проверены равенство стоимости запасу, превышение, INT_MIN, отрицательный запас, выключенный бит100 и исключённый owner. Приём таких значений через GUI, последующее списание маны и последствия выстрела не проверялись.

Deadline сравнивается как unsigned32: FFFFFFFF при tick0 даёт код0, deadline0 при tickFFFFFFFF проходит эту проверку. Это локальное правило сравнения, не исправление переполнения игрового времени.

Неизвестное WORD Traps204, которое загрузчик переносит в definition98, проверено при значениях0000/0001/8000/FFFF: код данной функции одинаков. Его общее игровое назначение остаётся открытым. Соседний DWORD9A физически не является этим WORD98.

## Две зацепки Doors236 относятся к CTrap

Native RTTI связывает vtable66D754, locator67D760 и type descriptor69F130 с именем `.?AVCTrap@@`.

- Slot14 содержит4A84E0. Функция сохраняет this в EDI по4A84FE; перед вызовом4A7D10 выполняет `MOV ECX,EDI` по4A8C3B. В самой проверке чтение4A7D58 получает DWORD9A из definition экземпляра ловушки. Это подтверждённый путь CTrap, а не доказательство назначения DoorWORD99.
- Slot4C содержит4A9B70. Функция сохраняет this в ESI по4A9B8C; чтения4A9C8C/4A9C99 получают definition из ESI+F7 и DWORD9A для диагностического вывода. Оно тоже принадлежит CTrap.

Из семи текущих DX-кандидатов поиска по пересечению смещений здесь типизированы только эти два. Остальные пять и семь старых кандидатов сохраняют отдельные требования проверки типа. Присутствие кода внутри метода CTrap не делает любой локальный указатель указателем this: например,4A8E70 получает ESI из выходного параметра обхода группы. Такой указатель требует собственного доказательства происхождения. Проверка остальных кандидатов не объявлена исчерпанной.
