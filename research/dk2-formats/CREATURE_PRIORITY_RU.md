## Физическое поле и разные структуры

| Слой | Pick-Up Priority | Отдельное SpellSwipe |
|---|---:|---:|
| Сырая запись Creatures | +0xF55, u8 | +0xF45, u8 |
| Промежуточная структура игры | +0x1345 | +0x1335 |
| Промежуточная структура редактора | +0x1355 | +0x1345 |
| Runtime definition игры | +0x6EB | +0x684 |
| Модель редактора | +0x16AE | +0x16B6 |

Совпадение числа+0x1345 в разных процессах не означает совпадение поля. Первоначальный поисковый след через SpellSwipe не доказывает назначения+0xF55. Итоговая схема явно разделяет две структуры. Игровой потребитель SpellSwipe в0x4100F0 читает+0x684 и передаёт swipe в0x5075A0; к Pick-Up Priority этот найденный потребитель не относится.

Raw+0xF55 присутствует в обоих известных вариантах записи —5449 и5537 байт. Game converter0x568E30 переносит байт в+0x1345 с presence+0x1E8; loader0x492320 — в runtime+0x6EB. Editor converter0x4287C0 переносит тот же raw-байт в+0x1355; callback0x4A01B0 — в модель+0x16AE.

## Подпись, панель и сохранение

Из Win32 STRINGTABLE самого EXE извлечён ресурс **0xF855 → Pick-Up Priority**. В `editor-strings.json` сохранены436 строк с resource path, физическим смещением текста, RVA и SHA-256 текста/блока. В схему встроено доказательство именно этой подписи.

Fill0x43F2A0 копирует model+0x16AE в panel+0x17EE. Property-extract0x4405E0 в ветке0xF855 преобразует **unsigned byte** panel+0x17EE в double. Property-update0x43FD60 вызывает `__ftol` и сохраняет младший байт результата обратно в panel+0x17EE. Commit0x441160 возвращает байт в model+0x16AE.

Writer0x4A7F00 копирует model+0x16AE в буфер записи: ESP+0xFE9 относительно начала ESP+0x94 даёт **raw+0xF55**. Передаваемая писателю длина0x15A1 соответствует5537 байтам. Физическая ширина не расширяется до DWORD из-за double-представления в панели.

Диапазон хранения —0..255. Отдельный допустимый диапазон native-GUI не установлен; ограничение нельзя придумывать по встреченным значениям. Проекция `commit_converted_integer` в `native_creature_priority.py` показывает только сужение **уже полученного** signed64-целого, без имитации диапазонов float/`__ftol`.
