## Исполненная цепочка

Для каждой исходной записи выполняется настоящий converter `42DF90`, затем целый callback `49FC30`. После26callback целиком выполняется writer `4A7AC0` с исходным catalogue context `54F550`, который читает именно этот массив. Указатели моделей и регистрация не подставляются из Python. Вектор действительно растёт: count26, capacity29; в данной подготовке выполнено47обращений HeapAlloc, выделено40304байта. Внутренние MFC/CRT malloc, пулы строк, копирование и флаги выполняются исходными инструкциями.

Сравниваются все1055байт каждой выходной записи, все11ресурсных блоков каждой модели, полные снимки моделей до/после writer, исходные записи, guard-зоны, размеры и число записей заголовка. ## Неизвестный ресурс1C4

Путь подтверждён исполнением:

  → intermediate+298

  → writer rawRoom+1C4, those same84bytes

Общий setter `41BB90` копирует21DWORD, затем вызывает `41C0B0`. Суффиксный cache не сериализуется вместе с84байтами. Не следует удалять `#число`, нормализовать строку по cache, очищать метаданные при type0 или давать неизвестному Room-слоту имя EditorMapIcon только из-за общего ArtResource-парсера.
