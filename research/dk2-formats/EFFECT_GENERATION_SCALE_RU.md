# Effects: адаптивное число создаваемых элементов

Этап141, 30 октября2026. Подтверждено поведение raw-флага `Effects +0xB4`, маска `0x4000`, в режиме `GenerationType=4` (`CUBE_GEN`). Точный профиль `DKII-DX.exe` закреплён в `effect-generation-scale-semantics.json`. Имя `USE_GENERATION_SCALE` осталось сторонним; теперь установлено настоящее игровое поведение флага, а не native-название.

## Формула

N — BYTE `ElementsPerTurn` raw `+0xF3`, S — глобальный BYTE `69752C`.

После прохождения native-проверки случайности и при положительном времени жизни родителя:

- Ветка **EffectElements**, флаг4000 установлен: `max(N != 0, floor(N × S / 255))` партий.
- Без флага: N партий.
- Ветка **Effects**, выбираемая флагом40, обходит масштабирование. Здесь это подтверждено инструкциями и исполнением с N=0; ненулевое создание дочерних Effects не исполнялось.

| N | S | Партий с флагом |
|---:|---:|---:|
| 6 | 0 | 1 |
| 6 | 50 | 1 |
| 6 | 127 | 2 |
| 6 | 128 | 3 |
| 6 | 254 | 5 |
| 6 | 255 | 6 |
| 0 | 0 | 0 |

S=0 — диагностический вход: настоящий setter ограничивает коэффициент50–255. При N>0 остаётся минимум одна партия, даже когда произведение округляется до нуля.

**Партия не равна одному живому элементу.** Без случайного распределения каждая партия обходит восемь физических GenerateIds и пытается создать каждый ненулевой ID, включая повторения. Native-контроль с тремя ненулевыми слотами и двумя партиями создал шесть зарегистрированных элементов. При случайном распределении выбирается один физический слот; первый слот0 может прервать обработчик до цикла. Сохраняются остальные проверки и возможность отказа создания. Это не частота «в секунду».

## Источник коэффициента

Setter внутри `43B220`, фрагмент `43B28B..43B2C9`, читает DWORD `75CA70`. Точное правило с переполнением32 бит:

`S = clamp(trunc(s32(205 × s32(F)) / 14) + 50, 50, 255)`.

Для обычных неотрицательных F: 0→50, 1→64, 7→152, 13→240, 14→255; при30 тоже255.

Источник F — `575700`: настоящий импорт `timeGetTime` через IAT `66C360`, разность миллисекунд с предыдущим вызовом, замена нулевой разности на1 и signed integer `1000 / delta`. Это позволяет интерпретировать F как оценку частоты кадров, а S — как адаптивную плотность генерации. Точное правило времени относится к интервалу между последовательными вызовами575700; её caller59D760 содержит дополнительные условия. Полный графический цикл и реальный FPS не измерялись; связь с ручной настройкой GUI не доказана.

Девять native-контролей проверяют только оригинальный арифметический фрагмент, включая signed/overflow входы. Остановка перед43B2C9 — **не полный World tick**. Весь setter и источник времени подтверждены статически.

## Файловый путь и доказательства

Effects: raw246 → initializer56AEC0 → converter56AFE0 → constructor4357E0 / loader4358C0 → generator4386F0. Флаги проходят через MID168 в definition5F; количество — через MID1A7 в definition8A. Native initializer пишет до1A9 включительно: измеренный MID занимает426 байт. После исправления первоначальной границы фикстуры424 все64 защитных байта сохраняются. Предварительная фикстура исключена из принятых проверок; это не ошибка игрового файла.

В той же CPU загружается исходная запись EffectElement294; настоящий4352E0→435F20 создаёт детей. Проверяются списки, теги, определения, время жизни, расход arena и свободные ID. Родитель подготовлен, его factory не запускалась.

- 18 полных цепочек загрузки/генерации,44 успешно созданных и зарегистрированных ребёнка.
- 5 независимых Ghidra CPU контролей:170 областей,840620 байт совпали целиком.
- 43 полных диапазона исполнявшихся оригинальных функций,2273 различных PC сверены с Ghidra и PE; арифметический фрагмент учитывается отдельно.
- 82 точные пересборки контейнеров в памяти: изменяются только F3 и бит4000. Остальные байты, включая Misc2/Misc3, F4, заголовки, записи и суффиксы, сохраняются.
- SHA-256 прежних199 источников и7 путей EXE совпадают. Исходные файлы и параллельный редактор не изменены.

Корпус82 контейнеров содержит30207 файловых записей Effects, включая повторения. У5702 записей type4 установлен4000, у21982 — снят. Это не количество уникальных эффектов.

## Применение в редакторе и ограничения

Сохранять N как полный u8, flags как полный u32, править только выбранный бит. Вычисленный S не записывается в KWD. Подсказка может говорить: «масштабировать число партий элементов по производительности; минимум одна при N>0». Формулу нельзя переносить с type4 на другие режимы.

API `native_effect_generation_scale.py`: `cube_batches`, `scale_from_rate_dword`, `patch_generation_count`. Актуальное представление Effects в пакете получает аннотации B4/F3; исторические поля сохранены.

Не исполнены parent factory, ненулевой Effects-target путь, поздняя физика/удаление, полный scheduler, asset decoding/GPU. Применены объявленные внешние providers мира/ресурсного handle и равномерная Q16 таблица, а не настоящие визуальные ресурсы.

Misc2/Misc3 загружаются в definition4B/4D; одна полная пара памяти различается только их копиями raw/MID/definition. Их назначение остаётся неизвестным, глобальная неиспользуемость не доказана. F4 сохраняется без нового назначения. Другие неизвестные15 семейств открыты; оценка всей цели остаётся около75%.

Воспроизведение: `emulate_effect_generation_scale.py`, `crosscheck_effect_generation_scale.py`, `prepare_effect_generation_scale_primary.py` и сохранённые queries, `validate_effect_generation_scale.py`, `build_effect_generation_scale.py`, `build_format_package.py`, `audit_effect_generation_scale.py`.
