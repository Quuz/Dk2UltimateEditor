## Первичный путь редактора

`442940` открывает диалог233 через constructor `463D20`. Его initializer `463DA0` четырежды вызывает `463FF0`, который добавляет `<none>`, затем читает таблицу `512D28` до ID−1. Карта индексов хранит байты0..15. Таблица Shot начинается с `5138D0`; двенадцать её пар `ID/UTF16-pointer` побайтно совпадают с хвостом таблицы резистов. Данные и все общие строки сверены через Ghidra с исходным PE.

`41E440` возвращает пару модели по адресу `model+1594+2*slot`. `41E450` записывает два младших байта при slot<4. Это модель редактора, не raw-offset файла. Raw Creatures E0C..E13 и runtime definition61C..623 подтверждены прежними исходными конвертером/загрузчиком; четыре пары по два байта физически не изменились.

DDX `463F30` связывает combo1766/1769/1772/1775 и значения1767/1770/1773/1776; каждое значение проверяется в диапазоне0..100. Сам диапазон интерфейса ещё не доказывает работающую процентную формулу. Message map `512DA8` связывает кнопку OK12431 с `464310`: после UpdateData выбор типа0 принудительно обнуляет соответствующее значение, затем записываются четыре пары. Эта полная MFC-ветка статически разобрана; живое окно и UpdateData целиком не исполнялись. Отдельные исходные lookup/setter исполнены в CPU.

Не следует глобально заменять все поля, названные старым enum `Creature.AttackType`: исходный построитель другого списка `4356B0` берёт категории1/2/3/15, затем добавляет реальные ID из каталога CreatureSpells. Для текущего исправления строго выделены четыре поля резистов. Имена других полей требуют собственной привязки.

## Значения вне нативного списка

На82предоставленных Creature-контейнерах/3734записях проверены14936слотов. Встречаются типы16/30/32, не представленные этим диалогом. В текущем editor/Creatures.kwd это Salamander:16, Fairy:30/32. Их назначение не установлено. Это не доказательство ошибки конкретного редактора, битовой маски или общей поддержки в движке.

API сохраняет любые u8. Не переименовывайте16 в Invulnerable,30 в Guided Bolt и32 в Monk Heal только из-за прежнего справочника. Изолированные lookup-проверки для18/41/255 возвращают−1; реальное открытие/сохранение окна с каждым исходным неизвестным ID не проверено. Совместимый редактор должен показывать неизвестный raw-ID и сохранять его без нормализации.
