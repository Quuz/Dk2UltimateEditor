# Variables Type77: границы проверенного поведения

14 ноября 2026. Отдельное дополнение к [этапу199](../EDITOR_VARIABLES_WRITER_RU.md).
Замороженный машинный пакет этапа205 и прежние схемы не изменены.

Выполнены семь подготовленных сцен оригинальных Pro writer `4937C0` и счётчика
`48CA00`, включая положительный путь Type77. Координатор повторил конечный аудит
без записи и сравнил весь JSON с сохранённым результатом: совпадение полное.
Первичные байты и хеши повторно прочитанных блоков сохранены в
[coordinator-validation.json](coordinator-validation.json).

Аксессор `48D720` возвращает адрес освобождённого локального слота стека на обеих
ветвях. Это подтверждено оригинальными инструкциями закреплённого EXE. В выбранных
путях `Map+108/+10C` не читаются; `Map+110` задаёт длину циклов. Глобальная
неиспользуемость полей и другие сборки не установлены.

Type77 в сценах записывается как четыре little-endian DWORD: `(77, 148, 2, 4800915)`.
Эти значения — ранее наблюдавшийся эталон данной фикстуры, поэтому сравнение
проверяет воспроизведение. Смысл игровых полей этим не назначается. Скалярные
ожидания, Type74 и хвост выводятся отдельно из входных данных и первичных правил.

В граничной сцене слот счётчика намеренно заполнен `0x2094`, а writer читает
наблюдаемый остаток `0x294`: header объявляет 196 записей, фактически выданы 197.
PASS здесь означает воспроизведение этой конфигурации. Корректность полученного
файла, естественное возникновение в GUI и серьёзность возможного дефекта не доказаны.
Причина конкретных чтений на второй итерации также остаётся без опубликованной
пошаговой трассы. [Подробности и все семь сцен](type77-explanation.ru.md).

## Воспроизведение

Полный CPU-прогон требует исходного исследовательского стенда: этот каталог должен
находиться в `Tools/dk2-format-research/variables-type77`, рядом с историческими
хелперами из снимка. Относительно корня стенда нужны собственные неизменённые
`Dungeon Keeper 2/Data/editor/DK2 Editor pro.exe` и `Terrain.kwd` с хешами из
отчёта, Python, pefile, Capstone и Unicorn указанных в проверке версий. Зависимости
и игровые файлы в публикацию не включены; установка здесь не выполнялась.

`python -B Tools/dk2-format-research/variables-type77/audit_type77.py --no-write`

Ожидается семь PASS, совпадение pinned/observed SHA. Скрипт завершается с ненулевым
кодом при FAIL. Обычный checkout репозитория сам по себе не воспроизводит CPU-сцены:
исторические хелперы рассчитывают пути относительно исходного стенда.

Прогон использует явно объявленные внешние CFile/heap/IAT и другие baseline-адаптеры,
подготовку регистров на входе и CFile/vtable-фикстуру. `code_substitutions=0`
относится к оригинальным инструкциям. Дополнительный caller записывает два глобала
и оба слота стека; инициализация writer-слота затем перезаписывается.

Игровые файлы не записывались, живой редактор/игра не запускались. Новый Variables
writer, редактирование файлов и сохранение произвольных неизвестных union-вариантов
не реализованы этим дополнением. Globals29/186/113/114 остаются открытыми; Crypt
отложен. Полнота цели по всем форматам из семи сцен не выводится.
