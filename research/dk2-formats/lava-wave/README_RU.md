# Лава: движение поверхности с одной текстурой

14 ноября2026. Профиль DKII-DX.exe SHA-256 `d7a8b854e4e4f02709eba271bead6fe2307dd6e332b5a96e70857e5b0e19fb8a`. Дополнение не меняет прежние схемы физических полей и не объявляет закрытыми другие неизвестные форматы.

## Наблюдено

В установленном Terrain.kwd у Water4 ресурс поверхности называется Water, type2, flags20005h, число кадров32. У Lava5 — Lava0, type2, flags20001h, число кадров0. В установленном EngineTextures.dir найдены Lava0 и Lava0SOLID с mipmaps; последовательности Lava1..31 в этом индексе нет. Это наблюдение этих файлов, не доказательство отсутствия ресурсов в каждой версии игры.

Статически прослежено: ветка43CC30 для runtime Terrain.Flags&100h вызывает graphics slotFCh, который у CPCEngineInterface соответствует5A2BE0 (указатель670670h). Вода с флагом80h использует другой slotF8h/5A2570. Эти runtime-флаги не объявляются новыми raw Map-полями. Ресурс Lava0 не нуждается в подстановке мнимого числа текстурных кадров.

Исполнена оригинальная5A2BE0 до5A2DF8, то есть после формирования высот/нормалей, до подготовки цвета, аллокации5873A0, очереди и GPU. Вход — подготовленные engine+C9 phase и дескриптор сетки с subdivisions2. Две позиции клетки, восемь фаз0/8/16/32/64/96/127/128:16 сцен,144 значения высоты. Engine/descriptor сохранились, внутренних подстановок0, код и vtable защищены старым раннером. EXE не запускается средствами Windows.

Высота renderer-Z (ось вниз) для ix/iy0..2:

```text
ax = ((32*ix -64*cellX +phase) &127) * float32(pi) /64
ay = ((32*iy -64*cellY +phase) &127) * float32(pi) /64
sy = float32(sin(ay) * double(0.04))
height = float32(sin(ax)*double(0.04) +sy -float32(0.85))
```

Независимый Python-расчёт совпал со всеми144 сохранёнными значениями побайтово. В C# максимальное отличие5.9604645e-8 (один float32 ULP) при допуске1.2e-7. Зафиксировано отличие, а не заявлено побайтовое совпадение C#.

Период по параметру phase равен128. Естественный планировщик phase/скорость игры здесь не исполнен. Предпросмотр использует фазу своих30 обновлений/с; её скорость не объявляется измеренной игровой скоростью.

## Предпросмотр

Dk2LavaWave сохраняет эту формулу. Лава использует сетку3×3 вершины, её высота обновляется от общего animationClock. Для общих границ индексы обращены относительно целочисленного native-якоря: клетка предпросмотра(x,y), вершина(ix,iy) использует native cell(x+1,y+1), sample(2-ix,2-iy). Поэтому две соседние клетки задают одинаковую волну на стыке. Renderer-Z преобразуется в preview-Z через -1-height, затем применяется общая Terrain-деформация.

Тест --lava-scene-only построил рядом25 клеток лавы и25 клеток воды. Проверены разные фазы, реальное обновление от часов, совпадение всех трёх вершин общей границы, обновление освещённых страниц и отсутствие повторной деформации, исчезновение после Paint и возврат после Undo, скрытие, очистка и исходные байты карты. Сняты и визуально проверены Lava-Water-0.png и Lava-Water-32.png. Это кадры редактора, не игры.

Одновременно исправлено пространство вершинного света: исходные координаты остаются в source mesh, отображаемые берутся из общей проекции. Статическое чтение57B0E0 показывает58F030 для отображения и57BF00 с исходной позицией для света. Синтетическая проверка различает RGB исходной и деформированной позиции и требует первый вариант, сохраняя деформацию выходной геометрии. Слабый кэш проекций не удерживает старые позы, один результат используется всеми страницами модели.

## Воспроизведение и границы

```powershell
python emulate.py --research-root <папка прежних dk2-formats скриптов> --exe <DKII-DX.exe> --output <временная папка>
python audit.py --exe <DKII-DX.exe>
```

CPU-стенд требует Python3.12, Unicorn2.1.4 и зависимости native_unicorn_factorytrace.py/audit_targeted_spell.py. audit.py проверяет сохранённые данные, независимые высоты, SHA пакета и полный первичный диапазон5A2BE0; он не повторяет CPU или визуальные проверки. WindowsSmoke: --lava-native-only <cases.json> и --lava-scene-only <map> <game> <output>.

Не проверены естественное обновление phase, все подразделения сетки/графические режимы, bump/environment текстуры и конечные GPU-пиксели игры. Нормали статически прочитаны из5A2BE0; в144 численно проверенных выходах сохранены только высоты. Кадр DKII-DX той же сцены ещё нужен. Визуальный эффект движения добавлен, полное совпадение рендера лавы не заявляется.
