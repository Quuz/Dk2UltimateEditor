# Variables: первая ветвь сохранения записей игрока

14 ноября 2026. Дополнение к [этапу199](../EDITOR_VARIABLES_WRITER_RU.md), отдельно
от замороженного пакета205. [Подробности и четыре сцены](PLAYER_WRITER_RU.md).

Координатор независимо повторил конечный `audit(write=False)`: весь JSON совпал,
исходные файлы отчёта сохранили хеши. Проверены первичные инструкции `4943C0`,
счётчика `48CF50`, аксессора `488830` и соответствующего вызова счётчика.
Диапазоны двух функций включают завершающий `RET 4`; байты, дизассемблирование,
хеши источников и условия приёмки — в [проверке](coordinator-validation.json).

В подготовленных сценах отбор игрока использует байт `+1C >= 3`. Для контейнера
игрока `+4C` writer выдаёт четыре little-endian DWORD `(1, key_low8, value, kind)`.
Новая запись полностью назначается оригинальными инструкциями и сверяется с
ожиданием из входов. Порядок двух элементов одного игрока подтверждён. Пропуск
нулевого value прослежен статически, но не исполнен этими сценами. Проверены
нулевой список игроков и граница kind=2. Индекс игрока больше нуля и порядок
между игроками остаются непроверенными. Назначение игровых полей не выводится
из нейтральных обозначений key/value/kind.

Числа записей:196/197/198/196; META и неиспользованный хвост буфера проверены.
Скалярные хвосты в полном сравнении — воспроизведение наблюдаемого entry-scratch,
поэтому независимый оракул для всех байтов полного Variables здесь не заявляется.
Настоящая запись файла, GUI и игровые потребители не запускались; pool/availability
и оставшиеся union-ветви не закрыты. Globals29/186/113/114 остаются открытыми,
Crypt отложен.

## Воспроизведение

Требуется исходная структура стенда `Tools/dk2-format-research` с хелперами снимка,
локальными неизменёнными Pro EXE и Terrain.kwd (хеши в проверке), Python, pefile,
Capstone и Unicorn указанных версий. Игровые файлы и зависимости не публикуются.
Один checkout без стенда CPU-сцены не запускает: исторические пути относятся
к расположению исходного исследования.

Из корня стенда:

`python -B Tools/dk2-format-research/variables-player-writer/audit_player_writer.py --no-write`

Ожидается `overall=PASS`, четыре сцены; при FAIL код возврата ненулевой. Baseline
CFile/heap/IAT-адаптеры и подготовка регистров являются явно объявленной фикстурой;
оригинальные инструкции не заменялись. Исходные игровые файлы только читались.
