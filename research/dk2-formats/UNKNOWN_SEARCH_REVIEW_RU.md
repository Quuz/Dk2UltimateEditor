# Дополнительный флаг Creatures и граница поиска бонусов Crypt

Этап 149, 31 октября 2026. Проверен предоставленный `DKII-DX.exe`, SHA-256 `d7a8b854e4e4f02709eba271bead6fe2307dd6e332b5a96e70857e5b0e19fb8a`.

Нового назначения неизвестного свойства этот этап не устанавливает. Сохранены результаты двух новых поисков и исключена конкретная ложная зацепка, чтобы дальнейшее исследование не возвращалось к ней. Машинная спецификация — `unknown-search-review.json`.

## Creatures: GameExtraFlags, бит 0x2

DWORD по raw `+0x1545` загружается в definition `+0x68A`; этот путь уже установлен прежними этапами. Новая трассировка начинается от указателей определения существа, учитывает смещения базы, стековые сохранения и до трёх уровней прямых вызовов. Для всего DWORD найдено шесть уникальных чтений:

| Инструкция | Проверяемая маска |
|---|---:|
| `478B8E` | `4` |
| `478C3E` | `4` |
| `478CE9` | `4` |
| `48B879` | `4` |
| `4AF28B` | `1` |
| `4DC064` | `8` |

Назначение маски `2` из этих чтений не следует. Прежняя подпись StoneKnight остаётся неподтверждённой как описание игрового поведения этого бита. Для редактора следует сохранять исходные биты и не обещать механический эффект только по подписи.

В 3 734 записях Creatures из 82 исходных контейнеров бит `2` установлен три раза. Во всех случаях это ID 28, GameExtraFlags = 3: отдельно в `Creatures.kwd`, а также в `XXLevel19Globals.kld` и `XXLevel20Globals.kld`. Это корреляция в данных; сама по себе она не доказывает, что игра проверяет бит `2` или что тот воспроизводит все особенности ID 28.

Поиск оставил один ограниченный контекст вызываемой функции; произвольные возвраты указателей и все индексированные пути не исчерпаны. Глобальная неиспользуемость бита не доказана.

## Crypt: ложное чтение счётчика Unique Warlock

Новый поиск следует за предполагаемыми указателями владельца из entity `+0x2A` и настоящего room-owner getter `4E52F0`. Он обнаружил 12 цепочек, в которых инструкция `4C7368` выглядела как чтение owner `+0x108B`, счётчика группы ID 34. Первичный код и выполнение отвергли эту трактовку.

Функция `4C7360` начинает с owner `+0xE97`, проверяет один байт, сдвигает указатель на `0x19` и повторяет цикл лишь пока unsigned-счётчик меньше 3. Реальные адреса чтения:

```text
owner + E97
owner + EB0
owner + EC9
```

Если первый ненулевой байт найден, функция возвращает 1; если все три нулевые — 0. В буфер владельца она не пишет. Более широкое назначение этих трёх байтов здесь не устанавливается.

Анализатор указателей не отслеживал числовое условие цикла и продолжал его за пределы трёх проверок. Смещение `108B` получилось как `E97 + 20 × 19`, то есть потребовало бы двадцать первого чтения. Такого прохода в исходной функции нет. Это ошибка исследовательского анализа, а не свидетельство неправильной записи оригинальным редактором или неправильного чтения игрой.

Восьми новым исполнениям оригинальной функции соответствуют следующие результаты:

| Подготовленный вариант | Результат | Число чтений |
|---|---:|---:|
| Три настоящих байта нулевые, owner108B = 0 / 1 / 127 / 255 | 0 | 3 |
| Первый настоящий байт = 1 | 1 | 1 |
| Второй настоящий байт = 1 | 1 | 2 |
| Третий настоящий байт = 1 | 1 | 3 |
| Первый настоящий байт = 128 | 1 | 1 |

Четыре независимых контроля Ghidra подтвердили EAX, ECX и ESP. Это проверки регистров; полного независимого снимка памяти Ghidra здесь нет. Unicorn дополнительно подтвердил точные адреса чтений и неизменность всего подготовленного буфера. Ghidra использует отдельный тестовый переход к своему адресу завершения; ранний вариант со стоп-байтом INT3 исключён из принятых контролей.

Ранее раскрыты восемь групп Crypt. Десять счётчиков — `108A`, `108B`, `1092`, `1093`, `1096`–`109B` — по-прежнему не получили подтверждённого игрового назначения. Новый поиск имеет шесть ограниченных контекстов вызываемых функций и не доказывает, что эти группы вообще нигде не действуют. Конкретная ложная зацепка `4C7368 → 108B` помечена как исключённая.

## Воспроизводимость и сохранность

Сверены полные байты семи функций: одна исполнена, шесть служат статическими доказательствами чтений дополнительных флагов. Все 12 уникальных исполненных адресов инструкций покрыты первичной сверкой с Ghidra. Новых точечных правок формата нет; API, перечисления и актуальные представления полей не изменены.

```text
python scan_extra_creature_flags.py
python scan_crypt_owner_pointers.py
python emulate_crypt_counter_boundary.py
python crosscheck_crypt_counter_boundary.py
python prepare_unknown_search_primary.py
python build_unknown_search_review.py
python audit_unknown_search_review.py
```

Сохранены SHA-256 310 исходных файлов, семи путей EXE и прежние 127 компонентов спецификации. В пакет добавлен компонент проверки границ поиска; это не увеличение числа расшифрованных свойств. Общая оценка готовности около 75% сохраняется, цель по 15 семействам остаётся открытой.
