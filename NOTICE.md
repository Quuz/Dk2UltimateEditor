# Credits and provenance

UltimateEditor is a modern C# / WPF implementation based on the behavior and file formats of NovFR’s Dungeon Keeper 2 map editor:

https://github.com/NovFR/DK2-Map-Editor

The upstream Git history is retained. `Source/` and `Binaries/` preserve original materials; the current application code is under `src/`. Some original source files and resources are embedded as format references or UI assets. Original names and attribution remain intact.

**Quuz** maintains UltimateEditor and leads its enhancements, ongoing development and new features, with contributions from the community. Original editor authorship remains with **NovFR**.

No license file was present in the imported upstream tree. This repository does not assign a new blanket open-source license to NovFR’s code/resources or Dungeon Keeper 2 materials. A public repository makes the source available for inspection; it does not by itself settle redistribution or licensing rights. Contributors should only submit material they have permission to contribute. A project license must account for the provenance of each component before being declared.

Dungeon Keeper 2 and associated game assets belong to their respective rights holders. UltimateEditor is a community project, not an official game release. The full game, a game executable and personal game installations are not part of the new application distribution.

Flame (https://github.com/DiaLight/Flame) is a separate community project. References to Flame document interoperability and testing; they do not imply that this repository is maintained by the Flame authors.
